Why DeviceRefAttr belongs in MLIR

Copied Q&A · tensor placement → native compiler decisions

QnA · Why does MAX use DeviceRefAttr instead of a device string?

Yes, MAX could be designed to encode a device as "devices:gpu0". But the compiler would still need to interpret that string and use it when generating allocations, transfers, and kernel calls. DeviceRefAttr gives those compiler stages a structured device reference.

It already stores a string; the definition separates it into two fields:

DEV0 = #M.device_ref<"gpu", 0>

attribute kind = M::DeviceRefAttr
label          = "gpu"
id             = 0

The attribute’s kind identifies these fields as a device reference. Its definition also says that the reference identifies a device specification within the model. See MAttrs.td:414.

  1. The device becomes part of the tensor’s compiler contract.

    In your attention example, each input has this compiler-visible description:

    Q_type = !mo.tensor<[32,32], f32, gpu:0>
├─ shape  → [32,32]
├─ dtype  → float32
└─ device → #M.device_ref<"gpu",0>

    Shape tells the compiler the tensor’s dimensions. Dtype tells it the element representation. Device identifies the tensor’s placement.

    MAX’s native TensorType builder specifically accepts a DeviceRefAttr for that field. An arbitrary string does not satisfy the current interface. See MOTypes.td:56.

    This placement also participates in verification. checkDeviceConstraint() reads the device from a type and reports an error when an operand’s device differs from the operation’s required device. For example, a constraint requiring gpu:0 can reject an operand on gpu:1. This check happens in the verifier—not merely by constructing DeviceRefAttr. See MOInterfaces.cpp:513.

  2. Native compiler passes can discover the devices by inspecting the IR.

    MAX has an actual routine for this:

    getAllDevicesUsedInGraph(G1)
├─ Include the host device: cpu:0
├─ Walk operation attributes and operand/result/block-argument types
├─ Collect every DeviceRefAttr encountered
└─ Deduplicate the collected references

    For Q, K, and V all on gpu:0, the collection contains:

    {cpu:0, gpu:0}

    The three inputs share one GPU reference. The lowering code then registers type and buffer builders for the discovered devices. See MOGGToMGP.cpp:217.

    This walker explicitly recognizes DeviceRefAttr. A string such as "devices:gpu0" would require additional rules identifying which strings represent devices and how to parse them.

  3. The device reference changes what operations lowering generates.

    Consider a graph containing an explicit tensor transfer. The existing lowering code reads the source and destination device references and chooses a route:

    Source → destination Lowering route
    cpu:0 → gpu:0 bufferTransferFromHost(...)
    gpu:0 → cpu:0 bufferTransferToHost(...)
    gpu:0 → gpu:1 bufferTransferDevice(...)

    These are the branches in lowerTransferImpl().

    For the first route:

    mo.transfer: cpu:0 → gpu:0
└─ lowerTransferImpl(...)
   └─ bufferTransferFromHost(...)
      └─ Create an MGP BufferHostToDeviceOp
         ├─ source buffer
         ├─ destination buffer
         ├─ device-context operand
         └─ ordering chain

    The buffer builder creates this operation during compilation. See BufferBuilder.cpp:148.

    The attribute guides the transformation; constructing the attribute does not perform the transfer.

  4. It connects placement to the device context used by the execution plan.

    Later lowering needs more than the designation gpu:0: it needs the corresponding device-context operand.

    getExecuteDevice(DEV0)
├─ Look for a context override for DEV0
├─ Otherwise match DEV0 against the model’s device references
└─ Return the associated device-context operand

    That operand can be supplied to generated allocation and transfer operations. See LoweringState.h:262.

    The reference is therefore a key connecting a tensor’s placement to the appropriate execution resources.

  5. Device identity and hardware implementation remain separate.

    #M.device_ref<"gpu",0> identifies a model device. Additional device information supplies properties such as CUDA versus HIP and GPU architecture.

    Kernel resolution uses that information:

    MojoRegistry::getResolvedKernel(name, DEV0)
├─ Look up device information for DEV0
├─ Compare it with registered kernel implementations
└─ Select a matching implementation

    See MojoRegistry.cpp:166.

    The device specification documentation also explicitly allows model device IDs to be placeholders, with initialization establishing their mapping to physical devices. Consequently, the 0 need not universally mean a particular physical CUDA device. See MAttrs.td:497.

MLIR does not require every device representation to be a custom attribute. A compiler could use strings with a documented convention. MAX chooses a dialect-defined attribute so its native type builders, verifiers, walkers, kernel resolution, and lowering routines share one representation. Keeping the designation only in Python would leave those native stages without the placement information they currently read from the IR.

def M_TargetInfoAttr : MAttr<"TargetInfo", "target"> {
  let summary = "Target configuration attribute.";
  let description = [{
    The `#M.target` attribute represents a compilation target configuration. It
    contains the target triple, microarchitecture, stdlib plugin, optional features,
    and derived data such as data layout and SIMD width.

    The user can also specify the default index bit width being used. This is
    important for GPUs where the hardware can support different index bit widths
    for cross compilation.

    The microarchitecture and features may encode version numbers, such as
    'sm_80' for CUDA compute capability 8.0. When deciding if a runtime host
    supports a compile time microarchitecutre or feature it may be necessary
    to compare these versions numerically rather than textually.

    Features are encoded in the form of "+feature1,+feature2,-feature3",
    where "+" enables and "-" disables a feature. The list is fully
    expanded: it includes both the features explicitly requested by the
    user and all features enabled by default for the target CPU (e.g.
    avx512f on znver4), with explicit user overrides applied on top.
    A feature present in the list without a "-" entry is enabled; a
    feature absent from the list was not enabled by the CPU model and
    was not explicitly requested.

    Example:
    ```mlir
    #M.target<triple="x86_64-unknown-linux-gnu", arch="znver3",
              stdlib_plugin="default", features="+avx,+avx2",
              data_layout="p:64:64-i64:64:64", relocation_model="static",
              simd_bit_width=256, index_bit_width=64>
    #M.target<triple="nvptx64-nvidia-cuda", arch="sm_80", stdlib_plugin="cuda">
    ```

    Can be (partially) represented at runtime by M::TargetInfo.

    The `accelerator_arch` contains the vendor name of the accelerator in
    lowercase (e.g. nvidia or amd) along with the compute capability (e.g. 80 or
    90). For example, a valid `accelerator_arch` is `nvidia:80` or `amdgpu:gfx942`.

    The `abi` names the target ABI (e.g. RISC-V's `lp64d`, MIPS's `n32`),
    mirroring clang's `-target-abi`. When set, it is recorded as a
    `target-abi` LLVM module flag, exactly as clang does.

    The `opaque_plugin` carries an opaque payload as the stdlib plugin. MDialect
    never inspects it. The payload must be a typed attribute, so that its type
    is always available to the dialect that interprets it.

    Example:
    ```mlir
    #M.target<triple="x86_64-unknown-linux-gnu", arch="znver3",
              opaque_plugin=#kgen.param_list<index>
                          : !kgen.param_list<!kgen.type>>
    ```
  }];

  let parameters = (ins
    "llvm::Triple":$triple,
    StringRefParameter<>:$arch,
    StringRefParameter<"", "\"default\"">:$stdlib_plugin,
    OptionalParameter<"TypedAttr">:$opaque_plugin,
    OptionalStringRefParameter:$features,
    OptionalDataLayoutParameter:$data_layout,
    DefaultValuedParameter<"llvm::Reloc::Model",
                           "llvm::Reloc::Static">:$relocation_model,
    DefaultValuedParameter<"int64_t", "0">:$simd_bit_width,
    DefaultValuedParameter<"std::optional<int64_t>",
                           "std::nullopt">:$index_bit_width,
    OptionalStringRefParameter:$tune_cpu,
    OptionalStringRefParameter:$accelerator_arch,
    OptionalStringRefParameter:$abi
  );

  let assemblyFormat = "`<` struct(params) `>`";

  let extraClassDeclaration = [{
    /// Get the target triple as a string.
    std::string getTripleStr() const {
      return getTriple().normalize();
    }

    /// Returns whether the triple is a GPU target.
    bool isGPU() const {
      return getTriple().isNVPTX() || getTriple().isAMDGPU() || isMetal();
    }

    /// Returns whether this is a Metal target (macOS with actual GPU, not embedded devices).
    bool isMetal() const {
      // Use the same logic as isMetalTriple() for consistency
      // Accept both air64 and arm64 triples for Metal GPU targets
      return getTripleStr().starts_with("air64");
    }

    /// Check if the target supports a specific hardware feature.
    /// See M::hasFeature for the matching contract.
    bool hasFeature(StringRef feature) const {
      return M::hasFeature(getFeatures(), feature);
    }

    /// Returns the operating system for the triple.
    StringRef getOS() const {
      return llvm::Triple::getOSTypeName(getTriple().getOS());
    }

    /// Returns the resolved index_bit_width.
    int64_t resolveIndexBitWidth() {
      return getIndexBitWidth().value_or(getDataLayout().getPointerBitWidth());
    }

    /// Returns ptr byteSize for the interpreter which is always 8
    int32_t getDefaultPointerSize() {
      return 8;
    }
  }];
}

def M_InOutSignatureAttr : MAttr<"InOutSignature", "inout_sig"> {
  let summary = "Describes the in/out/mut intended semantics for "
                "pointer-like operands.";
  let description = [{
    This attribute captures the intended semantics for each pointer-like
    operand of a primitive or kernel.
     - '.': Operand is a value.
     - 'i': Operand is only read.
     - 'o': Operand is only written.
     - 'm': Operand is mutated in-place.

    May be used to distinguish buffer-like operands on generic ops during
    compilation, in which case the attribute can be erased before conversion
    to MEF etc. May also be made available at runtime to help in runtime
    assertions and safety checks.

    Encoded into MEF as a string.

    Example:
    ```mlir
    #M.inout_sig<"ii.mo">
    ```
  }];

  let parameters = (ins StringRefParameter<>:$signature);
  let assemblyFormat = "`<` $signature `>`";
  let genVerifyDecl = 1;

  let extraClassDeclaration = [{
     /// The in/out/mut semantics of a single operand.
     enum InOutSemantics : char {
       kNone = '.',
       kIn = 'i',
       kOut = 'o',
       kMut = 'm'
     };

     /// Returns the arity of the signature.
     size_t size() const { return getSignature().size(); }

     /// Returns the semantics for the i'th operand.
     InOutSemantics operator[](size_t i) const {
       const StringRef& sig = getSignature();
       assert(i < sig.size() && "operand index out of range");
       return static_cast<InOutSemantics>(sig[i]);
     }

     /// Returns a new signature attribute with the specified arguments removed.
     InOutSignatureAttr remove(const llvm::BitVector& toRemove);

     /// Append new arguments to the current signature and return the result
     /// as a new signature attribute.

LogicalResult Impl::verifyMatchingRanks(ArrayRef<TensorValue> values) {
  SmallVector<size_t> staticRanks;
  for (auto v : values) {
    TensorType t = v.getType();
    // Layout annotations may change ranks.
    if (t.getLayoutAttr())
      return success();
    staticRanks.emplace_back(t.getRank());
  }

  return success(llvm::all_equal(staticRanks));
}

LogicalResult Impl::checkMatmulCompatibility(Operation *op, TensorValue A,
                                             TensorValue B, TensorValue C) {
  // Implicit broadcasting is not supported.
  SmallVector<TensorValue> tensors{A, B, C};

  TensorType aType = A.getType();
  TensorType bType = B.getType();

  if (aType.getRank() < 2) {
    return op->emitOpError(
               "expected input tensors to have at least rank 2, got ")
           << aType.getRank();
  }

  if (!aType.hasStaticShape() || !bType.hasStaticShape())
    return success();

  // Lowering may add attributes that implicitly transpose operands.
  if (auto bmm = dyn_cast<BatchMatmulOp>(op))
    if (bmm.getTransposeB())
      return success();

  // Likewise for layout annotations added during lowering.
  if (aType.getLayoutAttr() || bType.getLayoutAttr())
    return success();

  ArrayRef<TypedAttr> aMatShape = aType.getDims().take_back(2);
  ArrayRef<TypedAttr> bMatShape = bType.getDims().take_back(2);
  if (aMatShape[1] != bMatShape[0])
    return op->emitOpError("incompatible input/result matmul shapes");

  ArrayRef<TypedAttr> aMatBatches = aType.getDims().drop_back(2);
  ArrayRef<TypedAttr> bMatBatches = bType.getDims().drop_back(2);
  if (!aMatBatches.equals(bMatBatches))
    return op->emitOpError("incompatible input/result batch dimensions");

  TensorType resType = C.getType();

  // Dynamic results are left to shape inference.
  if (!resType.hasStaticShape())
    return success();

  ArrayRef<TypedAttr> resMatShape = resType.getDims().take_back(2);
  if (resMatShape[0] != aMatShape[0] || resMatShape[1] != bMatShape[1])
    return op->emitOpError("incompatible input/result matmul shapes");

  ArrayRef<TypedAttr> resMatBatches = resType.getDims().drop_back(2);
  if (!aMatBatches.equals(resMatBatches))
    return op->emitOpError("incompatible input/result batch dimensions");

  return success();
}

LogicalResult Impl::verifyReduction(Reduction op) {
  // TODO: test
  if (failed(verifyMatchingRanks({op.getInput(), op.getResult()})))
    return op.emitOpError("input and output must either both have dynamic "
                          "ranks or both have the same size static ranks");

  TensorType inputTy = op.getInput().getType();
  int64_t rank = inputTy.getRank();
  if (IntegerAttr axisAttr = op.getAxisAttribute()) {
    int64_t axis = axisAttr.getInt();
    if (axis < -rank || axis > rank - 1)
      return op.emitOpError() << "axis must be between [-" << rank << ", "
                              << (rank - 1) << "] found " << axis;
    return success();
  }

  // Without `axis`, the result shape names the reduced dimension.
  if (inputTy.getShape() == op.getResult().getType().getShape())
    return success();
  ErrorOr<int64_t> axis =
      getReductionAxis(op.getInput(), op.getResult().getType());
  if (axis.isError())
    return op.emitOpError() << axis.getError();
  return success();
}

  OpBuilder builder(op);
  return materializeReduceShape(graphOp, loc, inputShape,
                                axis ? builder.getIndexAttr(*axis)
                                     : TypedAttr());
}

// ScatterLike
//===----------------------------------------------------------------------===//

LogicalResult Impl::verifyScatterLike(ScatterLike op) {
  TensorType inputTy = op.getInput().getType();
  TensorType resTy = op.getInput().getType();
  if (!inputTy.hasStaticShape() || !resTy.hasStaticShape())
    return success();
  TypedAttr inputShapeAttr = inputTy.getShape();
  TypedAttr resShapeAttr = resTy.getShape();
  if (inputShapeAttr != resShapeAttr) {
    return op->emitError()
           << "input and result shapes must match if both static: "
           << "input shape = " << MOSH::shapeTypedAttrToStr(inputShapeAttr)
           << ", result shape = " << MOSH::shapeTypedAttrToStr(resShapeAttr);
  }

  uint64_t expectedRank;
  auto getOptionalRankAndSetExpectedRank =
      [&](TensorValue tensor) -> std::optional<uint64_t> {
    TensorType tensorTy = tensor.getType();
    if (!tensorTy.hasRank()) {
      return std::nullopt;
    }
    expectedRank = tensorTy.getRank();

    return expectedRank;
  };

  auto rankIsSameAsExpected = [&](std::optional<uint64_t> rank) -> bool {
    return rank.value_or(expectedRank) == expectedRank;
  };

  auto inputRank = getOptionalRankAndSetExpectedRank(op.getInput());
  auto updatesRank = getOptionalRankAndSetExpectedRank(op.getUpdates());
  auto indicesRank = getOptionalRankAndSetExpectedRank(op.getIndices());
  auto outputRank = getOptionalRankAndSetExpectedRank(op.getResult());

  if (!rankIsSameAsExpected(inputRank) || !rankIsSameAsExpected(updatesRank) ||
      !rankIsSameAsExpected(indicesRank) || !rankIsSameAsExpected(outputRank)) {
    return op->emitError() << "Output and inputs (except axis) of a "
                              "scatter-like op must have the same rank";
  }

  return success();
}

Impl::materializeScatterLikeShapeDefs(ScatterLike op,
                                      ArrayRef<TypedAttr> inputAttrs) {

  TypedAttr updatesShape = inputAttrs[1];
  TypedAttr indicesShape = inputAttrs[2];

}

//===----------------------------------------------------------------------===//
// ScatterNdLike
//===----------------------------------------------------------------------===//

LogicalResult Impl::verifyScatterNdLike(ScatterNdLike op) {
  TensorType inputTy = op.getInput().getType();
  TensorType resTy = op.getResult().getType();

  size_t inputRank = inputTy.getRank();
  size_t resRank = resTy.getRank();
  if (inputRank != resRank) {
    return op->emitError()
           << "input and result ranks must match if both static: "
           << "input rank = " << inputRank << ", result rank = " << resRank;
  }

  if (!inputTy.hasStaticShape() || !resTy.hasStaticShape())
    return success();
  TypedAttr inputShapeAttr = inputTy.getShape();
  TypedAttr resShapeAttr = resTy.getShape();
  if (inputShapeAttr != resShapeAttr) {
    return op->emitError()
           << "input and result shapes must match if both static: "
           << "input shape = " << MOSH::shapeTypedAttrToStr(inputShapeAttr)
           << ", result shape = " << MOSH::shapeTypedAttrToStr(resShapeAttr);
  }

  {
    int64_t dataRank = op.getInput().getType().getRank();
    int64_t indicesRank = op.getIndices().getType().getRank();
    int64_t indicesLastDim =
        op.getIndices().getType().getIntDim(indicesRank - 1);

    int64_t updatesRank = op.getUpdates().getType().getRank();
    int64_t expectedUpdatesRank = dataRank + indicesRank - indicesLastDim - 1;
    if (indicesLastDim != mlir::ShapedType::kDynamic &&
        updatesRank != expectedUpdatesRank) {
      return op->emitError("updates rank must be: data_rank + indices_rank - "
                           "indices_shape[-1] - 1");
    }
  }

  return success();
}

Impl::materializeScatterNdLikeShapeDefs(ScatterNdLike op,

  auto graphOp = op->getParentOfType<GraphOp>();
  Location loc = op->getLoc();
  TypedAttr inputShape = inputAttrs[0];
  TypedAttr updatesShape = inputAttrs[1];
  TypedAttr indicesShape = inputAttrs[2];
  return materializeScatterNdShape(graphOp, loc, inputShape, updatesShape,
                                   indicesShape);
}

LogicalResult SlidingWindow::verifyWindowParamShape(TensorValue windowParam,
                                                    StringRef name) {
  auto input =
      cast<MOTensorOpInterface>(this->getOperation()).getInputTensor(0);
  if (TensorType inputTy = input.getType(); inputTy.hasRank()) {
    if (TensorType windowParamTy = windowParam.getType();
        windowParamTy.hasStaticShape()) {
      if (name == "paddings") {
        if (static_cast<size_t>(windowParamTy.getIntDim(0)) !=
            2 * (inputTy.getRank() - 2)) {
          return emitError(name)
                 << " with static size must match 2 * (input rank - 2)";
        }
      } else if (static_cast<size_t>(windowParamTy.getIntDim(0)) !=
                 inputTy.getRank() - 2) {
        return emitError(name) << " with static size must match input rank - 2";
      }
    }
  }
  return success();
}

LogicalResult
SlidingWindow::verifyWindowParamSizes(ArrayRef<TensorValue> values) {
  SmallPtrSet<Attribute, 4> sizes;
  for (auto v : values)
    if (TensorType t = v.getType(); t.hasRank())
      sizes.insert(t.getDim(0));

  if (sizes.size() > 1)
    return emitError("window parameter sizes must match if static");

  return success();
}

LogicalResult Impl::verifySlidingWindow(SlidingWindow op) {
  if (failed(op.verifyWindowParamShape(op.getStrides(), "strides")))
    return failure();
  if (failed(op.verifyWindowParamShape(op.getDilations(), "dilations")))
    return failure();
  if (failed(op.verifyWindowParamShape(op.getPaddings(), "paddings")))
    return failure();

  auto moOp = cast<MOTensorOpInterface>(op.getOperation());
  if (failed(verifyMatchingRanks(
          {moOp.getInputTensor(0), moOp.getOutputTensor(0)}))) {
    return op.emitError(
        "input and output ranks must be all dynamic, or all static and match");
  }

  return success();
}

    }
  }

  return success();

// BufferOpConformance
//===----------------------------------------------------------------------===//

LogicalResult Impl::verifyBufferOpConformance(Operation *op) {
  auto numBufferOutputs = llvm::count_if(
      op->getResultTypes(), [](Type t) { return isa<MO::BufferType>(t); });

  auto numBufferInputs = llvm::count_if(
      op->getOperandTypes(), [](Type t) { return isa<MO::BufferType>(t); });

  if (numBufferInputs == 0 && numBufferOutputs == 0)
    return success();

  // Non-compute ops. mo.yield is excluded: alias analysis for mo.buffer
  // values is not supported.
  if (isa<MO::ChainCreateOp, MO::OutputOp>(op))
    return success();

  // These ops check this in their own verifiers.
  // TODO(GEX-1947): Unify their logic there with this trait verifier.
  if (isa<MO::YieldOp, MO::GuardOp>(op))
    return success();

  // Deliberately the only op that creates a buffer; to initialize one, pass
  // its result to the initializing op. If the extra memory round-trip matters,
  // implement mo.mutable.store as a kernel with fusion on its input.
  if (isa<MO::BufferCreateOp>(op))
    return success();

  if (numBufferOutputs != 0)
    return op->emitError("Ops are not allowed to create new mo.buffer values.");

  auto chainInputCount = llvm::count_if(
      op->getOperandTypes(), [](Type t) { return isa<MO::ChainType>(t); });

  auto chainOutputCount = llvm::count_if(
      op->getResultTypes(), [](Type t) { return isa<MO::ChainType>(t); });

  if (chainInputCount != chainOutputCount)
    return op->emitError(
        llvm::formatv("number of input chains ({}) does not match number "
                      "of output chains ({})",
                      chainInputCount, chainOutputCount));

  if (chainInputCount == 0)
    return op->emitError(
        "buffer consuming op must have at least one chain input/output");

  if (!isa<ChainType>(op->getResults().back().getType())) {
    return op->emitError("A mo.chain must be the last output for ops "
                         "with buffer inputs.");
  }

  if (!isa<ChainType>(op->getOperands().back().getType())) {
    return op->emitError("A mo.chain must be the last input for ops "
                         "with mo.buffer inputs.");
  }

  return success();
}

LogicalResult checkDeviceConstraint(Operation *op, const Twine &name, Type type,
                                    DeviceRefAttr constrainedTo) {
  auto deviceType = dyn_cast<MOHasDeviceTypeInterface>(type);
  if (!deviceType)
    return success();
  auto device = deviceType.getDeviceRef();
  if (!device)
    return op->emitError(name) << " is missing a device attribute.";
  if (constrainedTo && device != constrainedTo) {
    return op->emitError(op->getName().getStringRef())
           << ": " << name << " is constrained to be on device "
           << constrainedTo << " but has device " << device << ".";
  }
  return success();
}

LogicalResult checkOperandDeviceConstraint(Operation *op, size_t index,
                                           DeviceRefAttr constrainedTo) {
  Value operand = op->getOperand(index);
  std::string operandDesc = "Operand " + Twine(index).str();

  if (Operation *defOp = operand.getDefiningOp()) {
    operandDesc += " - " + defOp->getName().getStringRef().str();
  }

  operandDesc += " (using zero-based indexing)";

  return checkDeviceConstraint(op, operandDesc, operand.getType(),
                               constrainedTo);
}

LogicalResult checkResultDeviceConstraint(Operation *op, size_t index,
                                          DeviceRefAttr constrainedTo) {
  return checkDeviceConstraint(op, "Result " + Twine(index),
                               op->getResult(index).getType(), constrainedTo);
}

LogicalResult checkExecutionDeviceConstraint(MOHasDeviceInterface op,
                                             DeviceRefAttr constrainedTo) {
  if (constrainedTo && op.getExecutionDevice() != constrainedTo) {
    return op->emitError(op->getName().getStringRef())
           << ": Op is constrained to be on device " << constrainedTo
           << " but has device " << op.getExecutionDevice() << ".";
  }
  return success();
}

DeviceRefAttr Impl::getFirstResultDevice(Operation *op) {
  if (op->getNumResults() >= 1) {
    auto resultType = op->getResult(0).getType();
    if (auto deviceType = dyn_cast<MOHasDeviceTypeInterface>(resultType))
      return deviceType.getDeviceRef();
  }
  op->emitError(
      "Expected the first result to have a device type for MO_SingleDevice");
  return nullptr;
}

LogicalResult Impl::verifyHostOnly(Operation *op) {
  auto hostDevice = getHostDevice(op);

  if (auto hasDevice = dyn_cast<MOHasDeviceInterface>(op)) {
    if (!hasDevice.getExecutionDevice())
      return success();
    if (failed(checkExecutionDeviceConstraint(hasDevice, hostDevice)))
      return failure();
  }
  for (size_t i = 0; i < op->getNumOperands(); ++i)
    if (failed(checkOperandDeviceConstraint(op, i, hostDevice)))
      return failure();

  for (size_t i = 0; i < op->getNumResults(); ++i)
    if (failed(checkResultDeviceConstraint(op, i, hostDevice)))
      return failure();

  return success();
}

LogicalResult Impl::verifyExecutesOnHost(Operation *op) {
  auto hostDevice = getHostDevice(op);

  if (auto hasDevice = dyn_cast<MOHasDeviceInterface>(op)) {
    if (!hasDevice.getExecutionDevice())
      return success();
    // Control ops get a device even though they need no device context.
    if (isa<MO::MOControlOpInterface, MO::ChainCreateOp, MO::DebugPrintOp>(op))
      return success();
    if (failed(checkExecutionDeviceConstraint(hasDevice, hostDevice)))
      return failure();
  }
  return success();
}

LogicalResult Impl::verifySingleDevice(Operation *op,
                                       ArrayRef<size_t> hostOperandIndices,
                                       ArrayRef<size_t> deviceOperandIndices) {
  // The first device operand decides the device, else the first result.
  DeviceRefAttr singleDevice =
      deviceOperandIndices.empty()
          ? getFirstResultDevice(op)
          : getDeviceOrDefaultAny(
                op->getOperand(deviceOperandIndices.front()).getType());

  if (auto hasDevice = dyn_cast<MOHasDeviceInterface>(op)) {
    if (!hasDevice.getExecutionDevice())
      return success();
    if (failed(checkExecutionDeviceConstraint(hasDevice, singleDevice)))
      return failure();
  }

  // Empty deviceOperandIndices means all non-host operands.
  llvm::SmallVector<size_t> operandIndices;
  for (size_t i = 0; i < op->getNumOperands(); ++i)
    if (!llvm::is_contained(hostOperandIndices, i))
      operandIndices.push_back(i);
  if (deviceOperandIndices.empty())
    deviceOperandIndices = operandIndices;
  for (size_t i : deviceOperandIndices)
    if (failed(checkOperandDeviceConstraint(op, i, singleDevice)))
      return failure();
  for (size_t i : hostOperandIndices)
    if (failed(checkOperandDeviceConstraint(op, i, getHostDevice(op))))
      return failure();
  for (size_t i = 0; i < op->getNumResults(); ++i)
    if (failed(checkResultDeviceConstraint(op, i, singleDevice)))
      return failure();
  return success();
}

LogicalResult
Impl::verifyPeerInputDevices(Operation *op,
                             ArrayRef<size_t> hostOperandIndices) {
  DeviceRefAttr executionDevice = getFirstResultDevice(op);
  if (!executionDevice)
    return failure();
  DeviceRefAttr hostDevice = getHostDevice(op);

  for (size_t i = 0; i < op->getNumOperands(); ++i) {
    Value operand = op->getOperand(i);
    auto deviceType = dyn_cast<MOHasDeviceTypeInterface>(operand.getType());
    if (!deviceType)
      continue;
    DeviceRefAttr operandDevice = deviceType.getDeviceRef();
    // Host operands must match the host label exactly, which keeps host
    // scalars (e.g. epsilon) usable with kernels whose device operands live
    // on peer GPUs.
    if (llvm::is_contained(hostOperandIndices, i)) {
      if (operandDevice.getLabel() != hostDevice.getLabel())
        return op->emitError("Host operand ")
               << i << " device label '" << operandDevice.getLabel()
               << "' does not match host device label '"
               << hostDevice.getLabel() << "'.";
      continue;
    }
    if (operandDevice.getLabel() != executionDevice.getLabel())
      return op->emitError("Operand ")
             << i << " device label '" << operandDevice.getLabel()
             << "' does not match execution device label '"
             << executionDevice.getLabel() << "'.";
  }
  return success();
}

  if (auto graph = op->getParentOfType<GraphOp>())

struct IndexLowering {
  MGP::MOOpLoweringState &opLoweringState;

  // Arithmetic helpers
  auto constant(int64_t val) -> Value {
    return opLoweringState.create<mlir::index::ConstantOp>(val);
  }

  auto mul(Value a, Value b) -> Value {
    auto indexTy = opLoweringState.builder.getIndexType();
    return opLoweringState.create<mlir::index::MulOp>(indexTy, a, b);
  }

  auto add(Value a, Value b) -> Value {
    auto indexTy = opLoweringState.builder.getIndexType();
    return opLoweringState.create<mlir::index::AddOp>(indexTy, a, b);
  }

  auto div(Value a, Value b) -> Value {
    auto indexTy = opLoweringState.builder.getIndexType();
    return opLoweringState.create<mlir::index::DivSOp>(indexTy, a, b);
  }

  // `pop.select` takes a `!kgen.scalar<bool>` condition, but `index.cmp`
  // produces an `i1`. Convert the builtin `i1` to `!kgen.scalar<bool>`.
  auto asScalarBool(Value i1Cond) -> Value {
    auto boolTy = KGEN::SIMDType::get(opLoweringState.builder.getContext(), 1,
                                      KGEN::KGENDType::kBool);
    return opLoweringState.create<KGEN::POP::CastFromBuiltinOp>(boolTy, i1Cond);
  }

  auto ifPositive(Value check, Value yes, Value no) -> Value {
    auto indexTy = opLoweringState.builder.getIndexType();
    auto cond = opLoweringState.create<mlir::index::CmpOp>(
        mlir::index::IndexCmpPredicate::SLT, check, constant(0));
    return opLoweringState.create<KGEN::POP::SelectOp>(
        indexTy, asScalarBool(cond), no, yes);
  }

  auto ifZero(Value check, Value yes, Value no) -> Value {
    auto indexTy = opLoweringState.builder.getIndexType();
    auto cond = opLoweringState.create<mlir::index::CmpOp>(
        mlir::index::IndexCmpPredicate::EQ, check, constant(0));
    return opLoweringState.create<KGEN::POP::SelectOp>(
        indexTy, asScalarBool(cond), yes, no);
  }
};

                  mlir::SymbolTable &moduleSymbolTable)
      : loweringState(graph, compiledFrameworkLabel, minimumCpuAlignment,
                      moduleSymbolTable) {}

  /// Lower the mo.graph to mgp.model.
  LogicalResult run();

  // Establish type builders for all the (virtual) devices needed by the model.
  LogicalResult setupTypeBuildersForAllDevices(MO::GraphOp graph);

  // Establish buffer builders for all the (virtual) devices needed by the
  // model. Each device will have its 'runtime' created in the 'init' block
  // and held in the !mgp.context.
  CompileDiagnosticOrSuccess setupBufferBuildersForAllDevices();

  LogicalResult createModelOp();

  /// Lowers a MO::ListType to a MGP::ListType.
  MGP::ListType lowerListType(MO::ListType listTy);

  /// Clones a trivial operations that does not need transformation. E.g.,
  /// `index.constant`
  LogicalResult cloneTrivialOp(Operation *trivialOp);

  /// Returns an attribute to represent elementAttr for the remainder of
  /// compilation:
  ///  - We commit to a specific byte layout, ie from here on the attribute
  ///    is considered an ArrayRef<uint8_t> with no further interpretation.
  ///  - Large attributes are outlined as dense_resources.
  ///  - The required runtime alignment is captured as an !M.aligned_bytes type.
  ///  - The runtime alignment will be at least 'minimumCpuAlignment' from
  ///    the pass options.
  ///  - If elementAttr already has an !M.aligned_bytes type annotation, that
  ///    may increase the alignment. Otherwise, if the attribute itself has some
  ///    indication of alignment (eg a dense_resource's blob's alignment) that
  ///    may increase the alignment.
  ///  - However the result's underlying data may not respect the alignment.
  ///    Instead we assume alignment is enforced on serialization to MEF.
  ///    This helps us avoid gratuitous memory copies.
  ///  - No data is copied.
  ErrorOr<ElementsAttr> lowerElementsAttr(ElementsAttr elementsAttr) {
    return loweringState.lowerElementsAttr(elementsAttr);
  }

  /// Per-op lowering overloads. Each concrete MO/MOGG/KGEN op type has a
  /// corresponding `lower()` overload; `lowerOp()` dispatches to these via
  /// TypeSwitch.
  LogicalResult lower(MO::OutputOp op);
  LogicalResult lower(MO::YieldOp op);
  LogicalResult lower(MO::WhileConditionOp op);
  LogicalResult lower(MO::IndexToTensorOp op);
  LogicalResult lower(MO::Shape::ToTensorOp op);
  LogicalResult lower(MO::Shape::FromTensorOp op);
  LogicalResult lower(MO::RebindOp op);
  LogicalResult lower(MO::ConstantOp op);
  LogicalResult lower(MO::ConstantExternalOp op);
  LogicalResult lower(MO::ConstantScalarOp op);
  LogicalResult lower(MO::DebugPrintOp op);
  LogicalResult lower(MO::DebugTensorPrintOp op);
  LogicalResult lower(MO::TransferOp op);
  LogicalResult lower(MO::StableCreateOp op);
  LogicalResult lower(MO::IfOp op);
  LogicalResult lower(MO::WhileOp op);
  LogicalResult lower(MO::GuardOp op);
  LogicalResult lower(MO::ChainCreateOp op);
  LogicalResult lower(MO::MutableStoreOp op);
  LogicalResult lower(MO::MutableLoadOp op);
  LogicalResult lower(MO::BufferCreateOp op);
  LogicalResult lower(MO::BufferTransferOp op);
  LogicalResult lower(MO::CallOp op);
  LogicalResult lower(MO::ParallelOp op);
  LogicalResult lower(MO::SequenceOp op);
  LogicalResult lower(MO::TensorBundleOp op);
  LogicalResult lower(MO::TensorUnbundleOp op);

  /// Param ops need the enclosing region to resolve parameter expressions.
  LogicalResult lowerParam(Region *parentRegion, KGEN::ParamDeclareOp op);
  LogicalResult lowerParam(Region *parentRegion, MOSH::ParamToValueOp op);
  LogicalResult lowerParam(Region *parentRegion, MOSH::ParamFromValueOp op);

  /// Interface-based lowering for externally-defined ops.
  LogicalResult lowerInterface(MGP::LowerableToMGPInterface op);

private:
  /// Lowers a single Operation via type-based dispatch.
  LogicalResult lowerOp(Operation &op, mlir::Region *parentRegion);

  /// Lowers a Block
  LogicalResult lowerBlock(mlir::Block *block);

  MGP::MOGraphLoweringState loweringState;
};

static SmallVector<DeviceRefAttr> getAllDevicesUsedInGraph(MO::GraphOp graph) {
  llvm::DenseSet<DeviceRefAttr> devices;

  // The host device may not appear in the graph.
  DeviceRefAttr hostDevice = DeviceRefAttr::getDefault(graph->getContext());
  devices.insert(hostDevice);

  mlir::AttrTypeWalker walker;
  walker.addWalk([&](DeviceRefAttr attr) { devices.insert(attr); });
  graph->walk([&](Operation *op) {
    walker.walk(op->getAttrDictionary());
    for (Type type : op->getOperands().getTypes())
      walker.walk(type);
    for (Type type : op->getResultTypes())
      walker.walk(type);
    for (Region &region : op->getRegions()) {
      for (Type type : region.getArgumentTypes())
        walker.walk(type);
    }
  });

  // Host first, then the rest by string representation, for a stable order.
  SmallVector<DeviceRefAttr> sorted = llvm::to_vector(devices);
  llvm::sort(sorted.begin(), sorted.end(),
             [hostDevice](DeviceRefAttr left, DeviceRefAttr right) {
               if (left == hostDevice)
                 return true;
               if (right == hostDevice)
                 return false;
               return left.toString() < right.toString();
             });
  return sorted;
}

LogicalResult
MOGraphLowering::setupTypeBuildersForAllDevices(MO::GraphOp graph) {
  for (DeviceRefAttr device : getAllDevicesUsedInGraph(graph))
    loweringState.registerTypeBuilder(device);
  return success();
}

CompileDiagnosticOrSuccess MOGraphLowering::setupBufferBuildersForAllDevices() {
  DeviceRefAttr hostDevice =
      DeviceRefAttr::getDefault(loweringState.getModelOp()->getContext());

  auto makeBufferBuilder =
      [&](DeviceRefAttr targetDevice) -> CompileDiagnosticOrSuccess {
    MGP::MGPBufferBuilder *hostBufferBuilder;
    auto bufferBuilder = std::make_unique<MGP::MGPBufferBuilder>(targetDevice);
    if (hostDevice == targetDevice) {
      hostBufferBuilder = bufferBuilder.get();
    } else {
      hostBufferBuilder = &loweringState.getBufferBuilder(hostDevice);
    }
    auto inChain =
        cast<TypedValue<MEF::ChainType>>(loweringState.getInitChain());
    auto chain = bufferBuilder->setupForModel(
        loweringState.getModelOp(), hostBufferBuilder,
        loweringState.getInitOpBuilder(), loweringState.getGraph()->getLoc(),
        inChain);
    loweringState.setInitChain(chain);
    loweringState.registerBufferBuilder(targetDevice, std::move(bufferBuilder));
    return success();
  };

  if (auto err = makeBufferBuilder(hostDevice); err.isError())
    return err;

  for (auto device : getAllDevicesUsedInGraph(loweringState.getGraph())) {
    if (device != hostDevice) {
      if (auto err = makeBufferBuilder(device); err.isError())
        return err;
    }
  }

  return success();
}

// Create the mgp.model and the regions for the init/execute phases.
LogicalResult MOGraphLowering::createModelOp() {
  MO::GraphOp &graph = loweringState.getGraph();
  OpBuilder b(graph);

  // Establish type builders for all the devices.
  // CAUTION: Must be done before any types are lowered, eg the next
  // paragraph.
  if (failed(setupTypeBuildersForAllDevices(graph)))
    return failure();

  // Convert the tensor types for the model signature over.
  SmallVector<Type> inputTypes, outputTypes;
  if (failed(loweringState.getTypeConverter().convertTypes(
          graph.getArgumentTypes(), inputTypes))) {
    return graph.emitOpError("failed to convert mo graph input types")
           << graph.getArgumentTypes() << " is not supported";
  } else if (failed(loweringState.getTypeConverter().convertTypes(
                 graph.getResultTypes(), outputTypes))) {
    return graph.emitOpError("failed to convert mo graph output types -- ")
           << graph.getResultTypes() << " is not supported";
  }

  // Preserve the MO::GraphOp argument locations in the MGP::ModelOp 'execute'
  // block argument locations.
  SmallVector<Location> inputLocs;
  for (BlockArgument arg : graph.getBody().front().getArguments())
    inputLocs.push_back(arg.getLoc());

  // Collect additional attributes to include with the MGP::ModelOp to guide
  // the MEF executor.
  SmallVector<NamedAttribute> extraAttrs;

  ArrayAttr argNamesAttr =
      graph->getAttrOfType<ArrayAttr>(kMgpModelArgumentNames);
  ArrayAttr resultNamesAttr =
      graph->getAttrOfType<ArrayAttr>(kMgpModelResultNames);
  ASSERT_STREAM(
      (argNamesAttr == nullptr) == (resultNamesAttr == nullptr),
      << "expected either both or neither of the `argument_names` and "
         "`result_names` attributes.");
  if (argNamesAttr) {
    extraAttrs.emplace_back(b.getStringAttr(kMgpModelArgumentNames),
                            argNamesAttr);
    extraAttrs.emplace_back(b.getStringAttr(kMgpModelResultNames),
                            resultNamesAttr);
  }

  ErrorOrSuccess err(success());
  auto devices = llvm::map_to_vector(getAllDevicesUsedInGraph(graph),
                                     [&err](DeviceRefAttr attr) {
                                       auto refOr = toRuntimeDeviceRef(attr);
                                       if (refOr.isError()) {
                                         err = refOr.takeError();
                                         return DeviceRef();
                                       } else {
                                         return refOr.takeValue();
                                       }
                                     });
  if (err.isError())
    return err;

  auto ctx = graph->getContext();
  SmallDenseMap<DeviceRefAttr, IntegerAttr> deviceIndexMap;
  auto idxType = IntegerType::get(ctx, 32, IntegerType::Unsigned);
  for (const auto &[idx, deviceRef] :
       llvm::enumerate(getAllDevicesUsedInGraph(graph)))
    deviceIndexMap[deviceRef] = IntegerAttr::get(idxType, idx);
  auto populateDeviceIndicesExtraAttr = [&](const char *label,
                                            SmallVector<Type> types) {
    llvm::SmallVector<Attribute> deviceIndices;
    for (const auto &type : types) {
      if (auto hasDeviceType = dyn_cast<MGP::MGPHasDeviceTypeInterface>(type))
        deviceIndices.push_back(deviceIndexMap[hasDeviceType.getDevice()]);
    }
    if (!deviceIndices.empty()) {
      ArrayAttr deviceIndicesAttr = ArrayAttr::get(ctx, deviceIndices);
      extraAttrs.emplace_back(b.getStringAttr(label), deviceIndicesAttr);
    }
  };
  populateDeviceIndicesExtraAttr(kMgpModelArgumentDeviceIndices, inputTypes);
  populateDeviceIndicesExtraAttr(kMgpModelResultDeviceIndices, outputTypes);

  b.setInsertionPoint(graph);
  auto modelOp = MGP::ModelOp::create(
      b, graph.getLoc(),
      /*name=*/graph.getNameAttr(),
      /*frameworkName=*/loweringState.getCompiledFrameworkLabel(),
      /*devices=*/devices,
      /*inputTypes=*/inputTypes,
      /*outputTypes=*/outputTypes,
      /*inputArgLocs=*/inputLocs,
      /*isSubgraph=*/graph.getIsSubgraph(),
      /*isDeviceGraph=*/graph.getIsDeviceGraph(),
      /*extraAttrs=*/extraAttrs);

  loweringState.setModelOp(modelOp);

  // The model takes over the graph's symbol name. The cached
  // `SymbolTableAnalysis` is never invalidated by the pass manager, so update
  // it by hand; the graph stays in the IR until the end of `run()`.
  mlir::SymbolTable &moduleSymbolTable = loweringState.getModuleSymbolTable();
  moduleSymbolTable.remove(graph);
  moduleSymbolTable.insert(modelOp);

  loweringState.getInitOpBuilder().setInsertionPointToEnd(
      loweringState.getModelOp().getInitBlock());
  // Tracks the current init output chain.
  loweringState.setInitChain(GRT::ChainCreateOp::create(
      loweringState.getInitOpBuilder(), graph.getLoc()));

  // Create the !mgp.context. Its numSlots attribute will be incremented
  // as needed.
  loweringState.setInitMgpContext(MGP::ContextCreateOp::create(
      loweringState.getInitOpBuilder(), graph.getLoc(), /*numSlots=*/0));

  // Initialize the execute state.
  Block *executeBlock = loweringState.getModelOp().getExecuteBlock();
  loweringState.getExecuteOpBuilder().setInsertionPointToEnd(executeBlock);

  // Extract chain and MGP context from arguments
  loweringState.setRootExecuteChain(executeBlock->getArgument(0));
  loweringState.setCurrentExecuteChain(executeBlock->getArgument(0));
  loweringState.setExecuteMgpContext(executeBlock->getArgument(1));

  for (auto [devRef, devArg] :
       llvm::zip(modelOp.getDevices(), modelOp.getInitDevices())) {
    loweringState.setInitDevice(
        dyn_cast<DeviceRefAttr>(devRef),
        dyn_cast<TypedValue<MGP::DeviceContextType>>(devArg));
  }

  // Establish buffer builders for all the devices. This may require some
  // extra device-specific setup in the 'init' block.
  // CAUTION: Must be done after the 'init' and 'execute' mgp.contexts have
  // been established, but before we lower any device-specific ops.
  if (auto err = setupBufferBuildersForAllDevices(); err.isError())
    return err.takeError();

  return success();
}

MGP::ListType MOGraphLowering::lowerListType(MO::ListType listTy) {
  auto outputTensorTy = dyn_cast<MO::TensorType>(listTy.getElementType());
  // TODO(#29947): Support other element types
  ASSERT_STREAM(outputTensorTy, << "only support lowering list of tensors");

  MLIRContext *ctx = listTy.getContext();
  MGP::TensorSpecType outputTensorSpecTy =
      MGP::createTensorSpecType(outputTensorTy);
  DeviceRefAttr tensorDeviceRef = MO::getDeviceOrDefault(outputTensorTy);
  auto mgpOutputTensorTy = loweringState.getTypeBuilder(tensorDeviceRef)
                               .tensorType(outputTensorSpecTy);
  return MGP::ListType::get(ctx, mgpOutputTensorTy);
}

LogicalResult MOGraphLowering::cloneTrivialOp(Operation *trivialOp) {
  Operation *cloned = loweringState.getExecuteOpBuilder().clone(*trivialOp);
  for (auto [from, to] :
       llvm::zip_equal(trivialOp->getResults(), cloned->getResults()))
    loweringState.emplaceExecuteLoweredValue(from, to);

  return success();
}

LogicalResult MOGraphLowering::lower(MO::OutputOp output) {
  // Init phase.
  SmallVector<Value> outputs;
  outputs.push_back(loweringState.getInitChain());
  outputs.push_back(loweringState.getInitMgpContext());
  outputs.push_back(loweringState.getModelOp().getInitWeightsRegistry());
  for (auto dev : loweringState.getModelOp().getDevices())
    outputs.push_back(
        loweringState.getInitDevice(dyn_cast<DeviceRefAttr>(dev)));
  MEF::OutputOp::create(loweringState.getInitOpBuilder(), output.getLoc(),
                        outputs);

  // Execute phase. Always returns a chain.
  SmallVector<Value> operands;
  operands.push_back(loweringState.getCurrentExecuteChain());

  for (auto [idx, operand] : llvm::enumerate(output.getOperands())) {
    Value loweredValue = loweringState.lookupExecuteLoweredValue(operand);
    if (!loweredValue)
      return output.emitOpError("operand #")
             << idx << " of type " << operand.getType()
             << " was never lowered into the execute block";

    // The model's results expect mgp.opaque. ToMGPFromOpaqueOp is a type
    // rebind, folded away once the input becomes mgp.opaque (e.g. after
    // OutlineAsyncRoutines).
    if (auto moOpaqueType = dyn_cast<MO::OpaqueType>(loweredValue.getType())) {
      Type mgpOpaqueType =
          MGP::OpaqueType::get(output->getContext(), moOpaqueType.getSymbol(),
                               moOpaqueType.getOptionalParameters());
      loweredValue = MOGG::ToMGPFromOpaqueOp::create(
          loweringState.getExecuteOpBuilder(), operand.getLoc(),
          TypeRange{mgpOpaqueType}, loweredValue);
    }

    operands.push_back(loweredValue);
  }

  MEF::OutputOp::create(loweringState.getExecuteOpBuilder(), output.getLoc(),
                        operands);
  return success();
}

LogicalResult MOGraphLowering::lower(MO::YieldOp yield) {
  // Always implicitly returns the current 'execute' block chain.
  SmallVector<Value> operands;
  operands.push_back(loweringState.getCurrentExecuteChain());

  for (Value operand : yield.getOperands())
    operands.push_back(loweringState.lookupExecuteLoweredValue(operand));

  for (TypedAttr param : yield.getParameters()) {
    auto valueOr = loweringState.lowerExpression(yield->getParentRegion(),
                                                 yield.getLoc(), param);
    if (valueOr.isError())
      return yield->emitOpError(valueOr.getError());
    operands.push_back(*valueOr);
  }

  MEF::OutputOp::create(loweringState.getExecuteOpBuilder(), yield.getLoc(),
                        operands);
  return success();
}

LogicalResult MOGraphLowering::lower(MO::WhileConditionOp condition) {
  // Always implicitly returns the current 'execute' block chain.
  SmallVector<Value> operands;
  operands.push_back(loweringState.getCurrentExecuteChain());

  for (Value operand : condition.getOperands())
    operands.push_back(loweringState.lookupExecuteLoweredValue(operand));

  MEF::OutputOp::create(loweringState.getExecuteOpBuilder(), condition.getLoc(),
                        operands);
  return success();
}

LogicalResult MOGraphLowering::lowerParam(Region *parentRegion,
                                          KGEN::ParamDeclareOp declOp) {
  auto valueOr = loweringState.lowerExpression(parentRegion, declOp->getLoc(),
                                               declOp.getValue());
  if (valueOr.isError())
    return declOp->emitOpError(valueOr.getError());

  Value value = *valueOr;
  if (auto err = loweringState.lowerParamDecl(parentRegion,
                                              declOp.getParamDecl(), value))
    return declOp->emitOpError(err.getError());

  return success();
}

LogicalResult MOGraphLowering::lowerParam(Region *parentRegion,
                                          MOSH::ParamToValueOp paramToValueOp) {
  auto valueOr = loweringState.lowerExpression(
      parentRegion, paramToValueOp.getLoc(), paramToValueOp.getValue());
  if (valueOr.isError())
    return paramToValueOp->emitOpError(valueOr.getError());

  loweringState.emplaceExecuteLoweredValue(paramToValueOp.getResult(),
                                           *valueOr);
  return success();
}

LogicalResult
MOGraphLowering::lowerParam(Region *parentRegion,
                            MOSH::ParamFromValueOp paramFromValueOp) {
  auto input =
      loweringState.lookupExecuteLoweredValue(paramFromValueOp.getValue());

  if (auto err = loweringState.lowerParamDecl(
          parentRegion, paramFromValueOp.getParamDecl(), input))
    return paramFromValueOp->emitOpError(err.getError());

  return success();
}

LogicalResult MOGraphLowering::lowerInterface(MGP::LowerableToMGPInterface op) {
  return op.lower(loweringState);
}

LogicalResult MOGraphLowering::lower(MO::IndexToTensorOp toTensorOp) {
  ASSERT_STREAM(MO::isOnHost(toTensorOp),
                << "mo.index.to_tensor is for host only");
  MGP::MOOpLoweringState opLoweringState(loweringState, toTensorOp);

  // Set up output buffer.
  FailureOr<SmallVector<MGP::MOOutputStorage>> loweredOutputStorageOr =
      opLoweringState.createOutputStorage(loweringState.getExecuteChain());
  if (failed(loweredOutputStorageOr))
    return failure();
  auto &outputStorage = (*loweredOutputStorageOr)[0];
  [[maybe_unused]] auto bufType =
      dyn_cast<MGP::DeviceBufferType>(outputStorage.buffer.getType());
  ASSERT_STREAM(bufType && bufType.getDevice().getLabel() == kCPULabel,
                << "expecting !mgp.buffer on host but it is on "
                << bufType.getDevice());

  // Fill the buffer with the index value.
  Value loweredIndexVal =
      loweringState.lookupExecuteLoweredValue(toTensorOp.getInput());

  // The input to mo.index.to_tensor is an scalar<si64>. Cast to index to match
  // the expectation of mgp.set_with_index.
  auto &builder = loweringState.getExecuteOpBuilder();
  loweredIndexVal =
      MGP::dimensionToIndex(builder, toTensorOp.getLoc(), loweredIndexVal);

  auto outChain = opLoweringState.bufferSetWithIndex(
      outputStorage.buffer, {loweredIndexVal},
      toTensorOp.getResult().getType());

  // Set up output tensor.
  opLoweringState.createOutputs(outChain, *loweredOutputStorageOr);
  return success();
}

LogicalResult MOGraphLowering::lower(MO::Shape::ToTensorOp toTensorOp) {
  ASSERT_STREAM(MO::isOnHost(toTensorOp),
                << "mo.shape.to_tensor is for host only");
  MGP::MOOpLoweringState opLoweringState(loweringState, toTensorOp);

  // Set up output buffer.
  FailureOr<SmallVector<MGP::MOOutputStorage>> loweredOutputsStorageOr =
      opLoweringState.createOutputStorage(loweringState.getExecuteChain());
  if (failed(loweredOutputsStorageOr))
    return failure();
  auto &outputStorage = (*loweredOutputsStorageOr)[0];

  // Fill the buffer with the runtime dimensions.
  auto loweredShape =
      loweringState.lookupExecuteLoweredValue(toTensorOp.getInput());

  auto loweredTensorSpec = cast<TypedValue<MGP::TensorSpecType>>(loweredShape);
  // Note loweredTensorSpec is the encoding for the shape we are trying to
  // reify as a tensor, whereas outputStorage.tensorSpec just describes
  // the statically known shape of our output tensor.
  SmallVector<Value> values(loweredTensorSpec.getType().getRank());
  for (size_t i = 0; i < values.size(); ++i)
    values[i] =
        opLoweringState.create<MGP::TensorSpecGetDimOp>(loweredTensorSpec, i);

  auto outChain = opLoweringState.bufferSetWithIndex(
      outputStorage.buffer, values, toTensorOp.getResult().getType());

  // Set up output tensor.
  opLoweringState.createOutputs(outChain, *loweredOutputsStorageOr);
  return success();
}

LogicalResult MOGraphLowering::lower(MO::Shape::FromTensorOp fromTensorOp) {
  ASSERT_STREAM(MO::isOnHost(fromTensorOp),
                << "mo.shape.to_tensor is for host only");
  MGP::MOOpLoweringState opLoweringState(loweringState, fromTensorOp);

  MO::TensorType tensorType = fromTensorOp.getInput().getType();
  std::optional<int64_t> rank = tensorType.getNumElements();

  ASSERT_STREAM(rank, << "unable to determine rank of result shape");

  MGP::BufferizedTensor inputBuffer =
      opLoweringState.getBufferizedInput(fromTensorOp.getInput());

  Value inChain =
      opLoweringState.getGuardChain(loweringState.getExecuteChain());

  auto sizeInBytes = opLoweringState.create<mlir::index::ConstantOp>(
      tensorType.getDtype().getSizeInBytes());

  SmallVector<Value> indices;
  for (auto dim : llvm::seq(*rank)) {
    IndexLowering indexLowering{opLoweringState};

    Value offset = indexLowering.constant(dim);
    Value offsetInBytes = indexLowering.mul(offset, sizeInBytes);

    Value sliced = opLoweringState.bufferSlice(
        inputBuffer.buffer, offsetInBytes, sizeInBytes, tensorType);

    Value indexValue =
        opLoweringState.create<MGP::BufferToIndexOp>(inChain, sliced);

    indices.push_back(indexValue);
  }

  SmallVector<int64_t> shape(*rank, mlir::ShapedType::kDynamic);
  auto tensorSpecType =
      MGP::TensorSpecType::get(shape, tensorType.getElementType());

  auto result =
      opLoweringState.create<MGP::TensorSpecCreateOp>(tensorSpecType, indices);

  loweringState.emplaceExecuteLoweredValue(fromTensorOp.getResult(), result);

  return success();
}

/// Returns the lowered tensor that the rebind's result should map to.
static Value getRebindResTensor(MO::RebindOp rebindOp,
                                MGP::MOGraphLoweringState &loweringState) {
  MGP::MOOpLoweringState opLoweringState(loweringState, rebindOp);

  MO::TensorValue inputTensor = rebindOp.getInput();
  MO::TensorType inputTy = inputTensor.getType();
  MO::TensorType resTy = rebindOp.getResult().getType();

  auto outSpecTy = MGP::createTensorSpecType(resTy);
  auto inSpecTy = MGP::createTensorSpecType(inputTy);
  Value loweredInput = loweringState.lookupExecuteLoweredValue(inputTensor);
  if (outSpecTy == inSpecTy)
    return loweredInput;

  SmallVector<Value> runtimeDims;
  Location loc = opLoweringState.loc;
  for (auto [idx, inDim, resDim] :
       llvm::enumerate(inputTy.getDims(), resTy.getDims())) {

    if (MOSH::ShapeAttr::getStaticDim(resDim))
      continue;

    if (std::optional<int64_t> intDim = MOSH::ShapeAttr::getStaticDim(inDim)) {
      auto constOp = opLoweringState.create<mlir::index::ConstantOp>(*intDim);
      runtimeDims.emplace_back(constOp.getResult());
      continue;
    }

    // Both dims are dynamic.
    auto getDimOp = loweringState.getDim(loc, loweredInput, idx,
                                         getDeviceOrDefault(inputTy));
    runtimeDims.emplace_back(getDimOp);
  }

  Value buffer = opLoweringState.tensorExtract(loweredInput, inputTy).first;
  TypedValue<MGP::TensorSpecType> tensorSpec =
      opLoweringState.create<MGP::TensorSpecCreateOp>(outSpecTy, runtimeDims);
  return opLoweringState.tensorCreate(loweringState.getExecuteChain(), buffer,
                                      tensorSpec, inputTy);
}

LogicalResult MOGraphLowering::lower(MO::RebindOp rebindOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, rebindOp);

  MO::TensorValue inputTensor = rebindOp.getInput();
  MO::TensorValue resTensor = rebindOp.getResult();

  MO::TensorType inputTy = inputTensor.getType();
  MO::TensorType resTy = resTensor.getType();
  if (inputTy.hasRank() != resTy.hasRank())
    return rebindOp.emitOpError(
        "rebind lowering doesn't support unknown shapes");

  // The input chain also guards the users of the reshaped buffer.
  Value inChain =
      opLoweringState.getGuardChain(loweringState.getExecuteChain());

  Value loweredOutput = getRebindResTensor(rebindOp, loweringState);
  loweringState.emplaceExecuteLoweredBufferValue(resTensor, loweredOutput,
                                                 inChain);

  // Establish the lowered form of the rebind's result parameters.
  // TODO: Note this may end up extracting the dynamic dimensions from the
  // result tensor even though the same dimension values were just passed
  // as operands to a tensor_spec.create op.
  ArrayRef<KGEN::ParamDeclAttr> decls = rebindOp.getOutputParamDecls();
  if (!decls.empty()) {
    MOSH::ShapeAttr resShape = resTy.getShape();
    for (KGEN::ParamDeclAttr decl : decls) {
      int64_t idx = findDeclIdx(resShape, decl);
      if (idx == -1) {
        return rebindOp.emitOpError(
            "rebind declares parameter not appearing in its result");
      }

      auto getDimOp = loweringState.getDim(rebindOp.getLoc(), loweredOutput,
                                           idx, getDeviceOrDefault(resTy));

      auto asDimension = MGP::indexToDimension(
          loweringState.getExecuteOpBuilder(), rebindOp.getLoc(), getDimOp);

      if (auto err = loweringState.lowerParamDecl(rebindOp->getParentRegion(),
                                                  decl, asDimension))
        return rebindOp->emitOpError(err.getError());
    }
  }

  return success();
}

/// Takes a constant op's result buffer on host and:
/// - allocates device memory,
/// - copies from host to device, then,
/// - creates the output tensor.
/// If the target device is host, then just creates the output tensor.
static LogicalResult
constHostBufferToTarget(MGP::MOOpLoweringState &opLoweringState,
                        MGP::MOGraphLoweringState &graphLoweringState,
                        Value hostBuffer, TypedValue<MEF::ChainType> chain,
                        TypedValue<MO::TensorType> opResult,
                        std::optional<uint64_t> maybeAlignment = std::nullopt) {
  MO::TensorType moTensorType = opResult.getType();
  FailureOr<TypedValue<MGP::TensorSpecType>> tensorSpecOr =
      opLoweringState.createTensorSpec(moTensorType);
  if (failed(tensorSpecOr))
    return failure();
  TypedValue<MGP::TensorSpecType> tensorSpec = *tensorSpecOr;

  DeviceRefAttr device = MO::getDeviceOrDefault(moTensorType);
  DeviceRefAttr hostDevice = graphLoweringState.getHostDevice();

  // Off host, allocate a device buffer and transfer HtoD.
  if (device == hostDevice) {
    opLoweringState.createOutputTensor(opResult, chain, hostBuffer, tensorSpec);
    return success();
  }

  uint64_t alignment = maybeAlignment.value_or(
      M::Driver::getPreferredAlignment(device.getLabel().str()));

  uint64_t sizeInBytes = *tensorSpec.getType().getSizeInBytes();
  Value bufferSize =
      opLoweringState.create<mlir::index::ConstantOp>(sizeInBytes);
  Value deviceBuffer =
      opLoweringState.bufferAlloc(chain, bufferSize, alignment, moTensorType);
  // bufferTransferFromHost also handles the stream sync, which is needlessly
  // conservative since a constant external's lifetime is outside the graph.
  Value outChain = opLoweringState.bufferTransferFromHost(
      chain, cast<TypedValue<MGP::DeviceBufferType>>(hostBuffer), deviceBuffer,
      moTensorType);

  opLoweringState.createOutputTensor(opResult, outChain, deviceBuffer,
                                     tensorSpec);
  return success();
}

LogicalResult MOGraphLowering::lower(MO::ConstantOp constOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, constOp);

  ErrorOr<ElementsAttr> elementsOr = lowerElementsAttr(constOp.getValue());
  if (elementsOr)
    return constOp->emitOpError(elementsOr.getError());

  TypedValue<MO::TensorType> opResult = constOp.getResult();
  TypedValue<MEF::ChainType> chain = loweringState.getExecuteChain();

  Value hostBuffer = opLoweringState.hostBufferConstant(chain, *elementsOr,
                                                        opResult.getType());
  return constHostBufferToTarget(opLoweringState, loweringState, hostBuffer,
                                 chain, opResult);
}

LogicalResult MOGraphLowering::lower(MO::ConstantExternalOp constExternalOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, constExternalOp);
  OpBuilder &builder = opLoweringState.builder;
  Location loc = constExternalOp.getLoc();

  TypedValue<MEF::ChainType> chain = loweringState.getExecuteChain();
  TypedValue<MO::TensorType> opResult = constExternalOp.getResult();
  uint64_t sizeInBytes = opResult.getType().getDtype().getSizeInBytes() *
                         (*opResult.getType().getNumElements());
  uint64_t alignment = constExternalOp.getAlign();
  bool hasAlias = constExternalOp.getHasAlias();
  bool isPlaceholder = constExternalOp.getIsPlaceholder();

  auto mojoStringType = MGP::OpaqueType::get(
      builder.getContext(), builder.getStringAttr("mojo_string"), {});
  auto name = MGP::StringCreateOp::create(
      builder, loc, mojoStringType,
      builder.getStringAttr(constExternalOp.getName()));

  DeviceRefAttr opDevice = constExternalOp.getExecutionDevice();
  opDevice =
      opDevice ? opDevice : DeviceRefAttr::getDefault(chain.getContext());
  if (opDevice.getLabel() == kCPULabel) {
    // Lowered like mo.constant.
    Value hostBuffer = opLoweringState.hostBufferConstantExternal(
        chain, name, sizeInBytes, alignment, hasAlias, isPlaceholder);

    return constHostBufferToTarget(opLoweringState, loweringState, hostBuffer,
                                   chain, opResult, alignment);
  }

  // A device external constant stays on device, with no copy.
  DeviceRefAttr resultDevice = MO::getDeviceOrDefault(opResult.getType());
  if (resultDevice != opDevice)
    return constExternalOp->emitOpError(
        Twine("expected op device ") + opDevice.getLabel() +
        " and result device " + resultDevice.getLabel() + " to match");

  Value deviceBuffer = opLoweringState.deviceBufferConstantExternal(
      opDevice, chain, name, sizeInBytes, alignment, hasAlias, isPlaceholder);

  MO::TensorType moTensorType = opResult.getType();
  FailureOr<TypedValue<MGP::TensorSpecType>> tensorSpecOr =
      opLoweringState.createTensorSpec(moTensorType);
  if (failed(tensorSpecOr))
    return failure();
  TypedValue<MGP::TensorSpecType> tensorSpec = *tensorSpecOr;

  opLoweringState.createOutputTensor(opResult, chain, deviceBuffer, tensorSpec);

  return success();
}

LogicalResult MOGraphLowering::lower(MO::ConstantScalarOp constOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, constOp);

  // currently only si32, si64, and i1 constants are supported
  if (auto boolAttr = dyn_cast<mlir::BoolAttr>(constOp.getValue())) {
    IntegerAttr intAttr = boolAttr;
    auto grtConstOp =
        opLoweringState.create<GRT::ConstantI1Op>(intAttr.getType(), intAttr);
    loweringState.emplaceExecuteLoweredValue(constOp, grtConstOp);

  } else if (auto intAttr = dyn_cast<mlir::IntegerAttr>(constOp.getValue())) {
    if (intAttr.getType().isSignedInteger(32)) {
      auto grtConstOp = opLoweringState.create<GRT::ConstantSI32Op>(
          intAttr.getType(), intAttr);
      loweringState.emplaceExecuteLoweredValue(constOp, grtConstOp);
    } else if (intAttr.getType().isSignedInteger(64)) {
      auto mipConstOp =
          opLoweringState.create<mlir::index::ConstantOp>(intAttr.getSInt());
      loweringState.emplaceExecuteLoweredValue(constOp, mipConstOp);
    }
  } else {
    return constOp->emitOpError(
        "Only si32, si64 and i1 constant scalar are currently lowerable");
  }

  return success();
}

static LogicalResult lowerReshapeImpl(MGP::MOOpLoweringState &opLoweringState,
                                      Value input, Value output, Value chain,
                                      MO::TensorType outputType) {
  MGP::BufferizedTensor bufferizedInput =
      opLoweringState.getBufferizedInput(input);
  Value buffer = bufferizedInput.buffer;

  FailureOr<TypedValue<MGP::TensorSpecType>> tensorSpecOr =
      opLoweringState.createTensorSpec(outputType);
  if (failed(tensorSpecOr))
    return failure();

  // The input chain also guards the users of the reshaped buffer.
  Value inChain = opLoweringState.getGuardChain(chain);

  opLoweringState.createOutputTensor(output, inChain, buffer, *tensorSpecOr);

  return success();
}

static LogicalResult lowerMoggSliceImpl(MGP::MOOpLoweringState &opLoweringState,
                                        MOGG::SliceOp sliceOp, Value chain) {
  MO::TensorType outputType = sliceOp.getType();

  FailureOr<TypedValue<MGP::TensorSpecType>> outputSpecOr =
      opLoweringState.createTensorSpec(outputType);
  if (failed(outputSpecOr))
    return failure();

  Value loweredInput = opLoweringState.loweringState.lookupExecuteLoweredValue(
      sliceOp.getInput());
  Value loweredStart = opLoweringState.loweringState.lookupExecuteLoweredValue(
      sliceOp.getStart());

  // The Mojo primitive computes the sliced dimension, stride, and start offset
  // at runtime.
  auto inputDevice =
      cast<MGP::DeviceTensorType>(loweredInput.getType()).getDevice();
  TypedValue<MGP::DeviceContextType> deviceContext =
      opLoweringState.loweringState.getExecuteDevice(inputDevice);
  Value slicedTensor = opLoweringState.create<MGP::TensorSliceOp>(
      loweredInput, *outputSpecOr, loweredStart, deviceContext);

  Value inChain = opLoweringState.getGuardChain(chain);
  opLoweringState.loweringState.emplaceExecuteLoweredBufferValue(
      sliceOp.getResult(), slicedTensor, inChain);

  return success();
}

LogicalResult MOGraphLowering::lower(MO::DebugPrintOp printOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, printOp);

  OpBuilder b(printOp);

  DeviceRefAttr targetDevice = printOp.getExecutionDevice();
  DeviceRefAttr hostDevice = loweringState.getHostDevice();

  auto chain = opLoweringState.getGuardChain(
      loweringState.lookupExecuteLoweredValue(printOp.getInChain()));

  auto outChain =
      cast<TypedValue<MEF::ChainType>>(opLoweringState.hostDebugPrint(
          chain, printOp.getValueAttr(), printOp.getLabelAttr()));

  chain = opLoweringState.sync(chain);

  if (targetDevice != hostDevice)
    chain = opLoweringState.sync(chain);

  loweringState.setCurrentExecuteChain(
      cast<TypedValue<MEF::ChainType>>(outChain));

  loweringState.emplaceExecuteLoweredValue(printOp.getOutChain(), outChain);
  return success();
}

LogicalResult MOGraphLowering::lower(MO::DebugTensorPrintOp printOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, printOp);

  OpBuilder b(printOp);
  auto moTensorType = printOp.getInput().getType();
  DeviceRefAttr targetDevice = MO::getDeviceOrDefault(moTensorType);
  DeviceRefAttr hostDevice = loweringState.getHostDevice();

  MGP::BufferizedTensor bufferizedInput =
      opLoweringState.getBufferizedInput(printOp.getInput());

  auto &buffer = bufferizedInput.buffer;
  auto &tensorSpec = bufferizedInput.tensorSpec;
  auto chain = opLoweringState.getGuardChain(
      loweringState.lookupExecuteLoweredValue(printOp.getInChain()));

  if (printOp.getLabelAttr().empty() || targetDevice == hostDevice) {
    auto outChain = opLoweringState.debugTensorPrint(
        chain, buffer, tensorSpec, printOp.getLabelAttr(),
        printOp.getInput().getType());
    loweringState.setCurrentExecuteChain(
        cast<TypedValue<MEF::ChainType>>(outChain));

    loweringState.emplaceExecuteLoweredValue(printOp.getOutChain(), outChain);
    return success();
  }

  // Off host, copy DtoH and print on the host, as the device primitive does.
  auto maybeTensorSizeInBytes = tensorSpec.getType().getSizeInBytes();
  Value bufferSize;
  if (maybeTensorSizeInBytes.has_value())
    bufferSize = opLoweringState.create<mlir::index::ConstantOp>(
        *maybeTensorSizeInBytes);
  else
    bufferSize = opLoweringState.bufferSizeBytes(tensorSpec, moTensorType);
  Value hostBuffer = opLoweringState.hostBufferAlloc(
      cast<TypedValue<MEF::ChainType>>(chain), bufferSize,
      M::Driver::getPreferredAlignment(hostDevice.getLabel().str()));
  auto transferChain = opLoweringState.bufferTransferToHost(
      chain, buffer, cast<TypedValue<MGP::DeviceBufferType>>(hostBuffer),
      moTensorType);
  auto outChain = opLoweringState.hostDebugTensorPrint(
      transferChain, hostBuffer, tensorSpec, printOp.getLabelAttr());
  loweringState.setCurrentExecuteChain(
      cast<TypedValue<MEF::ChainType>>(outChain));
  loweringState.emplaceExecuteLoweredValue(printOp.getOutChain(), outChain);
  return success();
}

// Returns null for an unsupported device pair.
static Value lowerTransferImpl(MGP::MOOpLoweringState &opLoweringState,
                               DeviceRefAttr hostDevice,
                               MGP::BufferizedTensor &srcBuffer,
                               Value dstBuffer, MO::TensorType srcType,
                               MO::TensorType dstType, Value inChain) {
  DeviceRefAttr srcDevice = srcType.getDeviceRef();
  DeviceRefAttr dstDevice = dstType.getDeviceRef();

  if (srcDevice == hostDevice) {
    return opLoweringState.bufferTransferFromHost(
        inChain, cast<TypedValue<MGP::DeviceBufferType>>(srcBuffer.buffer),
        dstBuffer, dstType);
  }

  if (dstDevice == hostDevice) {
    return opLoweringState.bufferTransferToHost(
        inChain, srcBuffer.buffer,
        cast<TypedValue<MGP::DeviceBufferType>>(dstBuffer), srcType);
  }

  if (srcDevice.getLabel() == dstDevice.getLabel()) {
    return opLoweringState.bufferTransferDevice(inChain, srcBuffer.buffer,
                                                dstBuffer, srcType, dstType);
  }

  return nullptr;
}

LogicalResult MOGraphLowering::lower(MO::TransferOp transferOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, transferOp);

  auto srcType = transferOp.getInput().getType();
  auto dstType = transferOp.getResult().getType();
  if (!srcType.getDeviceRef() || !dstType.getDeviceRef())
    return transferOp->emitOpError(
        "should have explicit devices before lowering");

  MGP::BufferizedTensor bufferizedInput =
      opLoweringState.getBufferizedInput(transferOp.getInput());

  Value inChain =
      loweringState.lookupExecuteLoweredValue(transferOp.getInChain());
  inChain = opLoweringState.getGuardChain(inChain);

  FailureOr<SmallVector<MGP::MOOutputStorage>> loweredOutputsStorageOr =
      opLoweringState.createOutputStorage(inChain,
                                          {bufferizedInput.tensorSpec});
  if (failed(loweredOutputsStorageOr))
    return failure();
  auto &loweredOutputsStorage = *loweredOutputsStorageOr;

  Value outChain = lowerTransferImpl(
      opLoweringState, loweringState.getHostDevice(), bufferizedInput,
      loweredOutputsStorage[0].buffer, srcType, dstType, inChain);

  if (!outChain)
    return transferOp->emitOpError("mo.transfer from device '")
           << srcType.getDeviceRef() << "' to device '"
           << dstType.getDeviceRef() << "' is not supported.";

  opLoweringState.createOutputs(outChain, loweredOutputsStorage);

  loweringState.emplaceExecuteLoweredValue(transferOp.getOutChain(), outChain);

  return success();
}

LogicalResult MOGraphLowering::lower(MO::StableCreateOp stableOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, stableOp);

  MO::TensorValue input = stableOp.getInput();
  Value loweredInput = loweringState.lookupExecuteLoweredValue(input);
  ASSERT_STREAM(loweredInput, << "stable.create input not lowered before use");

  // The MGP operation takes the dynamic dimensions as inputs. Extract them from
  // the lowered shape attribute.
  ErrorOr<SmallVector<Value>> runtimeDimsOr =
      loweringState.lowerShapeAttrDynDims(stableOp->getParentRegion(),
                                          input.getType().getShape(),
                                          stableOp.getLoc());
  if (runtimeDimsOr.isError())
    return stableOp.emitOpError(runtimeDimsOr.getError());

  auto stable = opLoweringState.create<MGP::DeviceGraphStableCreateOp>(
      loweredInput, *runtimeDimsOr);

  loweringState.emplaceExecuteLoweredValue(stableOp.getResult(), stable);
  return success();
}

LogicalResult MOGraphLowering::lower(MO::BufferTransferOp transferOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, transferOp);

  auto srcType = MO::castFromTensorLike(transferOp.getSrc().getType());
  auto dstType = MO::castFromTensorLike(transferOp.getDst().getType());
  if (!srcType.getDeviceRef() || !dstType.getDeviceRef())
    return transferOp->emitOpError(
        "should have explicit devices before lowering");

  MGP::BufferizedTensor bufferizedInput =
      opLoweringState.getBufferizedInput(transferOp.getSrc());
  MGP::BufferizedTensor bufferizedOutput =
      opLoweringState.getBufferizedInput(transferOp.getDst());

  auto inChain =
      loweringState.lookupExecuteLoweredValue(transferOp.getInChain());
  inChain = opLoweringState.getGuardChain(inChain);

  Value outChain = lowerTransferImpl(
      opLoweringState, loweringState.getHostDevice(), bufferizedInput,
      bufferizedOutput.buffer, srcType, dstType, inChain);

  if (!outChain)
    return transferOp->emitOpError("mo.buffer.transfer from device '")
           << srcType.getDeviceRef() << "' to device '"
           << dstType.getDeviceRef() << "' is not supported.";

  loweringState.emplaceExecuteLoweredValue(transferOp.getOutChain(), outChain);
  return success();
}

LogicalResult MOGraphLowering::lower(MO::GuardOp guardOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, guardOp);

  Value loweredChain =
      loweringState.lookupExecuteLoweredValue(guardOp.getChain());

  SmallVector<Value> loweredInputs;

  for (Value val : guardOp.getInputs()) {
    Value loweredInput = loweringState.lookupExecuteLoweredValue(val);
    loweredInputs.push_back(loweredInput);
  }

  auto mgpGuardOp =
      opLoweringState.create<MGP::GuardOp>(loweredChain, loweredInputs);

  for (auto &&[origRes, loweredRes] :
       llvm::zip(guardOp.getResults(), mgpGuardOp.getResults())) {
    loweringState.emplaceExecuteLoweredValue(origRes, loweredRes);
  }

  return success();
}

LogicalResult MOGraphLowering::lower(MO::ChainCreateOp chainCreateOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, chainCreateOp);

  SmallVector<Value> loweredOperands;

  for (Value val : chainCreateOp.getOperands()) {
    Value loweredOperand = loweringState.lookupExecuteLoweredValue(val);
    loweredOperands.push_back(loweredOperand);
  }

  auto grtChainCreateOp =
      opLoweringState.create<GRT::ChainCreateOp>(loweredOperands);

  loweringState.emplaceExecuteLoweredValue(chainCreateOp.getResult(),
                                           grtChainCreateOp.getResult());

  return success();
}

LogicalResult MOGraphLowering::lower(MO::MutableStoreOp mutableStoreOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, mutableStoreOp);

  MO::TensorType srcType = mutableStoreOp.getInTensor().getType();
  MO::TensorType dstType =
      MO::castFromTensorLike(mutableStoreOp.getInBuffer().getType());

  auto srcBufferized =
      opLoweringState.getBufferizedInput(mutableStoreOp.getInTensor());
  auto dstBufferized =
      opLoweringState.getBufferizedInput(mutableStoreOp.getInBuffer());

  auto inChain =
      loweringState.lookupExecuteLoweredValue(mutableStoreOp.getInChain());
  inChain = opLoweringState.getGuardChain(inChain);

  auto loweredChain = opLoweringState.bufferTransferDevice(
      inChain, srcBufferized.buffer, dstBufferized.buffer, srcType, dstType);

  loweringState.emplaceExecuteLoweredValue(mutableStoreOp.getResult(),
                                           loweredChain);

  return success();
}

/// The little-endian bit pattern of a scalar `initValue`, zero-extended to 64
/// bits, for mgp.buffer.memset's `valueBits`. Accepts a single-element
/// elements attribute (as the Python API emits) or a scalar integer/bool/float.
static FailureOr<uint64_t> initValueBits(Attribute initValue) {
  // `M::ArrayElementsAttr` only iterates as `Attribute`.
  if (auto elts = dyn_cast<ElementsAttr>(initValue)) {
    if (elts.getNumElements() != 1)
      return failure();
    initValue = *elts.value_begin<Attribute>();
  }
  // Also covers BoolAttr.
  if (auto intAttr = dyn_cast<IntegerAttr>(initValue))
    return intAttr.getValue().zextOrTrunc(64).getZExtValue();
  if (auto floatAttr = dyn_cast<FloatAttr>(initValue))
    return floatAttr.getValue().bitcastToAPInt().zextOrTrunc(64).getZExtValue();
  return failure();
}

LogicalResult MOGraphLowering::lower(MO::BufferCreateOp bufferCreateOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, bufferCreateOp);

  Type resultType = bufferCreateOp.getResult().getType();
  auto resTensorType = MO::castFromTensorLike(resultType);

  Attribute initValue = bufferCreateOp.getInitValueAttr();
  if (!initValue) {
    // Uninitialized per-call scratch buffer, allocated on every 'execute'.
    Value inChain = loweringState.getCurrentExecuteChain();
    inChain = opLoweringState.getGuardChain(inChain);

    auto tensorSpecOr = opLoweringState.createTensorSpec(resTensorType);
    if (failed(tensorSpecOr))
      return failure();

    auto bufferOr =
        opLoweringState.createBuffer(inChain, *tensorSpecOr, resultType);
    if (failed(bufferOr))
      return failure();

    opLoweringState.createOutputTensor(bufferCreateOp.getResult(), inChain,
                                       bufferOr->buffer, bufferOr->tensorSpec);

    return success();
  }

  // Persistent state buffer: allocated and filled with `initValue` once in
  // 'init', cached in the context, and retrieved on every 'execute' so kernel
  // mutations persist across calls. A single memset needs a static size.
  std::optional<int64_t> numElements = resTensorType.getNumElements();
  if (!numElements)
    return bufferCreateOp->emitOpError(
        "persistent buffer with an 'initValue' must have a statically known "
        "shape (dynamic dimensions are unsupported)");
  uint64_t sizeOfDtype = resTensorType.getDtype().getSizeInBytes();
  uint64_t sizeInBytes = sizeOfDtype * static_cast<uint64_t>(*numElements);

  FailureOr<uint64_t> valueBitsOr = initValueBits(initValue);
  if (failed(valueBitsOr))
    return bufferCreateOp->emitOpError(
        "unsupported 'initValue' attribute kind");
  uint64_t valueBits = *valueBitsOr;

  DeviceRefAttr device = MO::getDeviceOrDefault(resTensorType);
  MGP::MGPBufferBuilder &bufferBuilder = loweringState.getBufferBuilder(device);

  Location loc = bufferCreateOp.getLoc();

  //===--- Init region: alloc -> memset -> cache. ---===//
  OpBuilder &initBuilder = loweringState.getInitOpBuilder();
  TypedValue<MGP::ContextType> initContext =
      loweringState.getInitMgpContext().getResult();
  TypedValue<MGP::DeviceContextType> initDevCtx =
      loweringState.getInitDevice(device);
  auto initChain =
      cast<TypedValue<MEF::ChainType>>(loweringState.getInitChain());

  // Match the alignment logic in MOOpLoweringState::createBuffer.
  uint64_t alignment =
      M::Driver::getPreferredAlignment(device.getLabel().str());
  if (device.getLabel() == kCPULabel)
    alignment = std::gcd(alignment, opLoweringState.minimumCpuAlignment);

  Value sizeVal = mlir::index::ConstantOp::create(
      initBuilder, loc, static_cast<int64_t>(sizeInBytes));

  Value allocBuffer = bufferBuilder.bufferAlloc(
      initBuilder, loc, initContext, /*inChain=*/initChain, /*size=*/sizeVal,
      /*deviceContext=*/initDevCtx, alignment);

  auto memsetChain = MGP::BufferMemsetOp::create(
                         initBuilder, loc, /*inChain=*/initChain,
                         /*buffer=*/allocBuffer, /*deviceContext=*/initDevCtx,
                         /*valueBits=*/valueBits, /*elemSize=*/sizeOfDtype)
                         .getOutChain();

  auto [cacheChain, slot] = bufferBuilder.cache(
      initBuilder, loc, initContext, /*inChain=*/memsetChain,
      /*contextCreateOp=*/loweringState.getInitMgpContext(),
      /*buffer=*/allocBuffer);
  loweringState.setInitChain(cacheChain);

  //===--- Execute region: retrieve the cached buffer, build the tensor.
  //---===//
  OpBuilder &execBuilder = loweringState.getExecuteOpBuilder();
  Value execChain = loweringState.getCurrentExecuteChain();
  execChain = opLoweringState.getGuardChain(execChain);

  Value cachedBuffer = bufferBuilder.getCached(
      execBuilder, loc, /*context=*/loweringState.getExecuteMgpContext(),
      /*inChain=*/cast<TypedValue<MEF::ChainType>>(execChain), slot,
      /*expectedBufferType=*/allocBuffer.getType());

  auto tensorSpecOr = opLoweringState.createTensorSpec(resTensorType);
  if (failed(tensorSpecOr))
    return failure();

  opLoweringState.createOutputTensor(bufferCreateOp.getResult(), execChain,
                                     cachedBuffer, *tensorSpecOr);

  return success();
}

LogicalResult MOGraphLowering::lower(MO::MutableLoadOp mutableLoadOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, mutableLoadOp);

  auto inChain =
      loweringState.lookupExecuteLoweredValue(mutableLoadOp.getInChain());

  auto bufferizedInput =
      opLoweringState.getBufferizedInput(mutableLoadOp.getInBuffer());

  inChain = opLoweringState.getGuardChain(inChain);
  auto bufOr =
      opLoweringState.createBuffer(inChain, bufferizedInput.tensorSpec,
                                   mutableLoadOp.getOutTensor().getType());
  if (failed(bufOr))
    return failure();

  auto &outputStorage = *bufOr;

  auto loweredChain = opLoweringState.bufferTransferDevice(
      inChain, bufferizedInput.buffer, outputStorage.buffer,
      MO::castFromTensorLike(mutableLoadOp.getInBuffer().getType()),
      mutableLoadOp.getOutTensor().getType());

  opLoweringState.createOutputTensor(mutableLoadOp.getOutTensor(), loweredChain,
                                     outputStorage.buffer,
                                     outputStorage.tensorSpec);

  loweringState.emplaceExecuteLoweredValue(mutableLoadOp.getOutChain(),
                                           loweredChain);

  return success();
}

LogicalResult MOGraphLowering::lower(MO::IfOp ifOp) {
  ASSERT_STREAM(MO::isOnHost(ifOp), << "mo.if is for host only");
  MGP::MOOpLoweringState opLoweringState(loweringState, ifOp);

  // Thread the current 'execute' chain through both branches.
  Value currentChain = loweringState.getCurrentExecuteChain();
  currentChain = opLoweringState.getGuardChain(currentChain);

  Value cond = ifOp.getCond();

  bool isScalarCond = isa<MO::ScalarType>(cond.getType());

  Value condBool;
  if (isScalarCond) {
    condBool = loweringState.lookupExecuteLoweredValue(cond);
  } else {
    MGP::BufferizedTensor bufferizedCond =
        opLoweringState.getBufferizedInput(cond);
    condBool = opLoweringState.bufferToBool(currentChain, bufferizedCond.buffer,
                                            cond.getType());
  }

  SmallVector<Value> operands;
  operands.push_back(condBool);

  SmallVector<Type> resultTypes;
  // Always return the current 'execute' chain
  resultTypes.emplace_back(currentChain.getType());

  for (Type type : ifOp.getResultTypes())
    resultTypes.emplace_back(
        loweringState.getTypeConverter().convertType(type));

  for (ParamDeclAttr decl : ifOp.getOutputParamDecls()) {
    Type declType = decl.getType();
    Type converted = loweringState.getTypeConverter().convertType(declType);
    resultTypes.emplace_back(converted ? converted : declType);
  }

  auto outputIf = opLoweringState.create<GRT::IfOp>(resultTypes, operands);

  size_t paramStartIdx = 1 + ifOp.getNumResults(); // After chain + tensors
  for (auto [decl, result] :
       llvm::zip(ifOp.getOutputParamDecls(),
                 outputIf.getResults().drop_front(paramStartIdx))) {
    if (auto err =
            loweringState.lowerParamDecl(ifOp->getParentRegion(), decl, result))
      return ifOp->emitOpError(err.getError());
  }

  auto enterLowerBlock = [&](Region &inputRegion,
                             Region &outputRegion) -> LogicalResult {
    // Enter the lowered region's unique block.
    Block &newBlock = outputRegion.emplaceBlock();
    opLoweringState.builder.setInsertionPointToEnd(&newBlock);

    if (failed(lowerBlock(&inputRegion.getBlocks().front())))
      return failure();
    return success();
  };

  if (failed(enterLowerBlock(ifOp.getThenRegion(), outputIf.getThenRegion())))
    return failure();

  loweringState.setCurrentExecuteChain(currentChain);

  if (failed(enterLowerBlock(ifOp.getElseRegion(), outputIf.getElseRegion())))
    return failure();

  Value outChain = outputIf.getResult(0);

  loweringState.setCurrentExecuteChain(outChain);

  for (auto [origResult, loweredResult] :
       llvm::zip(ifOp.getResults(), llvm::drop_begin(outputIf.getResults()))) {

    if (isa<MGP::DeviceTensorType>(loweredResult.getType())) {
      loweringState.emplaceExecuteLoweredBufferValue(origResult, loweredResult,
                                                     outChain);
    } else {
      loweringState.emplaceExecuteLoweredValue(origResult, loweredResult);
    }
  }

  opLoweringState.builder.setInsertionPointAfter(outputIf);

  return success();
}

LogicalResult MOGraphLowering::lower(MO::WhileOp whileOp) {
  ASSERT_STREAM(MO::isOnHost(whileOp), << "mo.while is for host only");
  MGP::MOOpLoweringState opLoweringState(loweringState, whileOp);

  // Thread the current 'execute' chain through 'cond' and 'body'.
  Value rootChain = loweringState.getExecuteChain();
  Value currentChain = loweringState.getCurrentExecuteChain();
  bool currentIsRoot = currentChain == rootChain;
  currentChain = opLoweringState.getGuardChain(currentChain);

  // Collect the lowered form of all the outer SSA values which (may) appear
  // in the final grt.while 'cond' and 'body' blocks.
  SmallVector<Value> loweredFreeValues;
  loweredFreeValues.reserve(1 + whileOp.getInputs().size());
  loweredFreeValues.emplace_back(currentChain);
  for (Value value : whileOp.getInputs())
    loweredFreeValues.emplace_back(
        loweringState.lookupExecuteLoweredValue(value));

  SmallVector<Value> operands;
  operands.reserve(loweredFreeValues.size());
  SmallVector<Type> resultTypes;
  resultTypes.reserve(loweredFreeValues.size());
  for (Value loweredFreeValue : loweredFreeValues) {
    operands.emplace_back(loweredFreeValue);
    resultTypes.emplace_back(loweredFreeValue.getType());
  }
  auto loweredWhileOp =
      opLoweringState.create<GRT::WhileOp>(resultTypes, operands);

  auto enterLowerBlock = [&](Region &inputRegion,
                             Region &outputRegion) -> LogicalResult {
    // Enter the lowered region's unique block.
    Block &newBlock = outputRegion.emplaceBlock();
    opLoweringState.builder.setInsertionPointToEnd(&newBlock);

    // The current 'execute' chain comes first.
    auto loweredChainArg =
        outputRegion.addArgument(currentChain.getType(), whileOp.getLoc());
    loweringState.setCurrentExecuteChain(loweredChainArg);
    if (currentIsRoot)
      loweringState.setRootExecuteChain(loweredChainArg);
    // Otherwise fixupIsolatedFromAbove adds a root-chain argument if needed.

    // Then one arg per original region arg, typed like loweredFreeValues.
    for (auto [loweredFreeValue, arg] : llvm::zip(
             llvm::drop_begin(loweredFreeValues), inputRegion.getArguments())) {
      Value loweredArg =
          outputRegion.addArgument(loweredFreeValue.getType(), arg.getLoc());
      if (isa<MGP::DeviceTensorType>(loweredArg.getType())) {
        loweringState.emplaceExecuteLoweredBufferValue(arg, loweredArg,
                                                       loweredChainArg);
      } else {
        loweringState.emplaceExecuteLoweredValue(arg, loweredArg);
      }
    }

    if (failed(lowerBlock(&inputRegion.getBlocks().front())))
      return failure();

    return success();
  };

  // The lowered 'cond' mef.output is fixed up below: grt.while needs every
  // signature value plus an i1 condition, not a mgp.tensor<bool>.
  if (failed(enterLowerBlock(whileOp.getCondRegion(),
                             loweredWhileOp.getCondRegion())))
    return failure();

  if (failed(enterLowerBlock(whileOp.getBodyRegion(),
                             loweredWhileOp.getBodyRegion())))
    return failure();

  {
    MO::WhileConditionOp origYieldOp = whileOp.getCondTerminator();

    Value origTensor = origYieldOp.getCondition();
    Type condMoTensorType = origTensor.getType();

    MEF::OutputOp loweredCondOutputOp = loweredWhileOp.getCondTerminator();

    // At this point, the lowered OutputOp operands are the form:
    // 1. the execute chain
    // 2. the lowered condition tensor
    // 3. the lowered arguments of the mo.yield
    Value loweredOutputChain = loweredCondOutputOp->getOperand(0);
    Value loweredCondTensor = loweredCondOutputOp->getOperand(1);
    ValueRange loweredArgs = loweredCondOutputOp->getOperands().drop_front(2);

    SmallVector<Value> condOutputOpOperands;
    condOutputOpOperands.reserve(loweredWhileOp->getNumResults() + 1);

    condOutputOpOperands.push_back(loweredOutputChain);
    llvm::append_range(condOutputOpOperands, loweredArgs);

    // i1 condition
    opLoweringState.builder.setInsertionPoint(loweredCondOutputOp);
    Value condBuffer =
        opLoweringState.tensorExtract(loweredCondTensor, condMoTensorType)
            .first;

    Value chain = loweredOutputChain;
    if (Value guardChain =
            loweringState.getChainGuardingValueOrNull(origTensor)) {
      chain =
          GRT::ChainCreateOp::create(opLoweringState.builder, whileOp.getLoc(),
                                     ValueRange{guardChain, chain})
              .getResult();
    }
    Value condBool =
        opLoweringState.bufferToBool(chain, condBuffer, condMoTensorType);
    condOutputOpOperands.push_back(condBool);

    loweredCondOutputOp.getOperandsMutable().clear();
    loweredCondOutputOp.getOperandsMutable().append(condOutputOpOperands);
  }

  assert(loweredWhileOp.getNumResults() == 1 + whileOp.getNumResults());

  Value outChain = loweredWhileOp.getResult(0);

  loweringState.setCurrentExecuteChain(outChain);
  loweringState.setRootExecuteChain(rootChain);

  for (auto [origResult, loweredResult] :
       llvm::zip(whileOp.getResults(),
                 llvm::drop_begin(loweredWhileOp.getResults()))) {
    if (isa<MGP::DeviceTensorType>(loweredResult.getType())) {
      loweringState.emplaceExecuteLoweredBufferValue(origResult, loweredResult,
                                                     outChain);
    } else {
      loweringState.emplaceExecuteLoweredValue(origResult, loweredResult);
    }
  }

  opLoweringState.builder.setInsertionPointAfter(loweredWhileOp);

  return success();
}

// level-wise topological sort
static LogicalResult levelwiseTopologicalSort(Block *block) {
  llvm::iterator_range<Block::iterator> ops = *block;
  if (block->back().hasTrait<OpTrait::IsTerminator>())
    ops = block->without_terminator();

  if (ops.empty())
    return success();

  llvm::SmallVector<Operation *> allOps;
  llvm::DenseMap<Operation *, unsigned> inDegree;
  llvm::DenseMap<Operation *, llvm::SmallVector<Operation *>> dependents;

  for (Operation &op : ops) {
    allOps.push_back(&op);
    inDegree[&op] = 0;
  }

  for (Operation *op : allOps) {
    llvm::SetVector<Operation *> dependencies;

    // Walk through operands of all nested operations to find dependencies
    op->walk</*Order=*/mlir::WalkOrder::PreOrder>([&](Operation *nestedOp) {
      for (Value operand : nestedOp->getOperands()) {
        Operation *parent = operand.getDefiningOp();
        if (!parent)
          continue; // Block argument

        while (parent->getParentOp() &&
               parent->getParentOp() != block->getParentOp()) {
          parent = parent->getParentOp();
        }

        if (parent->getBlock() == block && parent != op) {
          dependencies.insert(parent);
        }
      }

      if (nestedOp->hasTrait<mlir::OpTrait::IsIsolatedFromAbove>())
        return WalkResult::skip();
      return WalkResult::advance();
    });

    for (Operation *dep : dependencies) {
      dependents[dep].push_back(op);
      inDegree[op]++;
    }
  }

  Block::iterator nextScheduledOp = block->begin();
  [[maybe_unused]] unsigned sortedOps = 0;

  llvm::SmallVector<Operation *> readyQueue;
  for (Operation *op : allOps) {
    if (inDegree[op] == 0) {
      readyQueue.push_back(op);
    }
  }

  while (!readyQueue.empty()) {
    llvm::SmallVector<Operation *> currentLevel = std::move(readyQueue);
    readyQueue.clear();

    for (Operation *op : currentLevel) {
      ++sortedOps;
      op->moveBefore(block, nextScheduledOp);

      if (op == &*nextScheduledOp) {
        ++nextScheduledOp;
      }

      for (Operation *dependent : dependents[op]) {
        inDegree[dependent]--;
        if (inDegree[dependent] == 0) {
          readyQueue.push_back(dependent);
        }
      }
    }
  }

  ASSERT_STREAM(sortedOps == allOps.size(),
                << "Failed to sort the MO operations topologically.");

  return success();
}

LogicalResult MOGraphLowering::lowerOp(Operation &op, Region *parentRegion) {
  if (llvm::isa_and_nonnull<mlir::index::IndexDialect>(op.getDialect()))
    return cloneTrivialOp(&op);

  // clang-format off
  return llvm::TypeSwitch<Operation *, LogicalResult>(&op)
      // Param ops need the enclosing region.
      .Case<KGEN::ParamDeclareOp, MOSH::ParamToValueOp,
            MOSH::ParamFromValueOp>(
          [this, parentRegion](auto op) { return lowerParam(parentRegion, op); })
      // Reshape/slice ops need a local MOOpLoweringState.
      .Case<MO::Static::ReshapeOp>([this](auto op) {
        MGP::MOOpLoweringState opLoweringState(loweringState, op);
        return lowerReshapeImpl(opLoweringState, op.getInput(), op.getResult(),
                                loweringState.getExecuteChain(), op.getType());
      })
      .Case<MOGG::SliceOp>([this](auto op) {
        MGP::MOOpLoweringState opLoweringState(loweringState, op);
        return lowerMoggSliceImpl(opLoweringState, op,
                                  loweringState.getExecuteChain());
      })
      // All other concrete op types dispatch to lower() overloads.
      .Case<MO::IndexToTensorOp, MO::Shape::ToTensorOp,
            MO::Shape::FromTensorOp, MO::RebindOp, MO::ConstantOp,
            MO::ConstantExternalOp, MO::ConstantScalarOp, MO::DebugPrintOp,
            MO::DebugTensorPrintOp, MO::TransferOp, MO::StableCreateOp,
            MO::OutputOp, MO::IfOp, MO::WhileOp, MO::TensorBundleOp,
            MO::TensorUnbundleOp, MO::ParallelOp, MO::SequenceOp, MO::YieldOp,
            MO::WhileConditionOp, MO::GuardOp, MO::ChainCreateOp,
            MO::MutableStoreOp, MO::MutableLoadOp, MO::BufferCreateOp,
            MO::BufferTransferOp, MO::CallOp>(
          [this](auto op) { return lower(op); })
      // Externally-defined ops, e.g. `mogg.routine`.
      .Case<MGP::LowerableToMGPInterface>(
          [this](auto op) { return lowerInterface(op); })
      .Default([](Operation *op) -> LogicalResult {
        return op->emitOpError("currently not supported");
      });
  // clang-format on
}

LogicalResult MOGraphLowering::lowerBlock(Block *block) {
  if (failed(levelwiseTopologicalSort(block)))
    return failure();

  for (Operation &op : *block) {
    if (failed(lowerOp(op, block->getParent())))
      return failure();
  }
  return success();
}

LogicalResult MOGraphLowering::lower(MO::SequenceOp seq) {
  // Lower mo.sequence by inlining its body into the execute block, bound to a
  // per-device side-stream view of the device context. The region was a fusion
  // boundary (enforced at the MOGG stage) and a marker for which ops get the
  // side stream. Cross-stream ordering is expressed purely through buffer/
  // tensor guard chains -- never the running execute chain: the fork gates on
  // the guard chains of the body's inputs (chain-guarded captures are promoted
  // to inputs first), and the body's outputs are re-guarded on the join chain
  // so downstream consumers wait for the side stream.
  OpBuilder &b = loweringState.getExecuteOpBuilder();
  Location loc = seq.getLoc();
  Block &body = seq.getBodyRegion().front();
  Value execContext = loweringState.getExecuteMgpContext();
  Value rootChain = loweringState.getExecuteChain();

  // Combine guard chains (dropping nulls); the root chain stands in for "ready
  // immediately" when there are no producers (e.g. model inputs).
  auto combineChains = [&](ArrayRef<Value> chains) -> Value {
    SmallVector<Value> nonNull;
    for (Value c : chains)
      if (c)
        nonNull.push_back(c);
    if (nonNull.empty())
      return rootChain;
    if (nonNull.size() == 1)
      return nonNull.front();
    return GRT::ChainCreateOp::create(b, loc, nonNull).getResult();
  };
  // Device of a value, or null for non-tensor (e.g. chain) values: those carry
  // no device and must not fabricate a default one.
  auto deviceOf = [](Value v) -> DeviceRefAttr {
    if (auto devTy = dyn_cast<MO::MOHasDeviceTypeInterface>(v.getType()))
      return MO::getDeviceOrDefault(devTy);
    return {};
  };
  // A value may be guarded under its MO key or its lowered key (see
  // lower(MO::TensorUnbundleOp)).
  auto guardOf = [&](Value moVal) -> Value {
    if (Value g = loweringState.getChainGuardingValueOrNull(moVal))
      return g;
    if (Value lowered = loweringState.lookupExecuteLoweredValue(moVal))
      return loweringState.getChainGuardingValueOrNull(lowered);
    return {};
  };

  // Collect the unique accelerator devices the body touches. A replicated body
  // (e.g. the EP shared expert) spans every device, one side-stream view each.
  // streamId 0 (default stream) or a host-only body adds no binding.
  uint64_t streamId = seq.getStreamId();
  SmallVector<DeviceRefAttr> devices;
  auto addDevice = [&](Value v) {
    DeviceRefAttr dev = deviceOf(v);
    if (dev && !MO::isOnHost(v.getType()) && !llvm::is_contained(devices, dev))
      devices.push_back(dev);
  };
  for (Value in : seq.getInputs())
    addDevice(in);
  for (Value res : seq.getResults())
    addDevice(res);
  const bool bindStream = streamId != 0 && !devices.empty();

  // mo.sequence is not IsolatedFromAbove so the body can read constants and
  // weights directly. A capture with a producer chain is promoted to a block
  // argument so it is fork-guarded like a listed input.
  SmallVector<Value> inputs(seq.getInputs());
  llvm::SetVector<Value> captured;
  mlir::getUsedValuesDefinedAbove(seq.getBodyRegion(), captured);
  for (Value cap : captured) {
    if (!guardOf(cap))
      continue;
    BlockArgument arg = body.addArgument(cap.getType(), cap.getLoc());
    cap.replaceUsesWithIf(arg, [&](OpOperand &use) {
      return seq.getBodyRegion().isAncestor(use.getOwner()->getParentRegion());
    });
    inputs.push_back(cap);
  }

  // Fork: per device, create the side-stream view and a device_wait that makes
  // the side stream wait for the base-stream producers of that device's inputs.
  llvm::SmallDenseMap<DeviceRefAttr, TypedValue<MGP::DeviceContextType>>
      viewFor;
  llvm::SmallDenseMap<DeviceRefAttr, Value> forkChainFor;
  if (bindStream) {
    for (DeviceRefAttr dev : devices) {
      TypedValue<MGP::DeviceContextType> base =
          loweringState.getExecuteDevice(dev);
      auto view =
          MGP::DeviceContextSelectStreamOp::create(b, loc, base, streamId);
      viewFor[dev] = view;
      SmallVector<Value> inGuards;
      for (Value in : inputs)
        if (deviceOf(in) == dev)
          inGuards.push_back(guardOf(in));
      forkChainFor[dev] =
          MGP::DeviceWaitOp::create(b, loc, /*inChain=*/combineChains(inGuards),
                                    execContext, /*waitingDeviceContext=*/view,
                                    /*signalingDeviceContext=*/base,
                                    /*bDevice=*/dev)
              .getResult();
      loweringState.setExecuteDeviceOverride(dev, view);
    }
  }

  // Guard each body block argument (not the shared input, so unrelated
  // main-stream consumers are not serialized) on its device's fork chain. A
  // device with no fork keeps producer ordering.
  for (auto [arg, operand] : llvm::zip_equal(body.getArguments(), inputs)) {
    loweringState.emplaceExecuteLoweredValue(
        arg, loweringState.lookupExecuteLoweredValue(operand));
    Value guard = bindStream ? forkChainFor.lookup(deviceOf(operand)) : Value();
    if (!guard)
      guard = guardOf(operand);
    if (guard)
      loweringState.replaceChainGuard(arg, guard);
  }

  // Lower the body ops (excluding the yield terminator) in place; with the
  // overrides installed, getExecuteDevice routes them onto the side streams.
  if (failed(levelwiseTopologicalSort(&body)))
    return failure();
  for (Operation &op : body.without_terminator())
    if (failed(lowerOp(op, &seq.getBodyRegion())))
      return failure();

  // Join: per device, a device_wait that makes the base stream wait for the
  // side stream, gated on the guard chains of that device's body outputs.
  // deferSideStreamJoins later moves it to the first consumer of the results.
  auto yieldOp = cast<MO::YieldOp>(body.getTerminator());
  llvm::SmallDenseMap<DeviceRefAttr, Value> joinChainFor;
  if (bindStream) {
    for (DeviceRefAttr dev : devices)
      loweringState.clearExecuteDeviceOverride(dev);
    for (DeviceRefAttr dev : devices) {
      TypedValue<MGP::DeviceContextType> base =
          loweringState.getExecuteDevice(dev);
      SmallVector<Value> outGuards;
      for (Value out : yieldOp.getOperands())
        if (deviceOf(out) == dev)
          outGuards.push_back(guardOf(out));
      auto join = MGP::DeviceWaitOp::create(
          b, loc, /*inChain=*/combineChains(outGuards), execContext,
          /*waitingDeviceContext=*/base,
          /*signalingDeviceContext=*/viewFor[dev], /*bDevice=*/dev);
      join.setIsSideStreamJoin(true);
      joinChainFor[dev] = join.getResult();

      // A freed buffer goes back to its owner stream's free list, which hands
      // it out again right away without knowing the side stream still reads
      // it. Hold this device's inputs until the join has queued the base
      // stream's wait on the side stream.
      SmallVector<Value> held;
      for (Value in : inputs)
        if (deviceOf(in) == dev)
          if (Value lowered = loweringState.lookupExecuteLoweredValue(in)) {
            if (auto view = lowered.getDefiningOp<MGP::TensorCreateOp>())
              lowered = view.getBuffer();
            held.push_back(lowered);
          }
      if (!held.empty())
        MGP::ExtendLifetimeOp::create(b, loc, joinChainFor[dev], held);
    }
  }

  // Map each result to its lowered yield value and guard the result on the
  // device's join chain, so downstream consumers wait for the side stream.
  for (auto [res, yielded] :
       llvm::zip_equal(seq.getResults(), yieldOp.getOperands())) {
    loweringState.emplaceExecuteLoweredValue(
        res, loweringState.lookupExecuteLoweredValue(yielded));
    Value guard =
        bindStream ? joinChainFor.lookup(deviceOf(res)) : guardOf(yielded);
    if (guard)
      loweringState.replaceChainGuard(res, guard);
  }

  return success();
}

LogicalResult MOGraphLowering::run() {
  MO::GraphOp &graph = loweringState.getGraph();

  if (failed(createModelOp()))
    return failure();

  for (auto [graphArg, exeArg] :
       llvm::zip(graph.getBody().front().getArguments(),
                 loweringState.getModelOp().getExecuteInputs())) {
    auto loweringResult =
        loweringState.lowerArg(&graph.getRegion(), graphArg, exeArg);
    if (loweringResult.isError())
      return graph->emitOpError(loweringResult.getError());

    if (!loweringResult->hasParameters && graphArg.use_empty())
      continue;

    loweringState.emplaceExecuteLoweredValue(graphArg,
                                             loweringResult->loweredArg);
  }

  if (failed(lowerBlock(graph.getBodyBlock())))
    return failure();

  OpBuilder b(graph);
  MGP::ModelOp model = loweringState.getModelOp();

  // Binds free variables in grt.if/grt.while and adds a new model to the
  // module, replacing this one.
  (void)MGP::fixupIsolatedFromAbove(b, model);
  model.erase();
  graph.erase();

  return success();
}

/// Fuse a set of synchronous compiled regions into one, then convert the
/// synchronous call stubs to async dispatch with a join barrier.
///
/// After this function:
///   - The fused region contains CallStubAsyncOps, an AsyncJoinOp, and a
///     single AsyncReadyOp producing the output chain.
///   - The original regions in `groupRegions` have been erased.
///   - The fused region is inserted after `groupRegions.back()`.
static MOGG::AsyncRoutineOp
fuseAndConvertToAsync(mlir::MLIRContext *ctx, Location loc,
                      ArrayRef<Operation *> groupRegions) {
  MOGG::AsyncRoutineOp fusedRegion = MOGG::fuseAndReplaceCompiledRegions(
      /*allowDuplication=*/false, groupRegions);

  // fuseAndReplaceCompiledRegions leaves InOutSignatureAttr empty because it
  // normally runs after ABI lowering. We call it earlier, so downstream passes
  // still need a valid signature.
  SmallVector<InOutSignatureAttr::InOutSemantics> sig(
      fusedRegion->getNumOperands(), InOutSignatureAttr::kNone);
  fusedRegion.setInOutSignatureAttr(InOutSignatureAttr::get(ctx, sig));

  // Forward the affinity device ordinal (set only on GPU launches) so the
  // emitter can choose an affinity-aware create_task.
  Block &body = fusedRegion.getBody().front();
  SmallVector<Value> taskHandles;
  body.walk([&](MOGG::CallOp callStub) {
    OpBuilder b(ctx);
    b.setInsertionPoint(callStub);
    MOGG::CallAsyncOp asyncCall = MOGG::CallAsyncOp::create(
        b, callStub.getLoc(), callStub.getName(), callStub.getInputs(),
        callStub.getAffinityDeviceIdAttr());
    taskHandles.push_back(asyncCall.getTaskHandle());
    callStub.erase();
  });

  Operation *outputOp = body.getTerminator();
  OpBuilder b(ctx);
  b.setInsertionPoint(outputOp);
  MOGG::AsyncJoinOp::create(b, loc, taskHandles);

  // Fusion cloned one AsyncReadyOp per original region. The first one (which
  // fuseAndReplaceCompiledRegions wired into the OutputOp) is the canonical
  // chain; erase the rest and move the survivor after the join.
  MOGG::AsyncReadyOp canonical;
  body.walk([&](MOGG::AsyncReadyOp readyOp) {
    if (!canonical) {
      canonical = readyOp;
      return;
    }
    readyOp.getResult().replaceAllUsesWith(canonical.getResult());
    readyOp.erase();
  });
  ASSERT_STREAM(canonical, << "expected at least one AsyncReadyOp in fused "
                              "parallel region body");
  canonical->moveBefore(outputOp);

  for (Operation *region : groupRegions)
    region->erase();

  return fusedRegion;
}

LogicalResult MOGraphLowering::lower(MO::ParallelOp parallelOp) {
  mlir::MLIRContext *ctx = parallelOp->getContext();
  Location loc = parallelOp.getLoc();

  Block &bodyBlock = parallelOp.getBodyRegion().front();
  size_t numLaunches = parallelOp.getNumLaunches();
  size_t numBundleGroups = parallelOp.getInputs().size();

  // The parallel op threads its chain explicitly: the in-chain enters the body
  // through a trailing block argument, the body's buffer ops thread it, and the
  // result is yielded as the terminator's last operand and becomes the op's
  // out-chain. The lowering is a pass-through: it maps the chain block arg to
  // the lowered in-chain and the out-chain to the lowered yielded chain.

  // Per-launch MO-level values of each bundle input, from
  // lower(TensorBundleOp).
  size_t numGroups = numBundleGroups;
  SmallVector<SmallVector<Value>> bundleElements(numGroups);

  for (size_t group = 0; group < numBundleGroups; ++group) {
    Value bundleVal = parallelOp.getInputs()[group];
    auto moElements = loweringState.lookupBundleElements(bundleVal);
    for (size_t launch = 0; launch < numLaunches; ++launch)
      bundleElements[group].push_back(moElements[launch]);
  }

  // Only kernels and bundled.expand should remain by now; the verifier's other
  // transient ops (see ParallelOp::verify) mean a missing cleanup.
  SmallVector<Operation *> kernelOps;
  SmallVector<MO::BundledExpandOp> expandOps;
  for (Operation &op : bodyBlock.without_terminator()) {
    if (isa<MOGG::RoutineOp>(&op)) {
      kernelOps.push_back(&op);
    } else if (auto expand = dyn_cast<MO::BundledExpandOp>(&op)) {
      expandOps.push_back(expand);
    } else {
      return op.emitOpError()
             << "lowering of this op inside mo.parallel is not yet "
                "supported; see GEX-3701";
    }
  }
  if (kernelOps.empty())
    return parallelOp.emitOpError("body must contain at least one kernel");

  // Each kernel is cloned per launch, lowered via
  // `RoutineOp::lowerToAsync`, then fused and made async. Fusion is per
  // kernel group, since a later group's buffer allocs may depend on an earlier
  // group's chain. Bundled kernels (collectives) are N-expanded so each clone
  // sees every launch's inputs.
  //
  // perLaunchCloneResults maps each body result to its per-launch clone
  // results for later clones' IRMapping; clones stay alive until all kernels
  // are processed.
  DenseMap<Value, SmallVector<Value>> perLaunchCloneResults;
  SmallVector<Operation *> allClones;

  // A chained parallel's in-chain is the body's trailing block argument.
  Value loweredInChain;
  if (parallelOp.hasChain()) {
    loweredInChain =
        loweringState.lookupExecuteLoweredValue(parallelOp.getInChain());
    ASSERT_STREAM(loweredInChain,
                  << "parallel in-chain not lowered before parallel op");
  }
  // Each kernel group's fused completion chain, keyed by the group's MO-level
  // result values, so the yielded out-chain can be resolved to it.
  DenseMap<Value, Value> resultToFusedChain;

  // Each mo.bundled.expand result maps to the per-launch elements of its
  // source bundle.
  for (MO::BundledExpandOp expandOp : expandOps) {
    Value input = expandOp.getInput();
    for (size_t group = 0; group < numBundleGroups; ++group) {
      if (input != bodyBlock.getArgument(group))
        continue;
      for (size_t i = 0; i < expandOp.getNumResults(); ++i) {
        SmallVector<Value> &cloneResults =
            perLaunchCloneResults[expandOp.getResult(i)];
        cloneResults.resize(numLaunches);
        // Expand result i always resolves to launch i's value, regardless
        // of which per-launch clone is being built.
        for (size_t launch = 0; launch < numLaunches; ++launch)
          cloneResults[launch] = bundleElements[group][i];
      }
      break;
    }
  }

  for (Operation *kernelOp : kernelOps) {
    SmallVector<Operation *> kernelClones;
    SmallVector<Operation *> groupRegions;

    for (size_t launch = 0; launch < numLaunches; ++launch) {
      IRMapping mapper;
      for (size_t group = 0; group < numGroups; ++group)
        mapper.map(bodyBlock.getArgument(group), bundleElements[group][launch]);
      // Mapped to the MO-level in-chain; the compiled-region lowering
      // resolves its lowered value.
      if (parallelOp.hasChain())
        mapper.map(bodyBlock.getArgument(numBundleGroups),
                   parallelOp.getInChain());
      for (auto &[origResult, cloneResults] : perLaunchCloneResults)
        mapper.map(origResult, cloneResults[launch]);

      OpBuilder cloneBuilder(ctx);
      cloneBuilder.setInsertionPointAfter(parallelOp);
      Operation *clonedOp = cloneBuilder.clone(*kernelOp, mapper);

      // The body is typed for the first input's device; retarget the clone's
      // result types and device to this launch's device.
      DeviceRefAttr launchDevice = parallelOp.getLaunchDeviceList()[launch];
      const bool retarget = launchDevice != MO::getDeviceOrDefaultAny(clonedOp);
      for (OpResult result : clonedOp->getResults()) {
        if (auto resTy = dyn_cast<MO::TensorType>(result.getType()))
          if (resTy.getDeviceRef() != launchDevice)
            result.setType(resTy.cloneWith(launchDevice));
      }

      auto clonedKernel = cast<MOGG::RoutineOp>(clonedOp);
      if (retarget)
        clonedKernel.setDeviceRef(launchDevice);
      MOGG::AsyncRoutineOp launchRegion =
          clonedKernel.lowerToAsync(loweringState);
      if (!launchRegion)
        return failure();

      // Stamp the GPU device ordinal on each CallOp for
      // fuseAndConvertToAsync. A plain I64Attr, since kernel-layer device refs
      // are label-only.
      if (launchDevice && launchDevice.getLabel() == M::kGPULabel) {
        auto affinityId =
            mlir::IntegerAttr::get(mlir::IntegerType::get(ctx, 64),
                                   static_cast<int64_t>(launchDevice.getId()));
        launchRegion->walk([&](MOGG::CallOp callStub) {
          callStub.setAffinityDeviceIdAttr(affinityId);
        });
      }

      groupRegions.push_back(launchRegion);
      kernelClones.push_back(clonedOp);
    }

    for (auto [idx, origResult] : llvm::enumerate(kernelOp->getResults())) {
      SmallVector<Value> &cloneResults = perLaunchCloneResults[origResult];
      for (size_t launch = 0; launch < numLaunches; ++launch)
        cloneResults.push_back(kernelClones[launch]->getResult(idx));
    }
    allClones.append(kernelClones);

    MOGG::AsyncRoutineOp fusedRegion =
        fuseAndConvertToAsync(ctx, loc, groupRegions);
    Value fusedChain = fusedRegion.getResult(0);
    for (Value res : kernelOp->getResults())
      resultToFusedChain[res] = fusedChain;

    // Repoint guards from the erased per-launch region chains to the fused
    // chain.
    for (Operation *clone : kernelClones) {
      for (Value cloneRes : clone->getResults()) {
        loweringState.replaceChainGuard(cloneRes, fusedChain);
        Value lowered = loweringState.lookupExecuteLoweredValue(cloneRes);
        if (lowered)
          loweringState.replaceChainGuard(lowered, fusedChain);
      }
    }
  }

  // Register clone results as each result's bundle elements for
  // lower(TensorUnbundleOp).
  auto yieldOp = cast<MO::YieldOp>(bodyBlock.getTerminator());
  size_t resultIdx = 0;
  for (Value yieldOperand : yieldOp.getOperands()) {
    if (!isa<MO::TensorType>(yieldOperand.getType()))
      continue;
    Value bundleResult = parallelOp.getResult(resultIdx++);
    SmallVector<Value> &cloneResults = perLaunchCloneResults[yieldOperand];
    loweringState.emplaceBundleElements(bundleResult,
                                        SmallVector<Value>(cloneResults));
  }

  // The out-chain is the lowered completion of the body's yielded chain.
  if (parallelOp.hasChain()) {
    Value yieldedChain = yieldOp.getOperands().back();
    ASSERT_STREAM(
        isa<MO::ChainType>(yieldedChain.getType()),
        << "chained parallel must yield a trailing chain (enforced by verify)");
    auto it = resultToFusedChain.find(yieldedChain);
    // Or the in-chain, if the body passes it through.
    Value outChain =
        it != resultToFusedChain.end() ? it->second : loweredInChain;

    loweringState.emplaceExecuteLoweredValue(parallelOp.getOutChain(),
                                             outChain);
  }

  // Clones must stay alive, since loweredValues references their results.
  // Moving them into the body keeps lowerBlock from revisiting them; they die
  // with the MO graph.
  Block &bodyFront = parallelOp.getBodyRegion().front();
  for (Operation *clone : allClones)
    clone->moveBefore(&bodyFront, bodyFront.begin());

  return success();
}

LogicalResult MOGraphLowering::lower(MO::TensorBundleOp bundleOp) {
  SmallVector<Value> moElements = llvm::to_vector(bundleOp.getInputs());
  loweringState.emplaceBundleElements(bundleOp.getResult(),
                                      std::move(moElements));
  return success();
}

LogicalResult MOGraphLowering::lower(MO::TensorUnbundleOp unbundleOp) {
  auto moElements = loweringState.lookupBundleElements(unbundleOp.getInput());
  for (auto [result, moElem] :
       llvm::zip_equal(unbundleOp.getOutputs(), moElements)) {
    Value lowered = loweringState.lookupExecuteLoweredValue(moElem);
    Value chain = loweringState.getChainGuardingValueOrNull(moElem);
    if (!chain)
      chain = loweringState.getChainGuardingValueOrNull(lowered);
    if (chain)
      loweringState.emplaceExecuteLoweredBufferValue(result, lowered, chain);
    else
      loweringState.emplaceExecuteLoweredValue(result, lowered);
  }
  return success();
}

LogicalResult MOGraphLowering::lower(MO::CallOp callOp) {
  MGP::MOOpLoweringState opLoweringState(loweringState, callOp);
  OpBuilder b(callOp);

  StringRef targetModelName = callOp.getCallee();

  auto moduleOp = callOp->getParentOfType<ModuleOp>();
  if (!moduleOp)
    return callOp.emitError() << "Failed to find parent ModuleOp";

  auto targetModel = moduleOp.lookupSymbol<MGP::ModelOp>(targetModelName);
  if (!targetModel)
    return callOp.emitError()
           << "Failed to find target model with name: " << targetModelName;

  // Implicit args first: chain, context, weights registry, devices.
  SmallVector<Value> callOperands;
  callOperands.push_back(loweringState.getCurrentExecuteChain());
  callOperands.push_back(loweringState.getExecuteMgpContext());
  callOperands.push_back(loweringState.getExecuteWeightsRegistry());

  for (auto deviceAttr : targetModel.getDevices()) {
    DeviceRefAttr deviceRef = cast<DeviceRefAttr>(deviceAttr);
    callOperands.push_back(loweringState.getExecuteDevice(deviceRef));
  }

  for (auto operand : callOp.getOperands()) {
    Value loweredValue = loweringState.lookupExecuteLoweredValue(operand);
    if (!loweredValue)
      return callOp.emitError() << "Operand not lowered yet: " << operand;

    callOperands.push_back(loweredValue);
  }

  // The chain, then the explicit results.
  SmallVector<Type> resultTypes;
  resultTypes.push_back(b.getType<MEF::ChainType>());
  for (auto result : callOp.getResults()) {
    Type loweredType =
        loweringState.getTypeConverter().convertType(result.getType());
    if (!loweredType) {
      return callOp.emitError()
             << "Failed to lower result type: " << result.getType();
    }
    resultTypes.push_back(loweredType);
  }

  auto targetSymbol = SymbolRefAttr::get(targetModel.getSymNameAttr());
  auto mgpCallOp = opLoweringState.create<MGP::CallOp>(
      resultTypes, targetSymbol, callOp.getPrefixAttr(), callOperands);
  Value callOutChain = mgpCallOp.getResult(0);

  for (unsigned i = 0; i < callOp.getNumResults(); ++i) {
    loweringState.emplaceExecuteLoweredValue(callOp.getResult(i),
                                             mgpCallOp.getResult(i + 1));
    loweringState.guardValueWithChain(mgpCallOp.getResult(i + 1), callOutChain);
  }

  loweringState.setCurrentExecuteChain(callOutChain);

  return success();
}

/// A side-stream join is created at the end of its region, gated only on the
/// body's outputs, so the host enqueues the base stream's wait as soon as the
/// body is enqueued. Every base-stream op enqueued after that waits for the
/// side stream, data dependency or not. Move each join to the first consumer of
/// the region's results and gate it on that consumer's other chains, so the
/// host enqueues the independent base-stream work first.
static void deferSideStreamJoins(ModuleOp module) {
  SmallVector<MGP::DeviceWaitOp> joins;
  module.walk([&](MGP::DeviceWaitOp join) {
    if (join.getIsSideStreamJoin())
      joins.push_back(join);
  });
  llvm::SmallPtrSet<Value, 16> joinChains;
  for (MGP::DeviceWaitOp join : joins)
    joinChains.insert(join.getResult());

  for (MGP::DeviceWaitOp join : joins) {
    Block *block = join->getBlock();
    // The input holds made with the join move with it; they are not consumers.
    SmallVector<Operation *> holds;
    Operation *first = nullptr;
    for (Operation *user : join.getResult().getUsers()) {
      if (isa<MGP::ExtendLifetimeOp>(user)) {
        holds.push_back(user);
        continue;
      }
      Operation *op = block->findAncestorOpInBlock(*user);
      if (op && (!first || op->isBeforeInBlock(first)))
        first = op;
    }
    if (!first)
      continue;

    // Other joins in the consumer's chain are left out: gating joins on each
    // other would form a cycle.
    SmallVector<Value> chains{join.getInChain()};
    if (auto create = dyn_cast<GRT::ChainCreateOp>(first))
      for (Value chain : create->getOperands())
        if (!joinChains.contains(chain) && !llvm::is_contained(chains, chain))
          chains.push_back(chain);

    join->moveBefore(first);
    for (Operation *hold : holds)
      hold->moveAfter(join);
    if (chains.size() > 1) {
      OpBuilder b(join);
      join.getInChainMutable().assign(
          GRT::ChainCreateOp::create(b, join.getLoc(), chains).getResult());
    }
  }
}

void MOGGToMGPPass::runOnOperation() {
  ModuleOp theModule = getOperation();

  // Kernel stubs created during lowering are registered through the cached
  // `SymbolTableAnalysis`, which the pass manager never invalidates.
  SymbolTable &moduleSymbolTable =
      getAnalysis<mlir::SymbolTableAnalysis>().getTopLevelSymbolTable();

  std::deque<MO::GraphOp> worklist;

  DenseSet<StringAttr> completedGraphs;
  DenseMap<StringAttr, DenseSet<StringAttr>> graphDependencies;

  for (auto graphOp : theModule.getOps<MO::GraphOp>()) {
    worklist.push_back(graphOp);

    auto &dependencies = graphDependencies[graphOp.getNameAttr()];
    graphOp.walk([&](MO::CallOp callOp) {
      auto calleeName = callOp.getCalleeAttr().getAttr();
      dependencies.insert(calleeName);
    });
  }

  size_t lastProcessed = 0;
  // Process graphs in dependency order.
  while (!worklist.empty()) {
    // A full pass with no progress means a cycle.
    if (lastProcessed > worklist.size()) {
      theModule.emitError("cycle detected in graph ops");
      return signalPassFailure();
    }

    ++lastProcessed;

    MO::GraphOp graph = worklist.back();
    worklist.pop_back();

    auto &dependencies = graphDependencies[graph.getNameAttr()];

    if (!llvm::set_is_subset(dependencies, completedGraphs)) {
      worklist.push_front(graph);
      continue;
    }

    completedGraphs.insert(graph.getNameAttr());
    if (failed(MOGraphLowering(graph, compiledFrameworkLabel.getValue(),
                               minimumCpuAlignment.getValue(),
                               moduleSymbolTable)
                   .run()))
      return signalPassFailure();

    lastProcessed = 0;
  }

  deferSideStreamJoins(theModule);

  // A named dim on a stub's boundary would block MergeIdenticalFuncs
  // from deduplicating identical stubs. A nested pass so it stays testable on
  // its own.
  mlir::PassManager pm = mlir::PassManager::on<ModuleOp>(
      &getContext(), mlir::OpPassManager::Nesting::Implicit);
  pm.addPass(MOGG::createAnonymizeDimNames());
  if (pm.run(theModule).failed())
    return signalPassFailure();
}

TypedValue<MEF::ChainType> MGPBufferBuilder::setupForModel(
    ModelOp modelOp, MGPBufferBuilder *hostBufferBuilder, OpBuilder &builder,
    Location loc, TypedValue<MEF::ChainType> inChain) {
  this->hostBufferBuilder = hostBufferBuilder;

  TypedValue<ContextType> context;
  modelOp.walk([&](ContextCreateOp contextCreateOp) {
    runtimeSlot = contextCreateOp.getNumSlots();
    contextCreateOp.setNumSlots(runtimeSlot + 1);
    context = contextCreateOp.getResult();
    return WalkResult::interrupt();
  });

  if (this->hostBufferBuilder == this) {
    auto runtime = MGP::RuntimeCreateOp::create(builder, loc,
                                                /*inChain=*/inChain,
                                                /*theContext=*/context,
                                                /*aRuntimeSlot=*/runtimeSlot);
    ;
    return runtime.getOutChain();
  }
  return inChain;
}

void MGPBufferBuilder::recoverFromModel(ModelOp modelOp,
                                        MGPBufferBuilder *hostBufferBuilder) {
  this->hostBufferBuilder = hostBufferBuilder;

  // Without an mgp.runtime.create (unit tests), the slot index stays 0.
  modelOp.walk([&](RuntimeCreateOp runtimeCreateOp) {
    runtimeSlot = runtimeCreateOp.getARuntimeSlot();
    return WalkResult::interrupt();
  });

  size_t moduleIndex = 0;
  modelOp.walk([&](ModuleLoadOp moduleLoadOp) {
    for (auto [functionIndex, name] :
         llvm::enumerate(moduleLoadOp.getCFunctionSymbols())) {
      functionToIndexPair[name] = std::make_pair(moduleIndex, functionIndex);
    }
    for (auto [constantIndex, name] :
         llvm::enumerate(moduleLoadOp.getDConstantSymbols())) {
      constantToIndexPair[name] = std::make_pair(moduleIndex, constantIndex);
    }
    ++moduleIndex;
  });
}

Value MGPBufferBuilder::bufferTransferFromHost(OpBuilder &builder, Location loc,
                                               TypedValue<ContextType> context,
                                               Value inChain,
                                               MGPBufferBuilder *srcBuilder,
                                               Value srcBuffer, Value dstBuffer,
                                               Value deviceContext) {
  Value copyChain =
      BufferHostToDeviceOp::create(
          builder, loc,
          /*inChain=*/inChain,
          /*hostBuffer=*/cast<TypedValue<DeviceBufferType>>(srcBuffer),
          /*otherBuffer=*/cast<TypedValue<DeviceBufferType>>(dstBuffer),
          /*deviceContext*/
          cast<TypedValue<DeviceContextType>>(deviceContext),
          /*cHostDevice=*/hostBufferBuilder->device,
          /*dOtherDevice=*/device)
          .getResult();

  Value syncChain =
      MGP::SyncOp::create(builder, loc, copyChain, context, deviceContext,
                          /*bDevice=*/device);

  MGP::ExtendLifetimeOp::create(builder, loc, syncChain, ValueRange{srcBuffer});
  // Return copyChain, not syncChain: ops on the same deviceContext are
  // stream-ordered after the h2d copy, and waiting on syncChain would block
  // enqueueing ahead. A d2d copy using this dst as its src runs on another
  // stream, so it does not get that ordering for free.
  return copyChain;
}

Value MGPBufferBuilder::bufferTransferToHost(OpBuilder &builder, Location loc,
                                             TypedValue<ContextType> context,
                                             Value inChain, Value srcBuffer,
                                             MGPBufferBuilder *dstBuilder,
                                             Value dstBuffer,
                                             Value deviceContext) {
  Value copyChain =
      BufferDeviceToHostOp::create(
          builder, loc,
          /*inChain=*/inChain,
          /*otherBuffer=*/cast<TypedValue<DeviceBufferType>>(srcBuffer),
          /*hostBuffer=*/cast<TypedValue<DeviceBufferType>>(dstBuffer),
          /*deviceContext*/
          cast<TypedValue<DeviceContextType>>(deviceContext),
          /*cOtherDevice=*/device,
          /*dHostDevice=*/hostBufferBuilder->device)
          .getResult();

      MGP::SyncOp::create(builder, loc, copyChain, context, deviceContext,

  MGP::ExtendLifetimeOp::create(builder, loc, syncChain, ValueRange{dstBuffer});

  // The host cannot read dstBuffer until the d2h copy completes.
  return syncChain;
}

Value MGPBufferBuilder::bufferTransferDevice(
    OpBuilder &builder, Location loc, TypedValue<ContextType> context,
    Value inChain, Value srcBuffer, MGPBufferBuilder *dstBufferBuilder,
    Value dstBuffer, Value srcDeviceContext, Value dstDeviceContext) {
  DeviceRefAttr srcDevice = device;
  DeviceRefAttr dstDevice = dstBufferBuilder->device;

  // Different (virtual) devices use different streams, so the copy (on the
  // destination stream) is synchronized with the source stream via
  // mgp.device_wait on both sides.
  bool needsCrossStreamSync = srcDevice != dstDevice;

  Value copyInChain = inChain;
  if (needsCrossStreamSync) {
    // Source data must be ready before the copy reads it.
    copyInChain =
        MGP::DeviceWaitOp::create(builder, loc, /*inChain=*/inChain, context,
                                  /*waitingDeviceContext=*/dstDeviceContext,
                                  /*signalingDeviceContext=*/srcDeviceContext,
                                  /*bDevice=*/dstDevice)
            .getResult();
  }

  Value copyChain =
      BufferDeviceToDeviceOp::create(
          builder, loc,
          /*inChain=*/copyInChain,
          /*srcBuffer=*/cast<TypedValue<DeviceBufferType>>(srcBuffer),
          /*dstBuffer=*/cast<TypedValue<DeviceBufferType>>(dstBuffer),
          /*deviceContext*/
          cast<TypedValue<DeviceContextType>>(srcDeviceContext),
          /*deviceContext*/
          cast<TypedValue<DeviceContextType>>(dstDeviceContext),
          /*cSrcDevice=*/srcDevice,
          /*dDstDevice=*/dstDevice)
          .getResult();

  if (!needsCrossStreamSync)
    return copyChain;

  // The source must not be overwritten or freed until the copy completes.
  return MGP::DeviceWaitOp::create(builder, loc, /*inChain=*/copyChain, context,
                                   /*waitingDeviceContext=*/srcDeviceContext,
                                   /*signalingDeviceContext=*/dstDeviceContext,
                                   /*bDevice=*/srcDevice)
      .getResult();
}

/// Returns arrayAttr, which should be an array of StringAttrs, encoded as
/// a MultiLineStringAttr. Also adds each string to the given map.
static MultiLineStringAttr
toMultiline(OpBuilder &builder, uint64_t moduleIndex, ArrayAttr arrayAttr,
            llvm::StringMap<std::pair<uint64_t, uint64_t>> &nameToIndexPair) {
  SmallVector<StringAttr> stringAttrs;
  if (arrayAttr) {
    uint64_t nameIndex = 0;
    for (StringRef symbol : arrayAttr.getAsValueRange<mlir::StringAttr>()) {
      stringAttrs.emplace_back(builder.getStringAttr(symbol));
      nameToIndexPair.insert({symbol, std::make_pair(moduleIndex, nameIndex)});
      ++nameIndex;
    }
  }
  return MultiLineStringAttr::get(builder.getContext(), stringAttrs);
}

TypedValue<MEF::ChainType> MGPBufferBuilder::moduleLoad(
    OpBuilder &builder, Location loc, TypedValue<ContextType> context,
    TypedValue<MEF::ChainType> inChain, ElementsAttr image,
    ArrayAttr functionSymbols, ArrayAttr constantSymbols) {
  auto functionSymbolsAttr = toMultiline(builder, nextModuleIndex,
                                         functionSymbols, functionToIndexPair);
  auto constantSymbolsAttr = toMultiline(builder, nextModuleIndex,
                                         constantSymbols, constantToIndexPair);
  auto load = ModuleLoadOp::create(builder, loc,
                                   /*inChain=*/
                                   cast<TypedValue<MEF::ChainType>>(inChain),
                                   /*theContext=*/context,
                                   /*aRuntimeSlot=*/runtimeSlot,
                                   /*bImage=*/image,
                                   /*cFunctionSymbols=*/functionSymbolsAttr,
                                   /*dConstantSymbols=*/constantSymbolsAttr,
                                   /*eDevice=*/device,
                                   /*fModuleIndex=*/nextModuleIndex);
  ++nextModuleIndex;
  return load;
}

MGPBufferBuilder::cache(OpBuilder &initBuilder, Location loc,

  auto cacheOp = BufferCacheOp::create(
      initBuilder, loc, /*inChain=*/inChain, /*theContext=*/contextCreateOp,
      /*buffer=*/cast<TypedValue<DeviceBufferType>>(buffer),
      /*bBufferSlot=*/bufferSlot);
  return {cacheOp.getOutChain(), bufferSlot};
}

Value MGPBufferBuilder::getCached(OpBuilder &builder, Location loc,
                                  TypedValue<ContextType> context,
                                  TypedValue<MEF::ChainType> inChain,
                                  uint64_t bufferSlot,
                                  Type expectedBufferType) {
  auto parentOp = builder.getBlock()->getParentOp();
  if (!isa<ModelOp>(parentOp))
    parentOp = parentOp->getParentOfType<MGP::ModelOp>();

  auto modelOp = cast<ModelOp>(parentOp);
  Value bufferSlotIndex =
      mlir::index::ConstantOp::create(builder, loc, bufferSlot);
  if (modelOp.getIsSubgraph()) {
    bufferSlotIndex = mlir::index::AddOp::create(builder, loc, bufferSlotIndex,
                                                 modelOp.getSubgraphIndex());
  }

  return BufferGetCachedOp::create(builder, loc, expectedBufferType,
                                   /*inChain=*/inChain, /*theContext=*/context,
                                   /*bBufferSlot=*/bufferSlotIndex)
      .getOutBuffer();
}

/// State for lowering one mo.graph to a mgp.model, shared by MOGGToMGP and
/// LowerableToMGPInterface implementers and built up as ops are lowered.
class MOGraphLoweringState {
public:
  MOGraphLoweringState(M::MO::GraphOp graph,
                       llvm::StringRef compiledFrameworkLabel,
                       size_t minimumCpuAlignment,
                       mlir::SymbolTable &moduleSymbolTable)
      : graph(graph), common(compiledFrameworkLabel, minimumCpuAlignment),
        init(graph.getContext()), execute(graph.getContext()),
        moduleSymbolTable(moduleSymbolTable) {
    builderContext.hostDevice = M::getHostDevice(graph);

    typeConverter.addConversion(
        [this](MO::TensorType type) -> std::optional<Type> {
          return getTypeBuilder(MO::getDeviceOrDefault(type))
              .tensorType(MGP::createTensorSpecType(type), /*mut=*/false,
                          type.isStable());
        });
    typeConverter.addConversion(
        [this](MO::BufferType bufferType) -> std::optional<Type> {
          // Buffers lower to mutable tensors: the `mut` marker is the only
          // record of in-place semantics past this boundary.
          auto type = MO::BufferType::toTensorType(bufferType);
          return getTypeBuilder(MO::getDeviceOrDefault(type))
              .tensorType(MGP::createTensorSpecType(type), /*mut=*/true);
        });
    typeConverter.addConversion([this](
                                    MO::ListType type) -> std::optional<Type> {
      auto tensorTy = dyn_cast<MO::TensorType>(type.getElementType());
      // TODO(#29947): Support other element types
      ASSERT_STREAM(tensorTy, << "only support lowering list of tensors");

      MLIRContext *ctx = type.getContext();
      MGP::TensorSpecType tensorSpecTy = MGP::createTensorSpecType(tensorTy);
      DeviceRefAttr tensorDeviceRef = MO::getDeviceOrDefault(tensorTy);
      auto mgpTensorTy =
          getTypeBuilder(tensorDeviceRef).tensorType(tensorSpecTy);
      return MGP::ListType::get(ctx, mgpTensorTy);
    });
    typeConverter.addConversion([](MO::ScalarType type) -> std::optional<Type> {
      auto errOrDtype = MO::toMLIRType(type.getContext(), type.getDtype());

      if (errOrDtype.isError()) {
        return std::nullopt;
      }

      return *errOrDtype;
    });

    typeConverter.addConversion([](MO::OpaqueType type) -> std::optional<Type> {
      return OpaqueType::get(type.getContext(), type.getSymbol(), std::nullopt);
    });

    typeConverter.addConversion([](MO::ChainType type) -> std::optional<Type> {
      return MEF::ChainType::get(type.getContext());
    });

    // Foreign types.
    typeConverter.addConversion([](Type type) -> std::optional<Type> {
      if (auto interface = dyn_cast<ConvertibleToMGPTypeInterface>(type))
        return interface.convertType();
      return {};
    });
  }

  ErrorOr<ElementsAttr> lowerElementsAttr(ElementsAttr elementsAttr);

  /// Common state used by both the init and execute phases.
  struct CommonState {
    explicit CommonState(llvm::StringRef compiledFrameworkLabel,
                         size_t minimumCpuAlignment)
        : compiledFrameworkLabel(compiledFrameworkLabel),
          minimumCpuAlignment(minimumCpuAlignment) {}

    MGP::ModelOp modelOp;

    /// The name of the target framework, e.g. "mgp", "tf", etc.
    llvm::StringRef compiledFrameworkLabel;

    /// For all CPU buffers, constant and allocated.
    size_t minimumCpuAlignment;

    CommonState(const CommonState &) = delete;
    void operator=(const CommonState &) = delete;
  };

  /// State used when building an invokable for the 'init' phase.
  struct InitState {
    InitState(MLIRContext *ctx) : builder(ctx) {}

    Value chain;

    MGP::ContextCreateOp mgpContext;

    /// This is a builder appending operations to the end of the invokable.
    OpBuilder builder;

    InitState(const InitState &) = delete;
    void operator=(const InitState &) = delete;
  };

  /// State used when building an invokable for the 'execute' phase.
  struct ExecuteState {
    ExecuteState(MLIRContext *ctx) : builder(ctx) {}

    /// The input chain passed as the first argument to the 'execute' block,
    /// or an equivalent SSA value in a control flow sub-block.
    TypedValue<MEF::ChainType> rootChain;

    /// Sequences side-effecting operations such as printing.
    TypedValue<MEF::ChainType> currentChain;

    /// Passed in as the second argument.
    TypedValue<MGP::ContextType> mgpContext;

    /// Keeps track of what runtime SSA values the graph SSA values lower to.
    DenseMap<Value, Value> loweredValues;

    /// Maps !mo.bundle SSA values to their per-element MO-level values, so
    /// consumers needn't look through the defining TensorBundleOp.
    DenseMap<Value, SmallVector<Value>> bundleElements;

    /// The chain guarding each buffer / tensor's first write; readers must
    /// depend on it.
    DenseMap<Value, Value> loweredBufferChains;

    /// Names dense_resource attributes capturing MO constants.
    size_t nextConstId = 0;

    /// This is a builder appending operations to the end of the invokable.
    OpBuilder builder;

    /// Maps a lowered assert to the lowered assert it was chained to in MO.
    DenseMap<Operation *, Operation *> parentAssert;

    ExecuteState(const ExecuteState &) = delete;
    void operator=(const ExecuteState &) = delete;
  };

  // Base class for clients that want to inject their own custom state.
  struct ClientState {
    virtual ~ClientState() = default;
  };

  bool hasClientState() const { return bool(clientState); }

  // Only to be called once.
  template <typename T>
  void initClientState(T &&initState) {
    assert(!hasClientState());
    clientState = std::make_unique<T>(std::forward<T>(initState));
  }

  template <typename T>
  T &getClientState() {
    return static_cast<T &>(*clientState);
  }

  MGP::ModelOp getModelOp() { return common.modelOp; }

  /// New module-scope symbols (e.g. kernel stubs) must be inserted through
  /// this: the pass manager never invalidates `SymbolTableAnalysis`, so
  /// downstream passes wouldn't see them otherwise.
  mlir::SymbolTable &getModuleSymbolTable() { return moduleSymbolTable; }

  void setModelOp(MGP::ModelOp modelOp) { common.modelOp = modelOp; }

  llvm::StringRef getCompiledFrameworkLabel() {
    return common.compiledFrameworkLabel;
  }

  size_t getMinimumCpuAlignment() { return common.minimumCpuAlignment; }

  MO::GraphOp &getGraph() { return graph; }

  TypeConverter &getTypeConverter() { return typeConverter; }

  Value getInitChain() { return init.chain; }

  void setInitChain(Value chain) { init.chain = chain; }

  TypedValue<DeviceContextType> getInitDevice(DeviceRefAttr dev) {
    return initDevices[dev];
  }

  void setInitDevice(DeviceRefAttr dev, TypedValue<DeviceContextType> val) {
    initDevices[dev] = val;
  }

  OpBuilder &getInitOpBuilder() { return init.builder; }

  void setInitMgpContext(MGP::ContextCreateOp mgpContext) {
    init.mgpContext = mgpContext;
  }

  MGP::ContextCreateOp &getInitMgpContext() { return init.mgpContext; }

  TypedValue<MGP::OpaqueType> getInitWeightsRegistry() {
    return cast<TypedValue<MGP::OpaqueType>>(
        common.modelOp.getInitWeightsRegistry());
  }

  OpBuilder &getExecuteOpBuilder() { return execute.builder; }

  void setExecuteMgpContext(Value mgpContext) {
    execute.mgpContext = cast<TypedValue<MGP::ContextType>>(mgpContext);
  }

  TypedValue<MGP::ContextType> getExecuteMgpContext() {
    return execute.mgpContext;
  }

  TypedValue<DeviceContextType> getExecuteDevice(DeviceRefAttr dev) {
    if (!dev)
      dev = DeviceRefAttr::getDefault(execute.builder.getContext());

    // While lowering an `mo.sequence` body onto a side stream, every op
    // lowered through here picks up the side-stream context.
    if (auto it = execDevices.find(dev); it != execDevices.end())
      return it->second;

    for (auto [deviceRefAttr, deviceContext] : llvm::zip(
             common.modelOp.getDevices(), common.modelOp.getExecuteDevices())) {
      if (deviceRefAttr == dev)
        return cast<TypedValue<MGP::DeviceContextType>>(deviceContext);
    }
    llvm_unreachable("Could not find device in model args");
  }

  /// Make `getExecuteDevice(dev)` return `ctx` (e.g. a side-stream view) until
  /// cleared. Not nestable; the MO verifier forbids nested `mo.sequence`.
  void setExecuteDeviceOverride(DeviceRefAttr dev,
                                TypedValue<DeviceContextType> ctx) {
    assert(!execDevices.count(dev) &&
           "nested execute-device override for the same device");
    execDevices[dev] = ctx;
  }

  void clearExecuteDeviceOverride(DeviceRefAttr dev) { execDevices.erase(dev); }

  TypedValue<MGP::OpaqueType> getExecuteWeightsRegistry() {
    return cast<TypedValue<MGP::OpaqueType>>(
        common.modelOp.getExecuteWeightsRegistry());
  }

  void setRootExecuteChain(Value chain) {
    execute.rootChain = cast<TypedValue<MEF::ChainType>>(chain);
  }

  /// The 'root' chain of the 'execute' block, for non-side-effecting
  /// operations.
  TypedValue<MEF::ChainType> getExecuteChain() { return execute.rootChain; }

  /// The 'current' chain of the 'execute' block, for side-effecting
  /// operations.
  Value getCurrentExecuteChain() { return execute.currentChain; }

  void setCurrentExecuteChain(Value chain) {
    execute.currentChain = cast<TypedValue<MEF::ChainType>>(chain);
  }

  /// The runtime value a mo.graph SSA value (often a `mo.tensor`) lowers to.
  Value lookupExecuteLoweredValue(Value key) {
    return execute.loweredValues.lookup(key);
  }

  Value getChainGuardingValueOrNull(Value key) {
    return execute.loweredBufferChains.lookup(key);
  }

  void guardValueWithChain(Value key, Value chain) {
    execute.loweredBufferChains.try_emplace(key, chain);
  }

  /// Overwrite an existing chain guard, e.g. after region fusion.
  void replaceChainGuard(Value key, Value newChain) {
    execute.loweredBufferChains[key] = newChain;
  }

  using ParamPlaceholderOp = ParameterLoweringState::PlaceholderOp;

  /// Record the runtime value a mo.graph SSA value lowers to.
  void emplaceExecuteLoweredValue(Value key, Value value) {
    if (auto placeholder = value.getDefiningOp<ParamPlaceholderOp>())
      placeholderMap.find(placeholder)->getSecond().emplace_back(key);

    execute.loweredValues.try_emplace(key, value);
  }

  void emplaceExecuteLoweredBufferValue(Value key, Value value, Value chain) {
    guardValueWithChain(key, chain);
    guardValueWithChain(value, chain);
    execute.loweredValues.try_emplace(key, value);
  }

  void emplaceBundleElements(Value bundleVal, SmallVector<Value> elements) {
    execute.bundleElements.try_emplace(bundleVal, std::move(elements));
  }

  SmallVector<Value> lookupBundleElements(Value bundleVal) {
    auto it = execute.bundleElements.find(bundleVal);
    ASSERT_STREAM(it != execute.bundleElements.end(),
                  << "bundle value has no registered elements");
    return it->second;
  }

  size_t getExecuteNextConstId() { return execute.nextConstId++; }

  /// Returns the shape of a lowered tensor which is on the given device.
  TypedValue<MGP::TensorSpecType> getShape(Location loc, Value loweredTensor,
                                           DeviceRefAttr device);

  /// Assumes the rank is known.
  SmallVector<Value> getDynamicDims(Location loc, Value loweredTensor,
                                    DeviceRefAttr device);

  MGP::TensorSpecGetDimOp getDim(Location loc, Value loweredTensor,
                                 uint64_t axis, DeviceRefAttr device);

  struct ArgLoweringResult {
    bool hasParameters;
    Value loweredArg;
  };

  /// Maps the dynamic shape parameters of `inArg` (a !mo.tensor lowered to the
  /// !mgp.tensor `outArg`) to their MGP values. Returns whether there were
  /// parameters, and `outArg` guarded by any runtime assertions.
  ErrorOr<ArgLoweringResult> lowerArg(Region *parentRegion, BlockArgument inArg,
                                      BlockArgument outArg);

  /// Lowers a parameter expression: unseen references become placeholders,
  /// operators recurse, and other attributes go to the hook.
  ErrorOr<Value> lowerExpression(Region *parentRegion, Location loc,
                                 TypedAttr attr);

  /// Lower a parameter declaration once, resolving its placeholder if any.
  ErrorOrSuccess lowerParamDecl(Region *parentRegion,
                                KGEN::ParamDeclAttr declAttr, Value value);

  /// The values of `shape`'s parametric dimensions, in order.
  ErrorOr<SmallVector<Value>> lowerShapeAttrDynDims(Region *parentRegion,
                                                    MOSH::ShapeAttr shapeAttr,
                                                    Location loc);

  const BufferBuilderContext &getBufferBuilderContext() const {
    return builderContext;
  }

  /// Register a type builder for the given device.
  void registerTypeBuilder(DeviceRefAttr device) {
    builderContext.registerTypeBuilder(device);
  }

  /// Returns the type builder to use for device.
  MGP::MGPTypeBuilder getTypeBuilder(DeviceRefAttr device) {
    return builderContext.getTypeBuilder(device);
  }

  /// Register the given buffer builder for the given device.
  void
  registerBufferBuilder(DeviceRefAttr device,
                        std::unique_ptr<MGP::MGPBufferBuilder> bufferBuilder) {
    builderContext.registerBufferBuilder(device, std::move(bufferBuilder));
  }

  /// The returned builder is owned by this object.
  MGP::MGPBufferBuilder &getBufferBuilder(DeviceRefAttr device) {
    return builderContext.getBufferBuilder(device);
  }

  /// Return the 'host' device for this graph.
  DeviceRefAttr getHostDevice() { return builderContext.hostDevice; }

  /// Returns the buffer builder to use for the 'host' device.
  MGP::MGPBufferBuilder &getHostBufferBuilder() {
    return builderContext.getHostBufferBuilder();
  }

  /// Packs outputs and unpacks inputs of a MOGG::AsyncRoutineOp.
  static void lowerMOGGABI(MOGG::AsyncRoutineOp kernelOp);

private:
  //===-----------------------------------------------------------------===//
  // Parameter lowering helpers.
  //===-----------------------------------------------------------------===//

  /// Lowers an operator attribute to the appropriate mop index op.
  static ErrorOr<Value> lowerParamOperator(OpBuilder &builder, Location loc,
                                           KGEN::ParamOperatorAttr opAttr,
                                           ValueRange operands);

  /// Lowers an integer attribute to a index constant op.
  static Operation *lowerKGENConstantAttr(OpBuilder &builder, Location loc,
                                          TypedAttr intAttr);

  /// Lower a parameter expression.
  ErrorOr<Value> lowerExpressionImpl(ParameterLoweringState &state,
                                     OpBuilder &builder, Location loc,
                                     Region *parentRegion, TypedAttr attr,
                                     ValueRange operands);

  /// Lower a parameter expression used as a dimension.
  ErrorOr<Value> lowerDimensionExpression(ParameterLoweringState &state,
                                          OpBuilder &builder, Location loc,
                                          Region *parentRegion, TypedAttr dim);

private:
  //===-----------------------------------------------------------------===//
  // Lowering state
  //===-----------------------------------------------------------------===//

  /// The graph being lowered.
  MO::GraphOp graph;

  TypeConverter typeConverter;

/// MO ops only return !mo.tensors; other result types would need a variant.
using MOOutputStorage = BufferizedTensor;

/// Manages the value-to-buffer-semantic transition when lowering one MO op.
struct MOOpLoweringState {
  MOGraphLoweringState &loweringState;
  OpBuilder &builder;
  mlir::Operation *opBeingLowered;
  mlir::Location loc;
  TypedValue<MGP::ContextType> context;
  TypedValue<MGP::OpaqueType> weightsRegistry;
  uint64_t minimumCpuAlignment;

  MOOpLoweringState(MGP::MOGraphLoweringState &loweringState,
                    mlir::Operation *op)
      : loweringState(loweringState),
        builder(loweringState.getExecuteOpBuilder()), opBeingLowered(op),
        loc(op->getLoc()), context(loweringState.getExecuteMgpContext()),
        weightsRegistry(loweringState.getExecuteWeightsRegistry()),
        minimumCpuAlignment(loweringState.getMinimumCpuAlignment()) {}

  //===-----------------------------------------------------------------===//
  // Main API
  //===-----------------------------------------------------------------===//

  /// Returns the lowered operands: !mo.tensors as their buffer on the type's
  /// storage device, everything else as is.
  SmallVector<Value> getLoweredOperands();

  /// Merges `chain` with any other chains this op must wait on.
  Value getGuardChain(Value chain);

  /// Derives the output specs from the op's result types.
  FailureOr<SmallVector<MOOutputStorage>> createOutputStorage(Value inChain);

  /// Returns destination-passing-style storage for the op's !mo.tensor
  /// results: a fresh buffer on the storage device, paired with a tensor spec.
  FailureOr<SmallVector<MOOutputStorage>>
  createOutputStorage(Value inChain,
                      ArrayRef<TypedValue<MGP::TensorSpecType>> outSpecs);

  /// Create the outputs from the storage and map the MO op results to them.
  void createOutputs(Value inChain,
                     SmallVector<MOOutputStorage> &loweredOutputsStorage);

  //===-----------------------------------------------------------------===//
  // Input and Output helpers
  //===-----------------------------------------------------------------===//

  /// Returns the bufferized form for the MO tensor value.
  BufferizedTensor getBufferizedInput(Value moTensor);

  FailureOr<TypedValue<MGP::TensorSpecType>>
  createTensorSpec(MO::TensorType moTensorType);

  /// Returns the tensor specs to represent all the op's outputs.
  FailureOr<SmallVector<TypedValue<MGP::TensorSpecType>>>
  createOutputTensorSpecs();

  /// Allocates a buffer sized for `spec` on moTensorType's storage device.
  FailureOr<BufferizedTensor>
  createBuffer(Value inChain, TypedValue<TensorSpecType> tensorSpec,
               Type moTensorType);

  /// Creates a tensor on moTensor's storage device and maps moTensor to it.
  void createOutputTensor(Value moTensor, Value inChain, Value buffer,
                          TypedValue<MGP::TensorSpecType> tensorSpec);

  void createOutputTensors(
      Value inChain, SmallVector<Value> &buffers,
      SmallVector<TypedValue<MGP::TensorSpecType>> &tensorSpecs);

  //===-----------------------------------------------------------------===//
  // MLIR create helpers
  //===-----------------------------------------------------------------===//

  /// Creates an operation of specific op type at the current insertion point.
  template <typename OpTy, typename... Args>
  OpTy create(Args &&...args) {
    return OpTy::create(builder, loc, std::forward<Args>(args)...);
  }

  /// The buffer builder for moTensorType's storage device.
  MGP::MGPBufferBuilder &getStorageBufferBuilder(Type moTensorType);

  // These redirect to MGPBufferBuilder for moTensorType's storage device.

  std::pair<Value, TypedValue<TensorSpecType>>
  tensorExtract(Value loweredTensor, Type moTensorType) {
    MGP::MGPBufferBuilder &bufferBuilder =
        getStorageBufferBuilder(moTensorType);
    // Separate statements fix the op order; argument evaluation order is
    // unspecified.
    auto buffer =
        bufferBuilder.tensorExtractBuffer(builder, loc, loweredTensor);
    auto spec =
        bufferBuilder.tensorExtractTensorSpec(builder, loc, loweredTensor);
    loweringState.guardValueWithChain(
        buffer, loweringState.getChainGuardingValueOrNull(loweredTensor));
    return std::make_pair(buffer, spec);
  }

  Value tensorCreate(Value inChain, Value buffer,
                     TypedValue<TensorSpecType> tensorSpec, Type moTensorType) {
    bool isMut = isa<MO::BufferType>(moTensorType);

    Value tensor =
        getStorageBufferBuilder(moTensorType)
            .tensorCreate(builder, loc, context, inChain, buffer, tensorSpec,
                          /*mut=*/isMut);
    loweringState.guardValueWithChain(
        tensor, loweringState.getChainGuardingValueOrNull(buffer));
    return tensor;
  }

  Value hostBufferConstant(TypedValue<MEF::ChainType> inChain,
                           ElementsAttr value, Type moTensorType) {
    return loweringState.getHostBufferBuilder().bufferConstant(
        builder, loc, inChain, context, value);
  }

  Value hostBufferConstantExternal(TypedValue<MEF::ChainType> inChain,
                                   TypedValue<MGP::OpaqueType> name,
                                   uint64_t size, uint64_t align, bool hasAlias,
                                   bool isPlaceholder) {
    return loweringState.getHostBufferBuilder().bufferConstantExternal(
        builder, loc, inChain, context, weightsRegistry, name, size, align,
        hasAlias, isPlaceholder);
  }

  Value deviceBufferConstantExternal(DeviceRefAttr device,
                                     TypedValue<MEF::ChainType> inChain,
                                     TypedValue<MGP::OpaqueType> name,
                                     uint64_t size, uint64_t align,
                                     bool hasAlias, bool isPlaceholder) {
    return loweringState.getBufferBuilder(device).bufferConstantExternal(
        builder, loc, inChain, context, weightsRegistry, name, size, align,
        hasAlias, isPlaceholder);
  }

  Value hostDebugPrint(Value inChain, StringAttr data, StringAttr label) {
    return loweringState.getHostBufferBuilder().debugPrint(
        builder, loc, context, inChain, data, label);
  }

  Value debugTensorPrint(Value inChain, Value buffer,
                         TypedValue<TensorSpecType> tensorSpec,
                         StringAttr label, Type moTensorType) {
    return getStorageBufferBuilder(moTensorType)
        .debugTensorPrint(builder, loc, context, inChain, buffer, tensorSpec,
                          label);
  }
  Value hostDebugTensorPrint(Value inChain, Value buffer,
                             TypedValue<TensorSpecType> tensorSpec,
                             StringAttr label) {
    return loweringState.getHostBufferBuilder().debugTensorPrint(
        builder, loc, context, inChain, buffer, tensorSpec, label);
  }

  Value bufferTransferFromHost(Value inChain,
                               TypedValue<MGP::DeviceBufferType> srcBuffer,
                               Value dstBuffer, Type dstMoTensorType) {
    auto deviceRef = getStorageBufferBuilder(dstMoTensorType).getDevice();
    auto deviceContext = loweringState.getExecuteDevice(deviceRef);
    auto chain =
        getStorageBufferBuilder(dstMoTensorType)
            .bufferTransferFromHost(builder, loc, context, inChain,
                                    &loweringState.getHostBufferBuilder(),
                                    srcBuffer, dstBuffer, deviceContext);
    loweringState.guardValueWithChain(dstBuffer, chain);
    return chain;
  }
  Value bufferTransferToHost(Value inChain, Value srcBuffer,
                             TypedValue<MGP::DeviceBufferType> dstBuffer,
                             Type srcMoTensorType) {
    auto deviceRef = getStorageBufferBuilder(srcMoTensorType).getDevice();
    auto deviceContext = loweringState.getExecuteDevice(deviceRef);
    return getStorageBufferBuilder(srcMoTensorType)
        .bufferTransferToHost(builder, loc, context, inChain, srcBuffer,
                              &loweringState.getHostBufferBuilder(), dstBuffer,
                              deviceContext);
  }
  Value bufferTransferDevice(Value inChain, Value srcBuffer, Value dstBuffer,
                             Type srcMoTensorType, Type dstMoTensorType) {
    // The only op spanning two devices. The D2D device context synchronizes
    // them. TODO(GEX-1859): Explicit sync to enable compute overlap.

    DeviceRefAttr srcDeviceRef =
        getStorageBufferBuilder(srcMoTensorType).getDevice();
    DeviceRefAttr dstDeviceRef =
        getStorageBufferBuilder(dstMoTensorType).getDevice();
    auto dstDeviceContext = loweringState.getExecuteDevice(dstDeviceRef);
    auto srcDeviceContext = loweringState.getExecuteDevice(srcDeviceRef);

    return getStorageBufferBuilder(srcMoTensorType)
        .bufferTransferDevice(builder, loc, context, inChain, srcBuffer,
                              &getStorageBufferBuilder(dstMoTensorType),
                              dstBuffer, srcDeviceContext, dstDeviceContext);
  }

  Value bufferConcat(Value inChain, Value outBuffer, ArrayRef<Value> inBuffers,
                     Type outMoTensorType) {
    auto ty = cast<MO::TensorType>(outMoTensorType);
    auto deviceContext = loweringState.getExecuteDevice(ty.getDeviceRef());
    return getStorageBufferBuilder(outMoTensorType)
        .bufferConcat(builder, loc, deviceContext, inChain, outBuffer,
                      inBuffers);
  }

  Value bufferSlice(Value inBuffer, Value offset, Value size,
                    Type outMoTensorType) {
    auto deviceRef = getStorageBufferBuilder(outMoTensorType).getDevice();
    auto deviceContext = loweringState.getExecuteDevice(deviceRef);
    return getStorageBufferBuilder(outMoTensorType)
        .bufferSlice(builder, loc, inBuffer, offset, size, deviceContext);
  }

  Value bufferToBool(Value inChain, Value buffer, Type moTensorType) {
    return getStorageBufferBuilder(moTensorType)
        .bufferToBool(builder, loc, context, inChain, buffer);
  }

  Value bufferSetWithIndex(Value buffer, ArrayRef<Value> values,
                           Type moTensorType) {
    return getStorageBufferBuilder(moTensorType)
        .bufferSetWithIndex(builder, loc, context, buffer, values);
  }

  Value hostBufferAlloc(TypedValue<MEF::ChainType> inChain, Value size,
                        uint64_t align) {
    auto deviceContext =
        loweringState.getExecuteDevice(loweringState.getHostDevice());
    return loweringState.getHostBufferBuilder().bufferAlloc(
        builder, loc, context, inChain, size, deviceContext, align);
  }

  Value bufferAlloc(TypedValue<MEF::ChainType> inChain, Value size,
                    uint64_t align, Type moTensorType) {
    auto deviceRef = getStorageBufferBuilder(moTensorType).getDevice();
    auto deviceContext = loweringState.getExecuteDevice(deviceRef);
    return getStorageBufferBuilder(moTensorType)
        .bufferAlloc(builder, loc, context, inChain, size, deviceContext,
                     align);
  }

  Value bufferSizeBytes(TypedValue<TensorSpecType> tensorSpec,
                        Type moTensorType) {
    int64_t dtypeSize =
        dyn_cast<MO::TensorType>(moTensorType).getDtype().getSizeInBytes();
    Value numBytes = mlir::index::ConstantOp::create(builder, loc, dtypeSize);
    for (size_t i = 0; i < tensorSpec.getType().getRank(); ++i) {
      Value dimVal =
          builder.createOrFold<MGP::TensorSpecGetDimOp>(loc, tensorSpec, i);
      numBytes = builder.createOrFold<mlir::index::MulOp>(
          loc, builder.getIndexType(), numBytes, dimVal);
    }
    return numBytes;
  }

  Value sync(Value chain) {
    auto device = loweringState.getHostDevice();
    auto deviceContext = loweringState.getExecuteDevice(device);
    return loweringState.getBufferBuilder(device).sync(builder, loc, context,
                                                       deviceContext, chain);
  }
};

MojoRegistry::MojoRegistry(mlir::ModuleOp module) : deviceInfoMapping(module) {
  for (auto decl : module.getOps<KernelDeclOp>()) {
    kernelByName[decl.getRegistration()].push_back(decl);
    kernelBySymName[decl.getSymName()] = decl;
  }
  for (auto decl : module.getOps<PrimitiveDeclOp>()) {
    llvm::StringRef reg = decl.getRegistration();
    if (!primitiveByName.contains(reg))
      primitiveByName[reg] = decl;
  }
  for (auto decl : module.getOps<ShapeFunctionDeclOp>()) {
    shapeFuncByName[decl.getRegistration()] = decl;
    shapeFuncBySymName[decl.getSymName()] = decl;
  }
}

static bool deviceInfoMatches(DeviceInfoAttr kernelInfo,
                              DeviceInfoAttr deviceInfo) {
  auto matches = [](llvm::StringRef kernelField, llvm::StringRef runtimeField) {
    return kernelField.empty() || kernelField == runtimeField;
  };
  return matches(kernelInfo.getLabel(), deviceInfo.getLabel()) &&
         matches(kernelInfo.getApi(), deviceInfo.getApi()) &&
         matches(kernelInfo.getArch(), deviceInfo.getArch()) &&
         matches(kernelInfo.getModel(), deviceInfo.getModel());
}

static int deviceInfoSpecificity(DeviceInfoAttr infos) {
  return !infos.getLabel().empty() + !infos.getApi().empty() +
         !infos.getArch().empty() + !infos.getModel().empty();
}

// Whether the kernel's `execute` (or `execute_device`, for a declarative
// kernel) declares a tile-based fused output (_FusedComputeOutputTileTensor or
// _FusedOutputTileTensor), which only lowers on a tile_based_fusion device.
// Transitional, remove per GEX-3941.
static bool kernelDeclaresTileOutput(KernelDeclOp decl) {
  KernelDeclAdaptor adaptor(decl);
  if (!adaptor.executeFunction.has_value())
    return false;
  for (const auto &arg : adaptor.executeFunction->outputArguments) {
    const auto *tensorArg =
        std::get_if<KernelDeclTensorAdaptor>(&arg.underlyingType);
    if (tensorArg &&
        (tensorArg->ioSpec == IOSpec::FusedComputeOutputTileTensor ||
         tensorArg->ioSpec == IOSpec::FusedOutputTileTensor))
      return true;
  }
  return false;
}

// The order candidates win in, compared lexicographically: a user-defined
// kernel beats a built-in one, then more matching device fields beat fewer.
static std::tuple<bool, int> resolutionRank(KernelDeclOp decl) {
  return {decl.getIsUserDefined(),
          deviceInfoSpecificity(decl.getRegistrationDeviceInfo())};
}

ErrorOr<KernelDeclOp>
MojoRegistry::getResolvedKernel(llvm::StringRef name,
                                DeviceRefAttr device) const {
  DeviceInfoAttr deviceInfo = deviceInfoMapping.get(device);
  auto it = kernelByName.find(name);
  ASSERT_STREAM(it != kernelByName.end(),
                "no kernel registered for '" << name << "'");

  llvm::SmallVector<KernelDeclOp> candidates;
  for (KernelDeclOp decl : it->second) {
    if (!deviceInfoMatches(decl.getRegistrationDeviceInfo(), deviceInfo))
      continue;
    // TODO(GEX-3941): on non-tile devices, skip tile-output candidates so the
    // generic (SIMD) registration is selected.
    if (!deviceInfo.getTileBasedFusion() && kernelDeclaresTileOutput(decl))
      continue;
    candidates.push_back(decl);
  }

  if (candidates.empty()) {
    std::string msg;
    llvm::raw_string_ostream os(msg);
    os << "no kernel matching device info for '" << name << "' on device "
       << mlir::Attribute(deviceInfo) << "; candidates:";
    for (KernelDeclOp decl : it->second)
      os << "\n  - " << mlir::Attribute(decl.getRegistrationDeviceInfo())
         << " (" << decl.getSymName() << ")";
    return Error(os.str());
  }

  KernelDeclOp best =
      *llvm::max_element(candidates, [](KernelDeclOp a, KernelDeclOp b) {
        return resolutionRank(a) < resolutionRank(b);
      });
  ASSERT_STREAM(llvm::count_if(candidates,
                               [&](KernelDeclOp decl) {
                                 return resolutionRank(decl) ==
                                        resolutionRank(best);
                               }) == 1,
                "ambiguous kernel resolution for '"
                    << name << "': multiple "
                    << (best.getIsUserDefined() ? "user-defined" : "built-in")
                    << " registrations match the runtime device with equal "
                       "specificity");
  return best;
}

DeviceRefAttr MojoRegistry::getDeviceRefForOp(mlir::Operation *op) {
  if (auto hasDevice = mlir::dyn_cast<MO::MOHasDeviceInterface>(op)) {
    auto devices = hasDevice.getExecutionDevices();

      return devices[0];

  return getHostDevice(op->getContext());
}

void M::MOGG::copyKernelDecls(mlir::ModuleOp src, mlir::ModuleOp dst) {
  // Idempotent: a mapping attribute means `dst` is already seeded (e.g. by a
  // prior compile, or in re-imported textual MLIR), and re-cloning the decls
  // would redefine their symbols.
  if (dst->hasAttr(kOpaqueTypeMappingAttrName))
    return;

  mlir::OpBuilder builder(dst.getContext());
  builder.setInsertionPointToEnd(dst.getBody());
  for (auto decl : src.getOps<KernelDeclOp>())
    builder.clone(*decl.getOperation());
  for (auto decl : src.getOps<PrimitiveDeclOp>())
    builder.clone(*decl.getOperation());
  for (auto decl : src.getOps<ShapeFunctionDeclOp>())
    builder.clone(*decl.getOperation());

  // Also carry over the opaque-type mapping so `mogg-rewrite-opaque-types`
  // can run on `dst` without re-loading any packages.
  if (auto mapping = src->getAttrOfType<mlir::DictionaryAttr>(
          kOpaqueTypeMappingAttrName)) {
    dst->setAttr(kOpaqueTypeMappingAttrName, mapping);
  }
}

/// Owns the parser state needed to resolve module names and walk the module
/// import directories. One instance serves any number of resolutions, so
/// callers pay the `SharedState` construction cost (config read, dialect
/// preloading) once.
class LITModuleResolver {
public:
  explicit LITModuleResolver(mlir::MLIRContext *ctx)
      : config(ctx, options), sharedState(sourceMgr, config) {}

  /// Resolve `moduleName` to the path of its precompiled binary package.
  ErrorOr<std::string> resolveBinaryPackagePath(llvm::StringRef moduleName) {
    auto modulePath = sharedState.getModuleLoader().resolveModulePath(
        moduleName, llvm::SMLoc());
    if (!modulePath)
      return Error(
          llvm::formatv("Failed to resolve module path for `{}`", moduleName)
              .str());
    if (!modulePath->isPrecompiled()) {
      return Error(
          llvm::formatv("Resolved module path for `{}` to source directory "
                        "`{}` but a .mojoc precompiled file was expected "
                        "instead",
                        moduleName, modulePath->path)
              .str());
    }
    return modulePath->path;
  }

  KGEN::LIT::SharedState &getSharedState() { return sharedState; }

private:
  // Order matters: `config` refers to `options`, `sharedState` to both.
  llvm::SourceMgr sourceMgr;
  KGEN::CompilationOptions options;
  KGEN::LIT::ParserConfig config;
  KGEN::LIT::SharedState sharedState;
};

ErrorOr<llvm::SmallVector<std::string>>
resolveBuiltInKernelPackagePaths(LITModuleResolver &resolver) {
  llvm::SmallVector<std::string> paths;
  for (llvm::StringRef moduleName : kMoggRequiredKernelModuleNames) {
    auto pathOr = resolver.resolveBinaryPackagePath(moduleName);
    if (pathOr.isError())
      return pathOr.takeError();
    paths.push_back(*pathOr);
  }

  // Skipped rather than fatal: a tree without these still has a complete
  // registry of the open-source kernels, and a graph that uses one of their
  // ops fails later with that op unresolved rather than here with every op
  // unresolved.
  for (llvm::StringRef moduleName : kMoggOptionalKernelModuleNames) {
    auto pathOr = resolver.resolveBinaryPackagePath(moduleName);
    if (!pathOr.isError())
      paths.push_back(*pathOr);
  }

  return paths;
}

} // namespace

ErrorOr<llvm::SmallVector<std::string>>
M::MOGG::getBuiltInKernelPackagePaths(mlir::MLIRContext *ctx) {
  LITModuleResolver resolver(ctx);
  return resolveBuiltInKernelPackagePaths(resolver);
}

ErrorOr<llvm::SmallVector<std::string>>
M::MOGG::getKernelPackagePathsForCacheKey(mlir::MLIRContext *ctx) {
  LITModuleResolver resolver(ctx);

  // The built-in packages are required; fail loudly if they don't resolve.
  auto pathsOr = resolveBuiltInKernelPackagePaths(resolver);
  if (pathsOr.isError())
    return pathsOr.takeError();
  llvm::SmallVector<std::string> paths = std::move(*pathsOr);

  // Collect every binary package visible on the import path; the header
  // comment explains why their contents must reach the cache key.
  llvm::StringSet<> seen;
  resolver.getSharedState().getModuleLoader().traverseImportDirectories(
      /*importBufferFileId=*/0, [&](llvm::StringRef dir) {
        std::error_code ec;
        for (llvm::sys::fs::directory_iterator it(dir, ec), e; it != e && !ec;
             it.increment(ec)) {
          const std::string &path = it->path();
          if (M::Filesystem::isMojoBinaryPackagePath(path))
            seen.insert(path);
        }
        return mlir::WalkResult::advance();
      });
  // Append the collected packages, minus the built-ins already in `paths`,
  // sorted for a deterministic order independent of directory iteration.
  llvm::SmallVector<std::string> found;
  for (const auto &entry : seen)
    if (!llvm::is_contained(paths, entry.getKey()))
      found.push_back(entry.getKey().str());
  llvm::sort(found);
  llvm::append_range(paths, found);
  return paths;
}

static bool isStaticStringLoweredPattern(Type ty) {
  auto structTy = dyn_cast<KGEN::StructType>(ty);
  if (!structTy || structTy.getIsParamPack())
    return false;

  std::optional<SmallVector<Type>> elementTypes = structTy.getElementTypes();
  if (!elementTypes || elementTypes->size() != 2)
    return false;

  auto ptrTy = dyn_cast<KGEN::PointerType>((*elementTypes)[0]);
  if (!ptrTy || !isa<KGEN::NoneType>(ptrTy.getElementType()))
    return false;

  return isa<IndexType>((*elementTypes)[1]);
}

static bool isLITStaticStringType(Type ty) {
  auto structTy = KGEN::sugarDynCast<KGEN::LIT::StructType>(ty);
  if (!structTy) {
    if (auto ref = KGEN::sugarDynCast<KGEN::LIT::RefType>(ty)) {
      structTy =
          KGEN::sugarDynCast<KGEN::LIT::StructType>(ref.getElementType());
    }
  }
  if (!structTy)
    return false;

  auto symbol = structTy.getSymbol();
  std::string symbolName =
      llvm::formatv("{}::{}", symbol.getRootReference().strref(),
                    symbol.getLeafReference().strref())
          .str();
  if (symbolName != kMojoInternalStaticStringTypeName)
    return false;

  auto paramValues = structTy.getParamValues();
  if (paramValues.empty())
    return false;

  TypedAttr originAttr = paramValues[0];
  if (KGEN::sugarIsa<KGEN::ParamDeclRefAttr>(originAttr))
    return false;

  return true;
}

static StringAttr maybeDemangleName(StringAttr name) {
  StringRef demangled = KGEN::demangleParameterName(name);
  if (demangled != name)
    return StringAttr::get(name.getContext(), demangled);
  return name;
}

/// Return the "root::leaf" name of a parameter's declared struct type, or
/// null for non-structs. Distinguishes e.g. `std::StaticString` from
/// `std::StringSpan`, which the bare KGEN type does not.
static StringAttr getParamTypeName(MLIRContext *ctx, Type paramType) {
  if (auto ref = KGEN::sugarDynCast<KGEN::LIT::RefType>(paramType))
    paramType = ref.getElementType();
  auto structTy = KGEN::sugarDynCast<KGEN::LIT::StructType>(paramType);
  if (!structTy)
    return nullptr;
  auto sym = structTy.getSymbol();
  return StringAttr::get(ctx, llvm::formatv("{}::{}",
                                            sym.getRootReference().strref(),
                                            sym.getLeafReference().strref())
                                  .str());
}

static ErrorOrSuccess validateCustomOpParameters(const MojoRegistry &registry,
                                                 MO::CustomOp customOp) {
  if (!registry.containsKernel(customOp.getSymbol())) {
    return Error(
        llvm::formatv("no kernel registered for '{}'", customOp.getSymbol())
            .str());
  }
  auto declOpOr =
      registry.getResolvedKernel(customOp.getSymbol(), customOp.getDevice());
  if (declOpOr.isError())
    return declOpOr.takeError();
  KernelDeclOp declOp = *declOpOr;
  // The user-supplied `parameters` dict on `mo.custom` can target struct-level
  // compile-time params (e.g. `[interleaved: Bool]`) or any fn-level params
  // declared on the registered functions. Collect struct params first to
  // mirror Mojo's merged `@register` parameter layout, then union the param
  // lists from each function variant (some kernels declare params only on
  // `elementwise` instead of `execute`).
  SmallVector<KGEN::ParamDeclAttr> inputParamsVec;
  llvm::SmallDenseSet<StringRef> seen;
  auto append = [&](KGEN::ParamDeclAttr p) {
    if (seen.insert(p.getName().strref()).second)
      inputParamsVec.push_back(p);
  };
  for (auto a : declOp.getStructParams())
    append(cast<KGEN::ParamDeclAttr>(a));
  auto appendFn = [&](std::optional<MOGG::KernelFunctionAttr> fn) {
    if (!fn)
      return;
    for (auto a : fn->getParams())
      append(cast<KGEN::ParamDeclAttr>(a));
  };
  appendFn(declOp.getExecute());
  appendFn(declOp.getElementwise());
  if (registry.containsShapeFunction(declOp.getRegistration()))
    appendFn(
        registry.lookupShapeFunction(declOp.getRegistration()).getFunction());
  ArrayRef<KGEN::ParamDeclAttr> inputParams = inputParamsVec;

  struct MojoParameterAdaptor {
    KGEN::ParamDeclAttr attr;
    StringAttr typeName;
  };
  llvm::DenseMap<StringAttr, MojoParameterAdaptor> paramDecls;

  MLIRContext *ctx = customOp.getContext();
  for (auto param : inputParams)
    paramDecls[maybeDemangleName(param.getName())] = {
        param, getParamTypeName(ctx, param.getType())};

  for (const NamedAttribute &namedAttr : customOp.getParameters()) {
    auto it = paramDecls.find(namedAttr.getName());
    if (it == paramDecls.end()) {
      return Error(llvm::formatv(
          "parameter '{}' supplied to custom op '{}' does not exist in the "
          "corresponding Mojo code",
          namedAttr.getName().strref(), customOp.getSymbol()));
    }

    auto [customParamDecl, typeName] = it->second;
    Attribute mlirParamAttr = namedAttr.getValue();

    Type kgenParamTy = customParamDecl.getType();
    auto asIntegerType = dyn_cast<IntegerType>(kgenParamTy);

    if (isa<IndexType>(kgenParamTy)) {
      auto asInt = dyn_cast<IntegerAttr>(mlirParamAttr);
      if (asInt == nullptr) {
        return Error(llvm::formatv(
            "failed to convert custom op '{}' attribute '{}' with value '{}' "
            "to the proper Mojo parameter type: expected an integer type",
            customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
      }
    } else if (asIntegerType && asIntegerType.getWidth() == 1) {
      auto asBool = dyn_cast<BoolAttr>(mlirParamAttr);
      if (asBool == nullptr) {
        return Error(llvm::formatv(
            "failed to convert custom op '{}' attribute '{}' with value '{}' "
            "to the proper Mojo parameter type: expected an boolean type",
            customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
      }
    } else if (isa<KGEN::StringType>(kgenParamTy)) {
      if (typeName && typeName == MOGG::kMojoInternalStaticStringTypeName) {
        [[maybe_unused]] auto asString = dyn_cast<StringAttr>(mlirParamAttr);
        ASSERT_STREAM(asString != nullptr,
                      "failed to convert custom op attribute "
                          << mlirParamAttr
                          << " to expected mojo kernel param type "
                          << kgenParamTy << ": expected string type");
      } else if (typeName) {
        return Error(llvm::formatv(
            "in custom op '{}' attribute '{}' uses a string-like type that is "
            "not supported. Use type StaticString instead to define a string "
            "parameter for a custom op.",
            customOp.getSymbol(), customParamDecl.getName()));
      } else {
        [[maybe_unused]] auto asString = dyn_cast<StringAttr>(mlirParamAttr);
        ASSERT_STREAM(asString != nullptr,
                      "failed to convert custom op attribute "
                          << mlirParamAttr
                          << " to expected mojo kernel param type "
                          << kgenParamTy << ": expected string type");
      }
    } else if (isa<KGEN::DTypeType>(kgenParamTy)) {
      auto asType = dyn_cast<TypeAttr>(mlirParamAttr);
      if (asType == nullptr) {
        return Error(llvm::formatv(
            "failed to convert custom op '{}' attribute '{}' with value '{}' "
            "to the proper Mojo parameter type: expected a DType",
            customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
      }
    } else if (typeName && typeName == MOGG::kMojoDtypeTypeName) {
      auto asType = dyn_cast<TypeAttr>(mlirParamAttr);
      if (asType == nullptr) {
        return Error(llvm::formatv(
            "failed to convert custom op '{}' attribute '{}' with value '{}' "
            "to the proper Mojo parameter type: expected a DType",
            customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
      }
    } else if (typeName && typeName == MOGG::kMojoStaticStringTypeName) {
      auto asString = dyn_cast<StringAttr>(mlirParamAttr);
      if (asString == nullptr) {
        return Error(llvm::formatv(
            "failed to convert custom op '{}' attribute '{}' with value '{}' "
            "to the proper Mojo parameter type: expected string type",
            customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
      }
    } else if (typeName &&
               typeName == MOGG::kMojoInternalStaticStringTypeName) {
      bool isStaticString = isLITStaticStringType(kgenParamTy) ||
                            isStaticStringLoweredPattern(kgenParamTy);
      if (isStaticString) {
        auto asString = dyn_cast<StringAttr>(mlirParamAttr);
        if (asString == nullptr) {
          return Error(llvm::formatv(
              "failed to convert custom op '{}' attribute '{}' with value "
              "'{}' to the proper Mojo parameter type: expected string type",
              customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
        }
      } else {
        return Error(llvm::formatv(
            "in custom op '{}' attribute '{}' uses type StringSpan. Use type "
            "StaticString instead to define a string parameter for a custom "
            "op.",
            customOp.getSymbol(), customParamDecl.getName()));
      }
    } else if (typeName && (typeName == MOGG::kMojoInternalDpsSimdTypeName)) {
      // `Float32` (SIMD[f32, 1]) params arrive as the same rank-0 f32
      // elements attribute the RMS norm ops use for their scalar
      // attributes (see `MO_F32ScalarAttr`); integer SIMD params arrive
      // as `IntegerAttr`. Only f32 matches here: `MO_F32ScalarAttr` and
      // the Python side (`rms_norm._float32_attr`) are f32-only. A float
      // value against an integer SIMD param is not caught here — this
      // branch keys on the SIMD kind, not the element type — and fails
      // later, at Mojo elaboration.
      if (auto elems = dyn_cast<ElementsAttr>(mlirParamAttr);
          elems && elems.getShapedType().getRank() == 0 &&
          elems.getElementType().isF32())
        continue;
      auto asInt = dyn_cast<IntegerAttr>(mlirParamAttr);
      if (asInt == nullptr) {
        return Error(llvm::formatv(
            "failed to convert custom op '{}' attribute '{}' with value '{}' "
            "to the proper Mojo parameter type: expected an integer type",
            customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
      }
    } else if (typeName && typeName == MOGG::kMojoInternalDpsBoolTypeName) {
      auto asBool = dyn_cast<BoolAttr>(mlirParamAttr);
      if (asBool == nullptr) {
        return Error(llvm::formatv(
            "failed to convert custom op '{}' attribute '{}' with value '{}' "
            "to the proper Mojo parameter type: expected a boolean type",
            customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
      }
    } else if (typeName &&
               (typeName == MOGG::kMojoInternalStringSliceTypeName ||
                typeName == MOGG::kMojoStringTypeName)) {
      std::string userTypeName =
          typeName == MOGG::kMojoInternalStringSliceTypeName ? "StringSpan"
                                                             : "String";
      return Error(llvm::formatv(
          "in custom op '{}' attribute '{}' uses type {}. Use type "
          "StaticString instead to define a string parameter for a custom op.",
          customOp.getSymbol(), customParamDecl.getName(), userTypeName));
    } else if (!typeName && isStaticStringLoweredPattern(kgenParamTy)) {
      auto asString = dyn_cast<StringAttr>(mlirParamAttr);
      if (asString == nullptr) {
        return Error(llvm::formatv(
            "failed to convert custom op '{}' attribute '{}' with value '{}' "
            "to the proper Mojo parameter type: expected string type",
            customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr));
      }
    } else {
      return Error(llvm::formatv(
          "failed to convert custom op '{}' attribute '{}' with value '{}' to "
          "the proper Mojo parameter type: no type conversion found to type "
          "'{}'",
          customOp.getSymbol(), customParamDecl.getName(), mlirParamAttr,
          kgenParamTy));
    }
  }

  return success();
}

} // namespace M::MOGG

ErrorOrSuccess M::MOGG::verifyCustomOp(const MojoRegistry &registry,
                                       mlir::Operation *op) {
  MojoOperationInfo info = getMojoOperationInfo(op);
  if (info.operationName.empty())
    return Error(llvm::formatv("operation '{}' has no registered Mojo kernel",
                               op->getName().getStringRef())
                     .str());

  if (!registry.containsKernel(info.operationName)) {
    return Error(
        llvm::formatv("no kernel registered for '{}'", info.operationName)
            .str());
  }

  // Catch MO-vs-kernel operand type mismatches before lowering emits Mojo.
  DeviceRefAttr device = MojoRegistry::getDeviceRefForOp(op);
  auto declOpOr = registry.getResolvedKernel(info.operationName, device);
  if (declOpOr.isError())
    return declOpOr.takeError();
  KernelDeclAdaptor adaptor(*declOpOr);
  if (adaptor.isReduction()) {
    StringRef name = info.operationName;
    if (op->getNumOperands() != 1)
      return Error(llvm::formatv("reduction '{}' takes one input, got {}", name,
                                 op->getNumOperands())
                       .str());
    size_t numFields = adaptor.reduction->getOutputs().size();
    if (op->getNumResults() != numFields)
      return Error(llvm::formatv("reduction '{}' has {} output fields, but the "
                                 "op has {} results",
                                 name, numFields, op->getNumResults())
                       .str());
    ErrorOr<int64_t> axis =
        MO::getReductionAxis(op->getOperand(0), op->getResultTypes());
    if (axis.isError())
      return Error(
          llvm::formatv("reduction '{}' {}", name, axis.getError()).str());
  } else {
    if (!adaptor.executeFunction)
      return Error(llvm::formatv("kernel '{}' has no execute function",
                                 info.operationName)
                       .str());
    auto mappingOr =
        mapMOOpToKernelImplementation(op, *adaptor.executeFunction);
    if (mappingOr.isError())
      return mappingOr.takeError();
  }

  // For mo.custom, additionally check that user-supplied params match the
  // kernel's compile-time parameter list (struct + fn-level).
  if (auto custom = mlir::dyn_cast<MO::CustomOp>(op))
    return validateCustomOpParameters(registry, custom);

  return success();
}

ErrorOrSuccess M::MOGG::verifyCustomOp(mlir::ModuleOp kernelDecls,
                                       mlir::Operation *op) {
  MojoRegistry registry(kernelDecls);
  return verifyCustomOp(registry, op);
}
