Device specifications and native contexts

The complete copied answer from the S1 walkthrough.

QnA 1 · What are spec and context, and what do DC1 and DCPU1 contain?

spec describes the device. context refers to the native object through which MAX performs work on that device. The actual stored structure is:

struct ConfiguredDevice {
  DeviceSpecRef spec;
  M::Driver::DeviceContextRef context;
};

Source: EngineConfig.h.

The displayed spec: ("gpu", 0) is shorthand. The full specification contains:

spec → M::DeviceSpec
├─ ref
│  ├─ label = "gpu"
│  └─ id    = 0
└─ target
   ├─ triple
   ├─ arch
   ├─ features
   ├─ disabledFeatures
   └─ abi

ref identifies the device used by the graph. target describes compiler target information. For CPU0, ref is {"cpu", 0} and this constructor fills target from getHostTargetInfo(). The corresponding Python GPU construction path initially leaves target at its defaults. Sources: DeviceSpecs.h, device construction.

context: DC1 means a reference to an existing device-execution object. GPU contexts support operations such as memory allocation, transfers, kernel launches, and synchronization. (max.modular.com)

For an NVIDIA/CUDA example, the object behind DC1 can be represented as:

DC1 → M::Driver::CUDADeviceContext
├─ device().api() = "cuda"
├─ device().id()  = 0
├─ driver_       → CUDADriver: CUDA API access
├─ context_      → CUcontext: CUDA driver context handle
├─ stream_       → CUstream: stream created by cuStreamCreate
└─ streamPool_   → [stream_] initially

CUcontext and CUstream are opaque handles whose numerical values are assigned at runtime. The tree shows their meanings; an actual address requires inspecting the running process. MAX initially places the created stream in stream-pool slot 0. Source: CUDA context creation and initialization.

For a freshly constructed CPU context, the object is:

DCPU1 → M::Driver::CpuDeviceContext
├─ device().api() = "cpu"
├─ device().id()  = 0
├─ cpuDevice     → AsyncRT::CPUDevice
│                  └─ CPU scheduling / work-queue services
├─ streamChain   → initially READY asynchronous chain
└─ streamChainMutex → mutex protecting that chain

The CPU constructor obtains an AsyncRT CPU runtime and initializes streamChain from its ready chain. Source: CpuDeviceContext.cpp.

Where do these references come from? GPU0 and CPU0 already hold deviceSpec and ctx. The session constructor executes:

runtimeConfig.addDevice(
    {std::make_shared<const M::DeviceSpec>(device->deviceSpec),
     device->ctx});

This creates an immutable copy of the specification and retains a reference to the existing context:

GPU0.ctx ────────────────► DC1
runtimeConfig.devices[0].context ──► same DC1

CPU0.ctx ────────────────► DCPU1
runtimeConfig.devices[1].context ──► same DCPU1

Source: InferenceSession.cpp.

Later, model setup builds this mapping:

spec.ref ("gpu", 0) ──► DC1
spec.ref ("cpu", 0) ──► DCPU1

This connects a graph’s device identity to the native context that performs its runtime operations. Source: EngineContext.cpp.

/// Result of decoding a signed LLVM feature string.
struct DecodedFeatures {
  std::vector<std::string> enabled;  ///< Plain names of enabled features.
  std::vector<std::string> disabled; ///< Plain names of disabled features.

/// Decodes a signed LLVM feature string (e.g. "+avx2,+bmi1,-avx512f") into
/// separate enabled and disabled plain-name lists. Applies last-wins semantics
/// so duplicate names resolve to the final sign. Unsigned names (no prefix)
/// are treated as enabled for backward compat with older serialized data.
/// Returns an error if a sign prefix has no name after it.
ErrorOr<DecodedFeatures> decodeFeatures(StringRef encodedFeatures);

/// Runtime analogue of part of TargetInfoAttr.
///
/// See also HostMachineInfo and PackageTarget which have similar
/// structure.
struct TargetInfo {
  llvm::Triple triple;
  std::string arch;

  /// Enabled CPU features, as plain unsigned names (e.g. "avx2").
  std::vector<std::string> features;

  /// CPU features that are explicitly disabled (e.g. "avx512f"). These are
  /// present in the CPU model's defaults but unavailable at runtime.
  /// See getHostTargetInfo() for why this field exists.
  std::vector<std::string> disabledFeatures;

  /// The target ABI name (e.g. RISC-V's `lp64d`), mirroring `TargetInfoAttr`'s
  /// `abi`. Empty means no ABI constraint.
  std::string abi;

  TargetInfo(llvm::Triple triple = llvm::Triple(""), std::string arch = {},
             std::vector<std::string> &&features = {},
             std::vector<std::string> &&disabledFeatures = {},
             std::string abi = {})
      : triple(std::move(triple)), arch(std::move(arch)),
        features(std::move(features)),
        disabledFeatures(std::move(disabledFeatures)), abi(std::move(abi)) {}

  /// Serializes this target info to JSON.
  void serializeToJSON(llvm::json::OStream &json) const;
  std::string serializeToJSON() const;

  /// Returns the target info deserialized from JSON.
  static ErrorOr<TargetInfo> deserializeFromJSON(const llvm::json::Value *json);
  static ErrorOr<TargetInfo> deserializeFromJSON(StringRef json);

  /// Returns error if this target info does not satisfy the assumptions
  /// in required.
  ErrorOrSuccess checkSatisfiesRequirements(const TargetInfo &required) const;
};

/// Encodes a TargetInfo's features into the signed string form expected by
/// LLVM (e.g. "+avx2,+bmi1,-avx512f").
std::string encodeFeatures(const TargetInfo &targetInfo);

/// Compile time index of a particular abstract device amongst others with the
/// same or similar target info. The relationship between the device id
/// used in an #M.device_spec and an actual physical device (eg a CUDA device
/// id) is determined at runtime.
using DeviceId = uint64_t;

struct DeviceRef {
  std::string label;
  DeviceId id;

  explicit DeviceRef(std::string label = {}, DeviceId id = 0)
      : label(std::move(label)), id(id) {}

  /// Serialized this device ref to JSON.
  void serializeToJSON(llvm::json::OStream &json) const;

  /// Returns the device ref deserialized from JSON.
  static ErrorOr<DeviceRef> deserializeFromJSON(const llvm::json::Value *json);

  /// Returns device reference in compact string form.
  std::string toString() const;

  bool operator==(const DeviceRef &that) const {
    return std::tie(label, id) == std::tie(that.label, that.id);
  }
};

/// A shared, immutable `DeviceSpec`. A spec owns a `TargetInfo` -- a triple,
/// an arch string and two feature vectors -- so copying one per tensor is far
/// from free, and on the host path `getHostTargetInfo()` fills those vectors
/// in. The runtime keeps one spec per configured device for the session and
/// hands out this handle instead; consumers that only compare `ref` pay a
/// refcount rather than a dozen allocations.
using DeviceSpecRef = std::shared_ptr<const DeviceSpec>;

/// Returns true if `feature` is enabled in a comma-separated signed LLVM
/// feature string (e.g. "+avx2,+bmi1,-avx512f"). Scans tokens exactly;
/// disabled tokens ("-feature") and prefix matches (e.g. "avx512" against
/// "+avx512f") both return false.
bool hasFeature(StringRef llvmFeatureStr, StringRef feature);

/// Returns the SIMD bit width implied by a single plain (unsigned) feature
/// name, e.g. "avx512f" → 512, "avx2" → 256, "hvx-length128b" → 1024,
/// anything else → 128. The result is in bits, whatever unit the feature
/// spells its length in.
///
/// This feeds `TargetInfoAttr`'s `simd_bit_width`, which is the width of one
/// vector register as seen by a *single execution context* — one CPU thread,
/// one GPU lane, one DSP hardware thread. It is not the width of the whole
/// vector unit and it is not scaled by how many contexts run together, which
/// is why every GPU target declares 128 (the widest per-lane vector access)
/// rather than a warp-sized number, and why a DSP whose one thread owns a
/// 128-byte vector register declares 1024. A target's entry answers "how much
/// work fits in one register here", so that a kernel deriving its vector shape
/// from the field lands on a shape the target can issue.
size_t simdWidthFromFeature(StringRef plainFeature);

/// Returns the SIMD bit width implied by a comma-separated signed LLVM feature
/// string (e.g. "+avx2,+bmi1,-avx512f"). Disabled features (leading '-') are
/// ignored. Assumes no duplicate feature names; use decodeFeatures first if
/// the source string may contain duplicates.
size_t simdWidthFromFeatures(StringRef llvmFeatureStr);

/// Returns the SIMD bit width implied by a list of plain (unsigned) feature
/// names.
size_t simdWidthFromFeatures(ArrayRef<std::string> plainFeatures);

M::AsyncRT::CPUDeviceRef Python::CPU::getAsyncRTCPUDevice() const {
  // `Python::CPU` is only constructed by `getCpuDevice`, which creates the
  // context against `Device::cpuAPI`, so it is always a `CpuDeviceContext`.
  // The downcast helper asserts this contract.
#if MODULAR_HAL_DEVICE_CONTEXT
  // The HAL DeviceContext has no CpuDeviceContext subclass to reach through.
  // Use the same process-wide AsyncRT CPUDevice that CpuDeviceContext creates
  // (same source and options), so all consumers share one CPUDevice.
  M::AsyncRT::CPUDeviceRef cpuDevice = M::AsyncRT::getOrCreateCPUDevice(
      M::AsyncRT::CPUDeviceSource::CPUDeviceContext,
      M::AsyncRT::CPUDeviceOptions().withMainWillNotDonate(),
      /*allowUsingExistingOptions=*/true);
#else
  const M::Driver::CpuDeviceContext &cpuCtx =
      M::Driver::CpuDeviceContext::cast(*ctx);
  M::AsyncRT::CPUDeviceRef cpuDevice = cpuCtx.getCPUDevice();
#endif
  if (!cpuDevice) {
    throw std::runtime_error(
        "max.driver.CPU has no associated AsyncRT CPUDevice");
  }
  return cpuDevice;
}

std::string Python::Device::getStats() const {
  nb::gil_scoped_release release;
  ErrorOr<M::Driver::Device::MemInfo> infoOr = ctx->getMemoryInfo();
  if (infoOr.isError()) {
    std::string errorMessage =
        "failed to get device stats: "s + infoOr.getError();
    throw std::runtime_error(errorMessage);
  }
  M::Driver::Device::MemInfo info = infoOr.get();

  std::string s;
  llvm::raw_string_ostream os(s);
  llvm::json::OStream j(os);

  j.object([&] {
    j.attribute("free_memory", info.free);
    j.attribute("total_memory", info.total);
    ErrorOr<M::Driver::Device::GraphMemInfo> graphMemResult =
        ctx->device().getGraphMemoryInfo();
    if (!graphMemResult.isError()) {
      M::Driver::Device::GraphMemInfo graphMem = graphMemResult.takeValue();
      j.attribute("graph_mem_reserved", graphMem.reserved);
      j.attribute("graph_mem_used", graphMem.used);
    }
  });

  os.flush();
  return s;
}

void Python::Device::synchronize() const {

  nb::gil_scoped_release release;
  if (auto errOr = ctx->synchronize(); errOr.isError())
    throw std::runtime_error(errOr.getError());
}

// Owns the Python callable whose refcount must be managed under the GIL.
struct HostFuncUserData {
  nb::object fn;
};

// Invoked by the CUDA driver thread after all preceding stream work has
// completed. No GIL is held on entry.
//
// The GIL must be acquired before taking ownership of `rawUserData`. The
// `unique_ptr` destructor decrements the contained `nb::object`'s Python
// refcount, which is only legal with the GIL held. Declaring `userData`
// after `gil` guarantees the correct destruction order.
void hostFuncTrampoline(void *rawUserData) {
  nb::gil_scoped_acquire gil;
  std::unique_ptr<HostFuncUserData> userData(
      static_cast<HostFuncUserData *>(rawUserData));
  try {
    userData->fn();
  } catch (nb::python_error &e) {
    e.restore();
    PyErr_Print();
  } catch (const std::exception &e) {
    PySys_WriteStderr("host callback raised C++ exception: %s\n", e.what());
  }
}

} // namespace

void Python::DeviceStream::enqueueHostFunc(nb::callable &&fn) const {
  auto userData =
      std::make_unique<HostFuncUserData>(HostFuncUserData{std::move(fn)});

  ErrorOr<M::Driver::DeviceStreamRef> mlrtStream = stream->ctx->stream();
  if (mlrtStream.isError())
    throw std::runtime_error(mlrtStream.getError());

  ErrorOrSuccess err = [&] {
    nb::gil_scoped_release release;
    return (*mlrtStream)->enqueueHostFunc(&hostFuncTrampoline, userData.get());
  }();
  if (err.isError())
    throw std::runtime_error(err.getError());

  (void)userData.release();
}

std::tuple<uintptr_t, uintptr_t> Python::packHostFunc(nb::callable fn) {
  auto *userData = new HostFuncUserData{std::move(fn)};
  return {reinterpret_cast<uintptr_t>(&hostFuncTrampoline),
          reinterpret_cast<uintptr_t>(userData)};
}

// CUDA host function. Runs on a CUDA driver thread once the stream
// reaches this node. No GIL on entry. Must return promptly so the
// stream can continue. Dispatches the Python callable onto the
// explicit AsyncRT CPUDevice carried in `userData`, then returns.
//
// The AsyncRT worker re-acquires the GIL, invokes the callable,
// releases the GIL, then signals the flag with `signalValue` (release
// ordering, encapsulated in `CompletionFlag::signal`). A
// `cuStreamWaitValue64` node placed later on the same stream observes
// the value and lets downstream work proceed.
//
// Lifetime split: the outer `AsyncHostFuncUserData` block (which
// includes the `CPUDeviceRef` we dispatch through) is owned by this
// trampoline's stack and freed before returning to CUDA. The inner
// `AsyncHostFuncTaskData` is moved into a separate heap allocation
// owned by the worker closure, so the worker carries only the data it
// actually reads.
void asyncHostFuncTrampoline(void *rawUserData) {
  // Take ownership of the outer block with RAII.
  std::unique_ptr<Python::Detail::AsyncHostFuncUserData> userData(
      static_cast<Python::Detail::AsyncHostFuncUserData *>(rawUserData));

  // Clear the flag before the worker runs. cuStreamWaitValue64 sees 0
  // until the worker calls `signal`.
  userData->task.flagRef->reset();

  // Move the task data into its own heap allocation owned by a
  // shared_ptr with a GIL-aware deleter so the `nb::object`'s
  // Py_DECREF runs under the GIL when the worker finishes.
  auto taskData = std::shared_ptr<Python::Detail::AsyncHostFuncTaskData>(
      new Python::Detail::AsyncHostFuncTaskData(std::move(userData->task)),
      [](Python::Detail::AsyncHostFuncTaskData *p) {
        nb::gil_scoped_acquire gil;
        delete p;
      });

  // Dispatch onto a non-device worker so the callback doesn't contend
  // with the per-GPU command-dispatch worker threads. Outside of cuGraph
  // capture this matters most: a callback that lands on a device-pinned
  // worker can stall GPU command submission. See
  // `MLRT::taskIdForNonDevice`.
  M::AsyncRT::CPUDevice &cpuDevice = *userData->cpuDeviceRef;
  std::size_t numWorkers = cpuDevice.getWorkQueue()->getParallelismLevel();
  M::AsyncRT::addTask(
      cpuDevice,
      [taskData = std::move(taskData)] {
        std::uint64_t value = taskData->signalValue;
        {
          nb::gil_scoped_acquire gil;
          try {
            taskData->fn();
          } catch (nb::python_error &e) {
            e.restore();
            PyErr_Print();
          } catch (const std::exception &e) {
            PySys_WriteStderr("async host callback raised C++ exception: %s\n",
                              e.what());
          }
        } // GIL released here before the signal store.
        // signal() does a release-ordered store: result stores in `fn`
        // are visible before the GPU-side `cuStreamWaitValue64`
        // observes the value.
        taskData->flagRef->signal(value);
      },
      M::MLRT::taskIdForNonDevice(0, numWorkers));
}

} // namespace

void Python::DeviceStream::enqueueAsyncHostFunc(nb::callable &&fn,
                                                const CompletionFlag &flag,
                                                uint64_t value,
                                                const CPU &cpu) const {
  // Eagerly construct the user-data block at enqueue time; the factory
  // pulls `cpu`'s `CPUDeviceRef` and raises a clear Python error if
  // `cpu` is malformed (rather than crashing on a null deref in the
  // trampoline).
  auto userData = cpu.makeAsyncHostFuncUserData(std::move(fn), flag, value);

  ErrorOr<M::Driver::DeviceStreamRef> mlrtStream = stream->ctx->stream();
  if (mlrtStream.isError())
    throw std::runtime_error(mlrtStream.getError());

  ErrorOrSuccess err = [&] {
    nb::gil_scoped_release release;
    return (*mlrtStream)
        ->enqueueHostFunc(&asyncHostFuncTrampoline, userData.get());
  }();
  if (err.isError())
    throw std::runtime_error(err.getError());

  (void)userData.release();
}

uintptr_t Python::DeviceStream::nativeStreamHandle() const {
  // Mirrors getAsString's extraction: ask the device context for its native
  // stream and return the raw pointer. 0 when there is none (e.g. a CPU
  // device), which native callers treat as "no stream". Non-zero means a
  // CUstream / hipStream_t to callers, so other backends report 0.
  M::Driver::Device::API api = stream->ctx->device().api();
  if (api != M::Driver::Device::cudaAPI && api != M::Driver::Device::hipAPI)
    return 0;
  auto err = stream->ctx->stream();
  if (err.isError())
    return 0;
  return reinterpret_cast<uintptr_t>((*err)->ptr());
}

// The accelerator cache stores `weak_ptr`s so that GPU devices can be properly
// released. Otherwise, some resources owned by the device are held too long,
// and can cause segfaults if multiple models are run one after another.
template <class DeviceType>
class WeakDeviceCache {
public:
  std::shared_ptr<DeviceType> find(ssize_t key) {
    // If we have a cache entry that hasn't been freed yet, we just return it.
    if (auto it = map.find(key); it != map.end())
      if (std::shared_ptr<DeviceType> ptr = it->second.lock())
        return ptr;
    return nullptr;
  }

  std::shared_ptr<DeviceType> insert(ssize_t key, M::DeviceSpec spec,
                                     M::Driver::DeviceContextRef ctx) {
    auto shared = std::make_shared<DeviceType>(std::move(spec), std::move(ctx));
    // We use insert_or_assign to overwrite potential freed entries.
    map.insert_or_assign(key, shared);
    return shared;
  }

private:
  llvm::SmallDenseMap<ssize_t, std::weak_ptr<DeviceType>> map;
};

// The CPU cache stores `shared_ptr`s so that CPU devices (and the AsyncRT
// cpuDevice they hold) remain alive for the lifetime of the process.
template <class DeviceType>
class StrongDeviceCache {
public:
  std::shared_ptr<DeviceType> find(ssize_t key) {
    if (auto it = map.find(key); it != map.end())
      return it->second;
    return nullptr;
  }

  std::shared_ptr<DeviceType> insert(ssize_t key, M::DeviceSpec spec,
                                     M::Driver::DeviceContextRef ctx) {
    auto shared = std::make_shared<DeviceType>(std::move(spec), std::move(ctx));
    map.insert_or_assign(key, shared);
    return shared;
  }

private:
  llvm::SmallDenseMap<ssize_t, std::shared_ptr<DeviceType>> map;
};

using CPUCache = StrongDeviceCache<Python::CPU>;
using AcceleratorCache = WeakDeviceCache<Python::Accelerator>;
} // namespace

/// Protects the cache returned by `getCPUCache`.
static std::mutex &getCPUCacheMutex() {
  static std::mutex cacheMutex;
  return cacheMutex;
}

/// Users must acquire the `CPUCacheMutex` first;
static CPUCache &getCPUCache() {
  // Intentionally leaked: the CPU cache holds `shared_ptr<Python::CPU>`, which
  // in turn keeps the AsyncRT cpuDevice alive. At process exit, static-local
  // destructors across translation units run in reverse-of-construction order.
  // The global cpuDevice mutex (in libAsyncRTRuntimeGlobals.dylib) is
  // constructed *after* this cache (on first CpuDeviceContext creation), so it
  // is destroyed *first*. If the cache were then destroyed normally, releasing
  // its shared refs would run `CPUDevice::~Runtime` →
  // `clearGlobalCPUDevicePointerIfEquals`, which locks the already-destroyed
  // mutex — on macOS that returns EINVAL and std::mutex throws, terminating the
  // process (GEX-3583). Leaking the cache matches the stated intent that CPU
  // devices live for the lifetime of the process.
  static CPUCache *cache = new CPUCache{};
  return *cache;
}

using DeviceContextPair = std::pair<M::DeviceSpec, M::Driver::DeviceContextRef>;

/// Builds the CPU (spec, context) pair `M_createCPUDevice` used to produce.
/// The spec's id stays 0 for every numa node, matching the wrapper; only the
/// cache keys on the requested id.
ErrorOr<DeviceContextPair> makeCPUDeviceContext() {
  ErrorOr<TargetInfo> targetOr = M::getHostTargetInfo();
  if (targetOr.isError())
    return targetOr.takeError();

  ErrorOr<M::Driver::DeviceContextRef> ctxOr =
      M::Driver::DeviceContext::create(M::Driver::Device::cpuAPI);
  if (ctxOr.isError())
    return ctxOr.takeError();

  M::DeviceSpec spec;
  spec.ref.id = 0;
  spec.ref.label = kCPULabel;
  spec.target = targetOr.takeValue();
  return DeviceContextPair{std::move(spec), ctxOr.takeValue()};
}

/// Builds the accelerator (spec, context) pair `M_createAcceleratorDevice`
/// used to produce.
ErrorOr<DeviceContextPair> makeAcceleratorDeviceContext(ssize_t deviceId) {
  ErrorOr<M::Driver::DeviceContextRef> ctxOr =
      M::Driver::DeviceContext::getOrCreate(M::Driver::Device::gpuAPI,
                                            deviceId >= 0 ? deviceId : 0);
  if (ctxOr.isError())
    return ctxOr.takeError();

  M::DeviceSpec spec;
  spec.ref.label = kGPULabel;
  spec.ref.id = deviceId;
  return DeviceContextPair{std::move(spec), ctxOr.takeValue()};
}

std::shared_ptr<Python::CPU> Python::getCpuDevice(ssize_t numaId) {
  numaId = numaId >= 0 ? numaId : 0;
  CPUCache &cache = getCPUCache();
  {
    std::lock_guard<std::mutex> lock(getCPUCacheMutex());
    if (auto maybeDevice = cache.find(numaId))
      return maybeDevice;
  }

  ErrorOr<DeviceContextPair> deviceOr = [&] {
    nb::gil_scoped_release release;
    return makeCPUDeviceContext();
  }();
  if (deviceOr.isError()) {
    std::string errorMessage =
        "failed to create device: "s + deviceOr.getError();
    throw std::invalid_argument(errorMessage);
  }
  DeviceContextPair created = deviceOr.takeValue();

  ErrorOrSuccess compatibleOr = [&] {
    nb::gil_scoped_release release;
    return created.second->device().isCompatible();
  }();
  if (compatibleOr.isError())
    throw std::runtime_error(compatibleOr.getError());

  std::lock_guard<std::mutex> lock(getCPUCacheMutex());
  return cache.insert(numaId, std::move(created.first),
                      std::move(created.second));
}

std::shared_ptr<Python::Accelerator> Python::getAccelerator(ssize_t gpuId) {
  gpuId = gpuId >= 0 ? gpuId : 0;
  AcceleratorCache &cache = getAcceleratorCache();
  {
    std::lock_guard<std::mutex> lock(getAcceleratorCacheMutex());
    if (auto maybeDevice = cache.find(gpuId))
      return maybeDevice;
  }

  ErrorOr<DeviceContextPair> deviceOr = [&] {
    nb::gil_scoped_release release;
    return makeAcceleratorDeviceContext(gpuId);

    std::string errorMessage =

    throw std::invalid_argument(errorMessage);
  }
  DeviceContextPair created = deviceOr.takeValue();

  ErrorOrSuccess compatibleOr = [&] {
    nb::gil_scoped_release release;
    return created.second->device().isCompatible();
  }();
  if (compatibleOr.isError())
    throw std::runtime_error(compatibleOr.getError());

  std::lock_guard<std::mutex> lock(getAcceleratorCacheMutex());
  return cache.insert(gpuId, std::move(created.first),
                      std::move(created.second));
}

// Helper class to set and restore the CUcontext around interactions with the
// CUDA driver.
class CUDAContextScope {
public:
  CUDAContextScope(const CUcontext ctx, const CUDADriver &driver)
      : driver_(driver), ctx_(ctx), prevCtx_(nullptr),
        status_(CUDADriver::SUCCESS) {
    driver_.cuCtxGetCurrent(&prevCtx_);
    if (prevCtx_ == ctx_)
      return;
    status_ = driver_.cuCtxSetCurrent(ctx_);
  }

  ~CUDAContextScope() {
    // No need to restore the previous context if no previous context is to be
    // restored, if the context was already the desired context or if there was
    // an error setting the context.
    if ((prevCtx_ == ctx_) || (prevCtx_ == nullptr) ||
        (status_ != CUDADriver::SUCCESS))
      return;

    // Only pop the context if push was necessary and successful.
    CUcontext ctx = nullptr;
    driver_.cuCtxGetCurrent(&ctx);
    driver_.cuCtxSetCurrent(prevCtx_);
    assert(ctx == ctx_);
  }

  CUDADriver::Result status() { return status_; }

private:
  const CUDADriver &driver_;
  const CUcontext ctx_;
  CUcontext prevCtx_;
  CUDADriver::Result status_;
};

static Error formatNVMLError(const char *file, int line, const char *func,
                             NVML::Result result, std::string extra_msg = "") {
  ErrorOr<const NVML &> errNVML = NVML::get();
  const char *errStr = nullptr;

  if (!errNVML) {
    errStr = errNVML->nvmlErrorString(result);
  }

  return DeviceContext::formatError(file, line, func,
                                    llvm::Twine("NVML call failed: ") + errStr +
                                        (extra_msg.empty() ? "" : " - ") +
                                        extra_msg);
}

[[maybe_unused]]
static Error formatCUDAError(const char *file, int line, const char *func,
                             CUDADriver::Result result,
                             std::string extra_msg = "") {
  ErrorOr<const CUDADriver &> errDriver = CUDADriver::get();
  const char *errName = nullptr;
  const char *errStr = nullptr;

  if (!errDriver) {
    // Ignore errors and use nullptr of char* instead.
    errDriver->cuGetErrorName(result, &errName);
    errDriver->cuGetErrorString(result, &errStr);
  }

  if (!extra_msg.empty())
    extra_msg = std::string(" - ") + extra_msg;

  if (errName && errStr) {
    return DeviceContext::formatError(file, line, func,
                                      llvm::Twine("CUDA call failed: ") +
                                          errName + " (" + errStr + ")" +
                                          extra_msg);
  }

  if (errName || errStr) {
    return DeviceContext::formatError(
        file, line, func,
        llvm::Twine("CUDA call failed: ") +
            (errName != nullptr ? errName : errStr) + extra_msg);
  }

  return DeviceContext::formatError(
      file, line, func, "CUDA call failed: " + llvm::Twine(result) + extra_msg);
}

static int cudaCCMonolithic(int major, int minor) { return major * 10 + minor; }

static std::string cudaCCToSM(int major, int minor) {
  std::string sm = "sm_";
  int cc = cudaCCMonolithic(major, minor);
  sm += std::to_string(cc);

  // For architectures above 90 we use the "a" variants to enable hardware
  // specific features at the cost of backward and forward compatibility.
  if (cc >= 90)
    sm += "a";

  return sm;
}

// Finds the NVML handle describing `cuDevice` by matching PCI location.
//
// The two libraries index devices independently: NVML enumerates physical
// GPUs, CUDA enumerates the devices this process may use, and under MIG one
// physical GPU backs several of the latter. Matching on PCI location is what
// holds across that split — every MIG instance resolves to the handle for the
// GPU it is carved from, which is the handle NVML answers parent-level queries
// on anyway.
static ErrorOr<nvmlDevice_t> nvmlDeviceForCudaDevice(const NVML &nvml,
                                                     const CUDADriver &driver,
                                                     CUdevice cuDevice) {
  int domain, bus, slot;
  CUDA_CHECK_ERR(driver.cuDeviceGetAttribute(
      &domain, CUdevice_attribute::PCI_DOMAIN_ID, cuDevice));
  CUDA_CHECK_ERR(driver.cuDeviceGetAttribute(
      &bus, CUdevice_attribute::PCI_BUS_ID, cuDevice));
  CUDA_CHECK_ERR(driver.cuDeviceGetAttribute(
      &slot, CUdevice_attribute::PCI_DEVICE_ID, cuDevice));

  unsigned int nvmlCount;
  NVML_CHECK_ERR(nvml.nvmlDeviceGetCount_v2(&nvmlCount));

  for (unsigned int i = 0; i < nvmlCount; ++i) {
    nvmlDevice_t candidate;
    if (nvml.nvmlDeviceGetHandleByIndex(i, &candidate) != NVML::SUCCESS)
      continue;

    nvmlPciInfo_t pciInfo;
    if (nvml.nvmlDeviceGetPciInfo_v3(candidate, &pciInfo) != NVML::SUCCESS)
      continue;

    if (pciInfo.domain == static_cast<unsigned int>(domain) &&
        pciInfo.bus == static_cast<unsigned int>(bus) &&
        pciInfo.device == static_cast<unsigned int>(slot))
      return candidate;
  }

  RETURN_ERROR("NVML: no device at the PCI location CUDA reports for device " +
               llvm::Twine(static_cast<int>(cuDevice)));
}

CUDADevice::~CUDADevice() {
  // Destroy the function map before destroying the context.
  clearFunctionCache();
  clearMemoryManager();
  // Release the recycled event handles before releasing the primary context.
  // The cached events belong to that context, so they must be destroyed while
  // it is still alive.
  eventCacheClear();
  if (context_ != nullptr)
    // We ignore the result here as there is not much we can do if it fails
    // since in most cases the CUDA driver is in the process of shutting down.
    cudaDriver().cuDevicePrimaryCtxRelease_v2(cudaDevice());
}

ErrorOr<DriverVersion &> CUDADevice::getDriverVersion() const {
  // Initialize the driver version once on first call of this method
  // or remember the error.
  static ErrorOr<std::string> errOrVersion = []() -> ErrorOr<std::string> {
    DEFINE_OR_RETURN_ERROR(const NVML &, nvml, NVML::get());
    DEFINE_OR_RETURN_ERROR(std::string, version, nvml.GetDriverVersion());
    return version;
  }();

  // Propagate the error if getting the version produced an error.
  if (errOrVersion.isError()) {
    return Error(errOrVersion.getError());
  }
  // Return the version string.
  static DriverVersion version(*errOrVersion);
  return version;
}

// The value returned by `cuDriverGetVersion_` from the CUDA API is an integer
// with the API version embedded. The major version number is in the
// thousands place and the minor version number is in the hundreds place, scaled
// up by ten.
static std::string apiVersionToString(int apiVersion) {
  int majorVersion = apiVersion / 1000;
  int minorVersion = (apiVersion % 1000) / 10;

  return (llvm::Twine(majorVersion) + "." + llvm::Twine(minorVersion)).str();
}

ErrorOrSuccess CUDADevice::isCompatible() const {
#if !MODULAR_LINUX
  return Error("NVIDIA GPUs are only supported on Linux based systems.");
#endif

  // When MODULAR_NVPTX_COMPILER_PATH is set, the user is explicitly opting
  // into a fallback compilation path for older drivers or hardware. Skip the
  // minimum version checks since the whole point of the fallback is to bypass
  // our bundled libnvptxcompiler's requirements.
  if (llvm::sys::Process::GetEnv("MODULAR_NVPTX_COMPILER_PATH"))
    return success();

  if (computeCapability_ < MIN_COMPUTE_CAPABILITY) {
    RETURN_ERROR(
        "Only NVIDIA Turing (sm_75) architectures or higher are supported. "
        "Your GPU has compute capability " +
        llvm::Twine(computeCapability_) +
        ". For older hardware, set MODULAR_NVPTX_COMPILER_PATH to use an "
        "external ptxas binary.\nFor more information, see "
        "https://modul.ar/gpu-requirements.");
  }

  int driverVersion = 0;
  CUDA_CHECK_ERR(driver_.cuDriverGetVersion(&driverVersion));
  if (driverVersion < MIN_CUDA_DRIVER_VERSION) {
    std::string detectedVersion = "CUDA " + apiVersionToString(driverVersion);
    auto errOrDriverVersion = getDriverVersion();
    if (!errOrDriverVersion.isError())
      detectedVersion =
          errOrDriverVersion->toString() + " (" + detectedVersion + ")";
    RETURN_ERROR(
        "Your current NVIDIA GPU driver version is not supported.\n"
        "  Required: driver version >= " +
        llvm::Twine(MIN_NVIDIA_DRIVER_VERSION) +
        " (CUDA >= " + apiVersionToString(MIN_CUDA_DRIVER_VERSION) +
        ")\n"
        "  Detected: " +
        detectedVersion +
        "\n\nTo run on an older driver, set the MODULAR_NVPTX_COMPILER_PATH "
        "environment variable to the path of a system `ptxas` binary. "
        "For more information, see https://modul.ar/gpu-requirements.");
  }

  return success();
}

ErrorOr<bool> CUDADevice::canAccess(const Device &peer) const {
  if (id() == peer.id()) {
    // Always disable self access (same behaviour as cuDeviceCanAccessPeer).
    return false;
  }

  int canAccessPeer = 0;
  CUDA_CHECK_ERR(driver_.cuDeviceCanAccessPeer(
      &canAccessPeer, cudaDevice(), CUDADevice::cast(peer).cudaDevice()));

  // Use support for native atomics as a proxy for NVLink here.
  // On a PCIe-link A10G system connected through a PCIe host bridge, we
  // observed that direct P2P access with stream-ordered allocations returns
  // zeros.
  // Furthermore, the very act of calling cuMemPoolSetAccess causes
  // `cuMemcpyPeerAsync` to return zeroes.
  // So force the cuMemcpyPeerAsync path and skipping MemPoolSetAccess by
  // returning cannot access here.
  int isNativeAtomicSupported = 0;
  CUDA_CHECK_ERR(driver_.cuDeviceGetP2PAttribute(
      &isNativeAtomicSupported,
      CUdevice_P2PAttribute::CU_DEVICE_P2P_ATTRIBUTE_NATIVE_ATOMIC_SUPPORTED,
      cudaDevice(), CUDADevice::cast(peer).cudaDevice()));

  return canAccessPeer && isNativeAtomicSupported;
}

ErrorOrSuccess CUDADevice::enablePeerAccessImpl(const Device &peer) {
  CUDA_WITH_DEV_ERR(*this);

  const CUDADevice &peerCudaDev = CUDADevice::cast(peer);
  DEFINE_OR_RETURN_ERROR(CUcontext, peerCtx, peerCudaDev.cudaContext());
  DEFINE_OR_RETURN_ERROR(bool, canAccessPeer, canAccess(peerCudaDev));
  if (!canAccessPeer) {
    RETURN_ERROR("Cannot enable peer access from GPU " + Twine(id()) +
                 " to GPU " + Twine(peer.id()) +
                 ": hardware does not support P2P access");
  }

  // Tolerate "already enabled" as success to keep idempotent.
  CUDADriver::Result res = driver_.cuCtxEnablePeerAccess(peerCtx, /*flags=*/0);
  if (res != CUDADriver::SUCCESS) {
    const char *name = nullptr;
    driver_.cuGetErrorName(res, &name);
    if (!(name && (Twine(name) == "CUDA_ERROR_PEER_ACCESS_ALREADY_ENABLED")))
      return formatCUDAError(__FILE__, __LINE__, __FUNCTION__, res);
  }

  // Also allow access to the peer's stream-ordered allocation pool.
  CUmemoryPool pool;
  CUDA_CHECK_ERR(driver_.cuDeviceGetMemPool(&pool, peerCudaDev.cudaDevice()));

  CUmemAccessDesc desc{};
  desc.location.type = CUmemLocationType::CU_MEM_LOCATION_TYPE_DEVICE;
  desc.location.id = id();
  desc.flags = CUmemAccess_flags::CU_MEM_ACCESS_FLAGS_PROT_READWRITE;
  CUDA_CHECK_ERR(driver_.cuMemPoolSetAccess(pool, &desc, /*count=*/1));

  return success();
}

// Answers whether NVML's device count can be trusted to equal CUDA's.
//
// It cannot when MIG is enabled: NVML counts physical GPUs while CUDA
// enumerates compute instances, and several of the latter are carved from one
// of the former. The question is asked through NVML alone so that the common
// answer — no MIG anywhere — is reached without loading libcuda.
//
// Only a positive report of "MIG is off here" clears a device. NOT_SUPPORTED
// counts as cleared, because it means the GPU has no MIG capability at all;
// that is the answer on every pre-Ampere and non-datacenter part, so treating
// it as unknown would push the whole fleet onto the CUDA path. Anything else,
// NO_PERMISSION included, is unknown and defers to CUDA — the direction that
// is merely slower rather than wrong.
static ErrorOr<bool> nvmlCountMayDisagreeWithCUDA(const NVML &nvml) {
  unsigned int nvmlCount;
  NVML_CHECK_ERR(nvml.nvmlDeviceGetCount_v2(&nvmlCount));

  for (unsigned int i = 0; i < nvmlCount; ++i) {
    nvmlDevice_t device;
    if (nvml.nvmlDeviceGetHandleByIndex(i, &device) != NVML::SUCCESS)
      return true;

    unsigned int currentMode, pendingMode;
    NVML::Result result =
        nvml.nvmlDeviceGetMigMode(device, &currentMode, &pendingMode);
    if (result == NVML::NOT_SUPPORTED)
      continue;
    if (result != NVML::SUCCESS || currentMode != NVML_DEVICE_MIG_DISABLE)
      return true;
  }
  return false;
}

ErrorOr<int> CUDADevice::numberOfGPUs() {
  // CUDA is the authority on how many devices there are, because CUDA is what
  // each of them is subsequently addressed through: an id in [0, count) is
  // handed straight to cuDeviceGet. NVML answers a different question — it
  // counts physical GPUs, so it under-reports a container granted several MIG
  // compute instances carved from one GPU, and discovery then silently drops
  // the instances past the first.
  //
  // Asking CUDA unconditionally would cost more than it looks: cuDeviceGetCount
  // needs cuInit, so merely counting devices would initialize the CUDA driver
  // in this process, and a CUDA-using child forked afterwards then fails to
  // initialize its own. Counting is the one device query reachable without
  // touching CUDA at all, and callers such as accelerator_count() do exactly
  // that and nothing more. So NVML answers whenever its count cannot disagree,
  // and CUDA is consulted only where MIG makes the two differ.
  static ErrorOr<int> errOrCount = []() -> ErrorOr<int> {
    DEFINE_OR_RETURN_ERROR(const NVML &, nvml, NVML::get());
    DEFINE_OR_RETURN_ERROR(bool, migInPlay, nvmlCountMayDisagreeWithCUDA(nvml));

    if (!migInPlay) {
      unsigned int result;
      NVML_CHECK_ERR(nvml.nvmlDeviceGetCount_v2(&result));
      return static_cast<int>(result);
    }

    DEFINE_OR_RETURN_ERROR(const CUDADriver &, driver, CUDADriver::get());

    int result;
    if (driver.cuDeviceGetCount(&result) != CUDADriver::SUCCESS)
      RETURN_ERROR("CUDA: Unable to get device count");
    return result;
  }();

  if (errOrCount.isError()) {
    return errOrCount.copy();
  }

  int numGPUs = *errOrCount;

  // NVML ignores CUDA_VISIBLE_DEVICES entirely, so on that path this is what
  // keeps a count the caller will index through CUDA from exceeding what CUDA
  // exposes. On the CUDA path cuInit has already applied the variable, and this
  // only catches a process that narrowed it afterwards, which CUDA would not
  // see.
  std::optional<std::string> envOr =
      llvm::sys::Process::GetEnv("CUDA_VISIBLE_DEVICES");
  if (envOr) {
    // Assuming responsible users
    // https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/
    // environment-variables.html
    int const numCommas =
        envOr->size() == 0 ? -1 : StringRef(*envOr).count(',');
    numGPUs = std::min(numGPUs, numCommas + 1);
  }
  return numGPUs;
}

int CUDADevice::deviceCount() const {
  ErrorOr<int> errOrCount = numberOfGPUs();
  if (errOrCount.isError()) {
    // Do not propagate an error.
    return 0;
  }
  return *errOrCount;
}

// ---- CUDA Virtual Memory Management (VMM) ----
//
// Builds the CUmemAllocationProp describing a pinned device granule on this
// device. Mirrors the multicast path in createMulticastBuffer.
const CUmemAllocationProp &CUDADevice::vmmAllocProp() const {
  std::call_once(vmmAllocPropOnce_, [&]() {
    vmmAllocProp_.type = CUmemAllocationType::PINNED;
    vmmAllocProp_.location.type =
        CUmemLocationType::CU_MEM_LOCATION_TYPE_DEVICE;
    vmmAllocProp_.location.id = cudaDevice_;
    // Mark chunks GPUDirect-RDMA capable where the platform supports it.
    // NICs registering VMM-backed buffers through the legacy peer-memory path
    // (`nvidia_p2p_get_pages`, used by e.g. mlx5 on hosts without dmabuf
    // support) require cuMemCreate allocations to carry this flag; dmabuf
    // registration does not need it. Per NVIDIA guidance the flag is a no-op
    // otherwise, so set it whenever the device reports support.
    int rdmaWithVmm = 0;
    if (driver_.cuDeviceGetAttribute(
            &rdmaWithVmm,
            CUdevice_attribute::GPU_DIRECT_RDMA_WITH_CUDA_VMM_SUPPORTED,
            cudaDevice_) == CUDADriver::SUCCESS &&
        rdmaWithVmm)
      vmmAllocProp_.allocFlags.gpuDirectRDMACapable = 1;
    // Make granules exportable as POSIX fds so another process on this node
    // can map them. UCX cuda_ipc needs this to move VMM memory over NVLink;
    // without an exportable handle it falls back to a host-staged transport.
    int posixFdSupported = 0;
    if (driver_.cuDeviceGetAttribute(
            &posixFdSupported,
            CUdevice_attribute::HANDLE_TYPE_POSIX_FILE_DESCRIPTOR_SUPPORTED,
            cudaDevice_) == CUDADriver::SUCCESS &&
        posixFdSupported)
      vmmAllocProp_.requestedHandleTypes =
          CUmemAllocationHandleType::POSIX_FILE_DESCRIPTOR;
  });
  return vmmAllocProp_;
}

bool CUDADevice::vmmSupported() const {
  // VMM is usable iff the device accepts the granularity query for a pinned
  // device allocation. Probe once and cache, so this reflects actual support
  // (rather than merely "the backend is CUDA") and is cheap to call.
  std::call_once(vmmSupportedOnce_,
                 [&]() { vmmSupportedCached_ = !vmmGranularity().isError(); });
  return vmmSupportedCached_;
}

const std::vector<CUmemAccessDesc> &CUDADevice::vmmAccessDescs() const {
  std::call_once(vmmAccessOnce_, [&]() {
    auto pushDesc = [&](CUdevice dev) {
      CUmemAccessDesc d = {};
      d.location.type = CUmemLocationType::CU_MEM_LOCATION_TYPE_DEVICE;
      d.location.id = dev;
      d.flags = CUmemAccess_flags::CU_MEM_ACCESS_FLAGS_PROT_READWRITE;
      vmmAccessDescs_.push_back(d);
    };
    // The owning device always has access.
    pushDesc(cudaDevice_);

    // Grant access to every other GPU that can peer-access this device's memory
    // over a fast link. Use the same P2P + native-atomic (NVLink proxy) policy
    // as canAccess(), evaluated via raw ordinals so we do not eagerly
    // initialize peer device contexts.
    int count = 0;
    if (driver_.cuDeviceGetCount(&count) != CUDADriver::SUCCESS)
      return;
    for (int ord = 0; ord < count; ++ord) {
      CUdevice peerDev;
      if (driver_.cuDeviceGet(&peerDev, ord) != CUDADriver::SUCCESS)
        continue;
      if (peerDev == cudaDevice_)
        continue;
      // Can `peerDev` access memory physically resident on this device?
      int canAccessPeer = 0;
      if (driver_.cuDeviceCanAccessPeer(&canAccessPeer, peerDev, cudaDevice_) !=
              CUDADriver::SUCCESS ||
          !canAccessPeer)
        continue;
      int isNativeAtomicSupported = 0;
      if (driver_.cuDeviceGetP2PAttribute(
              &isNativeAtomicSupported,
              CUdevice_P2PAttribute::
                  CU_DEVICE_P2P_ATTRIBUTE_NATIVE_ATOMIC_SUPPORTED,
              peerDev, cudaDevice_) != CUDADriver::SUCCESS ||
          !isNativeAtomicSupported)
        continue;
      pushDesc(peerDev);
    }
  });
  return vmmAccessDescs_;
}

ErrorOrSuccess CUDADevice::vmmMapAndSetAccess(void *va, size_t byteSize,
                                              uint64_t handle) {
  CUDA_WITH_DEV_ERR(*this);
  CUdeviceptr ptr = reinterpret_cast<CUdeviceptr>(va);
  CUDA_CHECK_ERR(driver_.cuMemMap(
      ptr, byteSize, 0, static_cast<CUmemGenericAllocationHandle>(handle), 0));
  // Grant read/write access to the owning device and every P2P-capable peer so
  // multi-GPU (expert-parallel) kernels and collectives can read VMM-backed
  // buffers. VMM access does not inherit from cuCtxEnablePeerAccess.
  const std::vector<CUmemAccessDesc> &descs = vmmAccessDescs();
  CUDA_CHECK_ERR(
      driver_.cuMemSetAccess(ptr, byteSize, descs.data(), descs.size()));
  return success();
}

ErrorOr<Device::GraphMemInfo> CUDADevice::getGraphMemoryInfo() const {

  CUDA_CHECK_ERR(driver_.cuDeviceGetGraphMemAttribute(

      cudaDevice_, CUgraphMem_attribute::CU_GRAPH_MEM_ATTR_USED_MEM_CURRENT,
      &used));
  info.reserved = static_cast<size_t>(reserved);
  info.used = static_cast<size_t>(used);
  return info;
}

ErrorOr<CUDADevice &> CUDADevice::get(int id) {
  // On first call initialize devices and err. devices is only set if there was
  // no error during setup.
  static std::mutex mu;
  static DeviceList *devices = nullptr;
  static const ErrorOrSuccess err = [&]() -> ErrorOrSuccess {
    DEFINE_OR_RETURN_ERROR(int, count, numberOfGPUs());
    devices = new DeviceList(count, nullptr);
    return success();
  }();

  // If we did get an error during setup, skip accessing the device and forward
  // the error.
  if (err.isError()) {
    RETURN_ERROR(err.getError());
  }

  assert(devices != nullptr);
  assert((id >= 0) && (static_cast<size_t>(id) < devices->size()));

  // Get or initialize the Device object.
  std::lock_guard<std::mutex> lock(mu);
  CUDADevice *device = (*devices)[id];
  if (device == nullptr) {
    DEFINE_OR_RETURN_ERROR(const NVML &, nvml, NVML::get());
    DEFINE_OR_RETURN_ERROR(const CUDADriver &, driver, CUDADriver::get());

    // The CUDA device is what an id denotes, so it is resolved first and the
    // NVML handle the rest of this setup queries is derived from it.
    CUdevice cuDevice;
    CUDA_CHECK_ERR(driver.cuDeviceGet(&cuDevice, id));
    DEFINE_OR_RETURN_ERROR(nvmlDevice_t, nvmlDevice,
                           nvmlDeviceForCudaDevice(nvml, driver, cuDevice));

    char name[256];
    NVML_CHECK_ERR(nvml.nvmlDeviceGetName(nvmlDevice, name, sizeof(name)));

    nvmlMemory_t nvmlMemInfo;
    auto nvmlMemResult = nvml.nvmlDeviceGetMemoryInfo(nvmlDevice, &nvmlMemInfo);

    // NVML cannot report memory on some integrated GPUs or when only a MIG
    // instance is accessible. CUDA still reports the device's physical limit.
    bool memInfoFromCUDA = nvmlMemResult != NVML::SUCCESS;

    Device::MemInfo memInfo;
    if (nvmlMemResult == NVML::SUCCESS) {
      memInfo.free = nvmlMemInfo.free;
      memInfo.total = nvmlMemInfo.total;
    }

    int alignment;
    CUcontext cuContext;

    // Alignment does not seem to be available through NVML.
    CUDA_CHECK_ERR(driver.cuDeviceGetAttribute(
        &alignment, CUdevice_attribute::TEXTURE_ALIGNMENT, cuDevice));

    // Use the primary context for this device, with the effect that we share
    // the same context with other users of the CUDA Runtime API.
    CUDA_CHECK_ERR(driver.cuDevicePrimaryCtxRetain(&cuContext, cuDevice));

    // Activate on-demand profiling (libkineto/CUPTI) now that this device's
    // real primary context exists, with the context current — see
    // activatePendingTrace() in Support/Profiling/Ranges.h for the
    // contract (and why the before-first-cuGraphInstantiate ordering an
    // earlier revision required is obsolete on CUDA 13.1 — MXTOOLS-266).
    // Cheap no-op unless profiling was enable()'d or the process is in
    // Dynolog daemon mode; idempotent across devices.
    {
      CUDAContextScope ctxScope(cuContext, driver);
      M::Profiling::activatePendingTrace();
    }

    // Deferred to here because cuMemGetInfo needs a current context, and so
    // that the NVML path keeps reading free memory before the primary context
    // claims any.
    if (memInfoFromCUDA) {
      CUDAContextScope ctxScope(cuContext, driver);
      CUDA_CHECK_ERR(ctxScope.status());
      CUDA_CHECK_ERR_MSG(
          driver.cuMemGetInfo_v2(&memInfo.free, &memInfo.total),
          std::string("fallback after NVML rejected the memory query for "
                      "device ") +
              std::to_string(id) + " with error " +
              nvml.nvmlErrorString(nvmlMemResult));
    }

#if MODULAR_LINUX
    int integrated = 0;
    CUDA_CHECK_ERR(driver.cuDeviceGetAttribute(
        &integrated, CUdevice_attribute::INTEGRATED, cuDevice));
    if (integrated) {
      DEFINE_OR_RETURN_ERROR(Device::MemInfo, hostInfo,
                             getHostUnifiedMemoryInfo(memInfo));
      memInfo = hostInfo;
    }
#endif

    int computeCapabilityMajor, computeCapabilityMinor;
    NVML_CHECK_ERR(nvml.nvmlDeviceGetCudaComputeCapability(
        nvmlDevice, &computeCapabilityMajor, &computeCapabilityMinor));
    device = new CUDADevice(driver, id, nvmlDevice, cuDevice, cuContext, name,
                            computeCapabilityMajor, computeCapabilityMinor,
                            memInfo, alignment);

    // Once the Device has been created remember it in the devices list.
    (*devices)[id] = device;

    // Run healthcheck after device init — returns error on unhealthy GPU.
    RETURN_IF_ERROR(device->runHealthcheck());
  }
  return *device;
}

ErrorOrSuccess CUDADevice::runHealthcheck() const {
  if (DeviceContext::configAsBool("disable-healthcheck", false))
    return success();

  auto nvmlOr = NVML::get();
  if (nvmlOr.isError())
    return success(); // Gracefully skip if NVML unavailable.

  const NVML &nvml = *nvmlOr;

  GPUHealthData data;
  data.deviceId = id();
  data.deviceName = name();

  // Gather throttle reasons — map NVML-specific bitmask to platform-agnostic
  // GPUHealthData constants.
  unsigned long long nvmlThrottle = 0;
  if (nvml.nvmlDeviceGetCurrentClocksThrottleReasons(
          nvmlDevice_, &nvmlThrottle) == NVML::SUCCESS) {
    data.throttleQueried = true;
    if (nvmlThrottle & NVML_CLK_THROTTLE_REASON_HW_SLOWDOWN)
      data.throttleReasons |= GPUHealthData::THROTTLE_HW_SLOWDOWN;
    if (nvmlThrottle & NVML_CLK_THROTTLE_REASON_HW_THERMAL_SLOWDOWN)
      data.throttleReasons |= GPUHealthData::THROTTLE_HW_THERMAL_SLOWDOWN;
    if (nvmlThrottle & NVML_CLK_THROTTLE_REASON_HW_POWER_BRAKE_SLOWDOWN)
      data.throttleReasons |= GPUHealthData::THROTTLE_HW_POWER_BRAKE;
  }

  // Gather ECC errors.
  data.eccQueried = nvml.nvmlDeviceGetTotalEccErrors(
                        nvmlDevice_, NVML_MEMORY_ERROR_TYPE_UNCORRECTABLE,
                        NVML_VOLATILE_ECC, &data.eccErrors) == NVML::SUCCESS;

  return evaluateGPUHealth(data);
}

void CUDADevice::eventCacheClear() const {
  std::lock_guard<std::mutex> lock(mu_);
  for (const auto &event : eventCache_) {
    // Ignore errors during destruction of device object.
    cudaDriver().cuEventDestroy(event);
  }
  eventCache_.clear();
}

ErrorOr<CUevent> CUDADevice::eventCachePop(bool useCache) const {
  if (useCache) {
    std::lock_guard<std::mutex> lock(mu_);
    if (!eventCache_.empty()) {
      CUevent result = std::move(eventCache_.back());
      eventCache_.pop_back();
      return result;
    }
  }

  CUevent event;
  CUDA_CHECK_ERR(cudaDriver().cuEventCreate(
      &event,
      static_cast<unsigned int>(CUevent_flags::CU_EVENT_DISABLE_TIMING)));
  return event;
}

void CUDADevice::eventCachePush(CUevent event) const {
  std::lock_guard<std::mutex> lock(mu_);
  eventCache_.emplace_back(event);
}

// ===== CUDADeviceMulticastBuffer ===== //
CUDADeviceMulticastBuffer::CUDADeviceMulticastBuffer(
    size_t byteSize, size_t paddedByteSize, const CUDADriver &driver,
    CUmemGenericAllocationHandle multicastHandle, CUdeviceptr multicastPtr,
    std::vector<CUDADeviceMulticastBuffer::DeviceToBuffer> unicastBuffers)
    : DeviceMulticastBuffer(byteSize), driver_(driver),
      multicastHandle_(multicastHandle), multicastPtr_(multicastPtr),
      paddedByteSize_(paddedByteSize),
      unicastBuffers_(std::move(unicastBuffers)) {}

CUDADeviceMulticastBuffer::~CUDADeviceMulticastBuffer() {
  CUDA_CHECK(driver_.cuMemUnmap(multicastPtr_, paddedByteSize_));
  CUDA_CHECK(driver_.cuMemAddressFree(multicastPtr_, paddedByteSize_));

  for (const auto &it : unicastBuffers_) {
    CUDA_CHECK(driver_.cuMulticastUnbind(multicastHandle_, it.device_, 0,
                                         paddedByteSize_));
    CUDA_CHECK(driver_.cuMemUnmap(it.ptr_, paddedByteSize_));
    CUDA_CHECK(driver_.cuMemAddressFree(it.ptr_, paddedByteSize_));
    CUDA_CHECK(driver_.cuMemRelease(it.handle_));
  }
  CUDA_CHECK(driver_.cuMemRelease(multicastHandle_));
}

ErrorOr<DeviceBufferRef>
CUDADeviceMulticastBuffer::multicastBuffer(DeviceContext &ctx) const {
  return ctx.createBufferOwning(multicastPtr_, byteSize(),
                                /* owning = */ false);
}

ErrorOr<DeviceBufferRef>
CUDADeviceMulticastBuffer::unicastBufferFor(DeviceContext &ctx) const {
  CUdevice dev = CUDADevice::cast(ctx.device()).cudaDevice();
  for (const auto &it : unicastBuffers_) {
    if (it.device_ == dev) {
      return ctx.createBufferOwning(it.ptr_, byteSize(), /* owning = */ false);
    }
  }
  RETURN_ERROR("device is not part of this DeviceMulticastBuffer");
}

ErrorOr<DeviceMulticastBufferRef>
CUDADeviceMulticastBuffer::allocate(const std::vector<const Device *> &devices,
                                    size_t byteSize) {
  if (devices.size() < 2)
    RETURN_ERROR(
        "At least two DeviceContexts needed for device multicast allocation.");
  for (const auto &it : devices) {
    if (it->api() != CUDADevice::api)
      RETURN_ERROR("Only CUDADeviceContext supports device multicast access.");
  }
  const CUDADevice &dev0 = CUDADevice::cast(*devices[0]);
  const CUDADriver &driver = dev0.cudaDriver();

  // Verify that multicast memory is supported.
  int multicastSupported = 0;
  CUDA_CHECK_ERR(driver.cuDeviceGetAttribute(
      &multicastSupported, CUdevice_attribute::MULTICAST_SUPPORTED,
      dev0.cudaDevice()));
  if (multicastSupported == 0)
    RETURN_ERROR("Multicast buffer not supported.");

  // Get minimum multicast and allocation granularity, adjust requested size up.
  CUmulticastObjectProp multiProp = {};
  multiProp.numDevices = devices.size();
  multiProp.handleTypes =
      //    static_cast<unsigned long long>(CUmemAllocationHandleType::NONE);
      static_cast<unsigned long long>(
          CUmemAllocationHandleType::POSIX_FILE_DESCRIPTOR);
  multiProp.size = byteSize;

  size_t granularity = 0;
  CUDA_CHECK_ERR(driver.cuMulticastGetGranularity(
      &granularity, &multiProp,
      CUmulticastGranularity_flags::GRANULARITY_MINIMUM));

  size_t paddedByteSize = llvm::alignTo(byteSize, granularity);

  CUmemAllocationProp memProp = {};
  memProp.type = CUmemAllocationType::PINNED;
  memProp.location.type = CUmemLocationType::CU_MEM_LOCATION_TYPE_DEVICE;
  memProp.requestedHandleTypes =
      CUmemAllocationHandleType::POSIX_FILE_DESCRIPTOR;
  memProp.location.id = dev0.cudaDevice();

  granularity = 0;
  CUDA_CHECK_ERR(driver.cuMemGetAllocationGranularity(
      &granularity, &memProp,
      CUmemAllocationGranularity_flags::GRANULARITY_MINIMUM));
  paddedByteSize = llvm::alignTo(paddedByteSize, granularity);
  multiProp.size = paddedByteSize;

  // Allocate the multicast memory handle.
  CUmemGenericAllocationHandle multiHandle;
  CUDA_CHECK_ERR(driver.cuMulticastCreate(&multiHandle, &multiProp));

  // Until the buffer object takes ownership, every early return must undo
  // what has been reserved so far, in the destructor's order. The scope exits
  // below nest innermost-first; each is released once its resource is handed
  // to `unicastBuffers` or the buffer object. Cleanup results are ignored: the
  // original failure is what gets reported.
  std::vector<DeviceToBuffer> unicastBuffers;
  auto releaseMulticast = llvm::scope_exit([&] {
    for (const auto &it : unicastBuffers) {
      (void)driver.cuMulticastUnbind(multiHandle, it.device_, 0,
                                     paddedByteSize);
      (void)driver.cuMemUnmap(it.ptr_, paddedByteSize);
      (void)driver.cuMemAddressFree(it.ptr_, paddedByteSize);
      (void)driver.cuMemRelease(it.handle_);
    }
    (void)driver.cuMemRelease(multiHandle);
  });

  // First add all the devices to the multicast handle to avoid blocking when
  // adding physical memory for each participating device.
  for (const auto &it : devices) {
    const CUDADevice &device = CUDADevice::cast(*it);
    CUDA_CHECK_ERR(
        driver.cuMulticastAddDevice(multiHandle, device.cudaDevice()));
  }

  // Only after all devices have been added we can allocate and map virtual
  // address space on the individual devices. Then bind the physical memory to
  // the multicast memory handle.
  CUmemAccessDesc memDesc = {};
  memDesc.location.type = CUmemLocationType::CU_MEM_LOCATION_TYPE_DEVICE;
  memDesc.flags = CUmemAccess_flags::CU_MEM_ACCESS_FLAGS_PROT_READWRITE;

  for (const auto &it : devices) {
    const CUDADevice &device = CUDADevice::cast(*it);
    memProp.location.id = device.cudaDevice();
    memDesc.location.id = device.cudaDevice();

    CUmemGenericAllocationHandle memHandle;
    CUDA_CHECK_ERR(driver.cuMemCreate(&memHandle, paddedByteSize, &memProp, 0));
    auto releaseMem =
        llvm::scope_exit([&] { (void)driver.cuMemRelease(memHandle); });
    CUdeviceptr memPtr;
    CUDA_CHECK_ERR(
        driver.cuMemAddressReserve(&memPtr, paddedByteSize, 0, nullptr, 0));
    auto freeVA = llvm::scope_exit(
        [&] { (void)driver.cuMemAddressFree(memPtr, paddedByteSize); });
    CUDA_CHECK_ERR(driver.cuMemMap(memPtr, paddedByteSize, 0, memHandle, 0));
    auto unmap = llvm::scope_exit(
        [&] { (void)driver.cuMemUnmap(memPtr, paddedByteSize); });
    CUDA_CHECK_ERR(driver.cuMemSetAccess(memPtr, paddedByteSize, &memDesc, 1));
    CUDA_CHECK_ERR(driver.cuMulticastBindMem(multiHandle, 0, memHandle, 0,
                                             paddedByteSize, 0));
    unicastBuffers.push_back(
        DeviceToBuffer{device.cudaDevice(), memHandle, memPtr});
    unmap.release();
    freeVA.release();
    releaseMem.release();
  }

  // Map the multicast memory handle to a virtual address range and allow access
  // from all participating devices.
  CUdeviceptr multiPtr = nullptr;
  CUDA_CHECK_ERR(
      driver.cuMemAddressReserve(&multiPtr, paddedByteSize, 0, nullptr, 0));
  auto freeMultiVA = llvm::scope_exit(
      [&] { (void)driver.cuMemAddressFree(multiPtr, paddedByteSize); });
  CUDA_CHECK_ERR(driver.cuMemMap(multiPtr, paddedByteSize, 0, multiHandle, 0));
  auto unmapMulti = llvm::scope_exit(
      [&] { (void)driver.cuMemUnmap(multiPtr, paddedByteSize); });
  for (const auto &it : devices) {
    const CUDADevice &device = CUDADevice::cast(*it);
    memDesc.location.id = device.cudaDevice();
    CUDA_CHECK_ERR(
        driver.cuMemSetAccess(multiPtr, paddedByteSize, &memDesc, 1));
  }

  unmapMulti.release();
  freeMultiVA.release();
  releaseMulticast.release();
  return CUDADeviceMulticastBufferRef::create(byteSize, paddedByteSize, driver,
                                              multiHandle, multiPtr,
                                              std::move(unicastBuffers));
}

// ===== CUDADeviceEvent ===== //
CUDADeviceEvent::CUDADeviceEvent(CUDADevice &device, CUevent event,
                                 bool recordedDuringCapture, bool enableTiming)
    : DeviceEvent(device), event_(event),
      recordedDuringCapture_(recordedDuringCapture),
      enableTiming_(enableTiming) {}

CUDADeviceEvent::~CUDADeviceEvent() {
  const auto &cudaDevice = CUDADevice::cast(device());
  CUDA_WITH_DEV(cudaDevice);
  if (recordedDuringCapture_ || enableTiming_) {
    // Timing-enabled events have different flags than cached events,
    // so they must not be returned to the non-timing event cache.
    // Events recorded during capture also bypass the cache.
    cudaDevice.cudaDriver().cuEventDestroy(event_);
  } else {
    cudaDevice.eventCachePush(event_);
  }
}

ErrorOrSuccess CUDADeviceEvent::synchronize() {
  const auto &cudaDevice = CUDADevice::cast(device());
  CUDA_WITH_DEV_ERR(cudaDevice);
  CUDA_CHECK_ERR(cudaDevice.cudaDriver().cuEventSynchronize(event_));
  return success();
}

ErrorOr<bool> CUDADeviceEvent::isReady() const {
  if (recordedDuringCapture_) {
    // Events recorded during stream capture become graph nodes; polling them
    // directly is not allowed, so treat them as ready.
    return true;
  }
  const auto &cudaDevice = CUDADevice::cast(device());
  CUDA_WITH_DEV_ERR(cudaDevice);
  CUDADriver::Result res = cudaDevice.cudaDriver().cuEventQuery(event_);
  if (res == CUDADriver::SUCCESS)
    return true;
  else if (res == CUDADriver::NOT_READY) {
    return false;
  }
  CUDA_CHECK_ERR(res); // All other errors get raised here.
  // Not reachable because there is an error status in res, but compiler
  // complains if not returning a value.
  llvm_unreachable("Not Reachable");
  return Error("Not Reachable.");
}

ErrorOr<float> CUDADeviceEvent::elapsedTime(const DeviceEvent &end) const {
  const auto &cudaEnd = CUDADeviceEvent::cast(end);
  const auto &cudaDevice = CUDADevice::cast(device());
  CUDA_WITH_DEV_ERR(cudaDevice);
  float millis;
  CUDA_CHECK_ERR(cudaDevice.cudaDriver().cuEventElapsedTime(
      &millis, event_, cudaEnd.cudaEvent()));
  return millis;
}

CUevent CUDADeviceEvent::cudaEvent() const { return event_; }

  return static_cast<const CUDADeviceEvent &>(event);
}

// ===== CUDADeviceGraph ===== //
CUDADeviceGraph::~CUDADeviceGraph() {
  const auto &cudaDevice = CUDADevice::cast(device());
  CUDA_WITH_DEV(cudaDevice);
  if (rawGraph_)
    CUDA_CHECK(cudaDevice.cudaDriver().cuGraphDestroy(rawGraph_));
  if (exec_)
    CUDA_CHECK(cudaDevice.cudaDriver().cuGraphExecDestroy(exec_));
}

static std::unique_lock<std::mutex> getCudaProfilerLock() {
  // CUPTI's graph-tracing hooks (active when any CUDA injection profiler such
  // as nsys or ncu is running) are not thread-safe for concurrent
  // cuGraphInstantiateWithParams calls, even on distinct CUgraph objects.
  // Serialize instantiation under a process-wide mutex when profiling is
  // detected via CUDA_INJECTION64_PATH.

  static const bool kUnderCudaProfiler =
      llvm::sys::Process::GetEnv("CUDA_INJECTION64_PATH").has_value();

  if (kUnderCudaProfiler) {
    static std::mutex sInstantiateMutex;
    std::unique_lock<std::mutex> profilingLock(sInstantiateMutex);
    return profilingLock;
  }

  return {};
}

ErrorOrSuccess CUDADeviceGraph::instantiate() {
  const auto &cudaDevice = CUDADevice::cast(device());
  CUDA_WITH_DEV_ERR(cudaDevice);

  // Prepare instantiation parameters with enhanced error reporting.
  CUDA_GRAPH_INSTANTIATE_PARAMS params = {
      .flags =
          M::to_underlying(CUgraphInstantiateFlags::
                               CUDA_GRAPH_INSTANTIATE_FLAG_AUTO_FREE_ON_LAUNCH),
      .hUploadStream = nullptr,
      .hErrNode_out = nullptr,
      .result_out = CUgraphInstantiateResult::CUDA_GRAPH_INSTANTIATE_SUCCESS};

  CUgraphExec exec = nullptr;
  CUDADriver::Result res = [&] {
    auto lock = getCudaProfilerLock();
    return cudaDevice.cudaDriver().cuGraphInstantiateWithParams(
        &exec, rawGraph_, &params);
  }();

  if (res != CUDADriver::SUCCESS) {
    std::string errorMsg = "failed to instantiate CUDA graph";
    if (params.result_out !=
        CUgraphInstantiateResult::CUDA_GRAPH_INSTANTIATE_SUCCESS) {
      errorMsg += ": ";
      errorMsg += toString(params.result_out);
    }
    if (params.hErrNode_out != nullptr) {
      errorMsg +=
          " at node " + llvm::formatv("{0}", (void *)params.hErrNode_out).str();
    }
    return formatCUDAError(__FILE__, __LINE__, __FUNCTION__, res, errorMsg);
  }

  // Destroy the raw graph now that instantiation succeeded; exec_ takes over.
  CUDA_CHECK_ERR(cudaDevice.cudaDriver().cuGraphDestroy(rawGraph_));
  rawGraph_ = nullptr;
  exec_ = exec;
  return success();
}

ErrorOrSuccess CUDADeviceGraph::replay() const {
  if (!hasStream())
    RETURN_ERROR("cannot replay CUDA graph: no stream stored during capture");
  const auto *cudaStream = CUDADeviceStream::verified_cast(captureStream());
  if (!cudaStream)
    RETURN_ERROR(
        "cannot replay CUDA graph: stored stream is not a CUDA stream");
  const auto &cudaDevice = CUDADevice::cast(device());
  CUDA_WITH_DEV_ERR(cudaDevice);
  CUDA_CHECK_ERR(
      cudaDevice.cudaDriver().cuGraphLaunch(exec_, cudaStream->cudaStream()));
  return success();
}

ErrorOrSuccess
CUDADeviceStream::enqueueWaitOnHostValue(const CompletionFlag &flag,
                                         uint64_t value) const {
  const auto &cudaDevice = CUDADevice::cast(this->device());
  CUDA_WITH_DEV_ERR(cudaDevice);
  // Wait until *flag.devicePtr() == value. CU_STREAM_WAIT_VALUE_FLUSH is
  // intentionally omitted: it's gated by CAN_FLUSH_REMOTE_WRITES, which
  // is 0 on most current devices, and writes from a normal host thread
  // are visible via the device-mapped pinned alias without it.
  CUDA_CHECK_ERR(cudaDevice.cudaDriver().cuStreamWaitValue64_v2(
      stream_, reinterpret_cast<CUdeviceptr>(flag.devicePtr()), value,
      static_cast<unsigned int>(
          CUstreamWaitValue_flags::CU_STREAM_WAIT_VALUE_EQ)));
  return success();
}

CUstreamCaptureStatus CUDADeviceStream::getCaptureStatus() const {
  const auto &cudaDevice = CUDADevice::cast(this->device());
  CUstreamCaptureStatus status =
      CUstreamCaptureStatus::CU_STREAM_CAPTURE_STATUS_NONE;
  cudaDevice.cudaDriver().cuStreamIsCapturing(stream_, &status);
  return status;
}

ErrorOrSuccess CUDADeviceStream::beginCapture() const {
  CUstreamCaptureStatus status = getCaptureStatus();
  if (status == CUstreamCaptureStatus::CU_STREAM_CAPTURE_STATUS_ACTIVE)
    RETURN_ERROR("stream is already capturing");
  if (status == CUstreamCaptureStatus::CU_STREAM_CAPTURE_STATUS_INVALIDATED)
    RETURN_ERROR("stream capture was invalidated");

  const auto &cudaDevice = CUDADevice::cast(this->device());
  CUDA_WITH_DEV_ERR(cudaDevice);
  CUDA_CHECK_ERR(cudaDevice.cudaDriver().cuStreamBeginCapture(
      stream_, CUstreamCaptureMode::CU_STREAM_CAPTURE_MODE_RELAXED));
  return success();
}

ErrorOr<DeviceGraphRef> CUDADeviceStream::endCapture() {
  CUstreamCaptureStatus status = getCaptureStatus();
  if (status == CUstreamCaptureStatus::CU_STREAM_CAPTURE_STATUS_NONE)
    RETURN_ERROR("stream is not capturing");
  if (status == CUstreamCaptureStatus::CU_STREAM_CAPTURE_STATUS_INVALIDATED)
    RETURN_ERROR("stream capture was invalidated");

  CUDADevice &cudaDevice = CUDADevice::cast(this->device());
  CUDA_WITH_DEV_ERR(cudaDevice);

  CUgraph graph = nullptr;
  CUDA_CHECK_ERR(cudaDevice.cudaDriver().cuStreamEndCapture(stream_, &graph));

  if (!graph)
    RETURN_ERROR("cuStreamEndCapture returned null graph");

  if (logGraphCapture_ != "") {
    static std::atomic<int32_t> graphCaptureCount = 0;

    int32_t currentId = graphCaptureCount.fetch_add(1);
    // Debug: print graph to DOT file for visualization.
    // This is only enabled at compile time for debugging purposes.
    // The DOT file can be visualized with Graphviz tools (e.g., dot -Tpng).
    // Set MODULAR_CUDA_GRAPH_DOT_PATH to customize the output path.
    std::string outputPath =
        llvm::formatv("{}/cuda_graph_{}.dot", logGraphCapture_, currentId)
            .str();
    cudaDevice.cudaDriver().cuGraphDebugDotPrint(
        graph, outputPath.c_str(),
        static_cast<unsigned>(CUgraphDotFlags::Verbose));
  }

  // Store the stream for replay/verification.
  return CUDADeviceGraphRef::create(
      DeviceContextRef::copy(&context_()), graph,
      DeviceStreamRef::copy(static_cast<DeviceStream *>(this)));
}

ErrorOrSuccess CUDADeviceFunction::cudaCallKernelDirect(
    uint32_t gridX, uint32_t gridY, uint32_t gridZ, uint32_t blockX,
    uint32_t blockY, uint32_t blockZ, uint32_t sharedMemBytes,
    CUlaunchAttribute *attrs, uint32_t numAttrs, void **args,
    CUstream stream) const {
  CUlaunchConfig config;
  config.gridDimX = gridX;
  config.gridDimY = gridY;
  config.gridDimZ = gridZ;
  config.blockDimX = blockX;
  config.blockDimY = blockY;
  config.blockDimZ = blockZ;
  config.sharedMemBytes = sharedMemBytes;
  config.hStream = stream;
  config.attrs = attrs;
  config.numAttrs = numAttrs;

  // Record launch trace if enabled
  auto &registry = launchTraceRegistry();
  if (registry.isLaunchTraceEnabled(stream)) {
    // Convert CUDA-specific types to generic interface
    ArrayRef<uint8_t> attrsArray;
    if (attrs && numAttrs > 0) {
      attrsArray = ArrayRef<uint8_t>(reinterpret_cast<const uint8_t *>(attrs),
                                     sizeof(CUlaunchAttribute) * numAttrs);
    }

    ArrayRef<size_t> paramSizes = moduleFunction_->paramSizes();
    ArrayRef<void *> argsArray = ArrayRef<void *>(args, paramSizes.size());

        moduleFunction_->name(),
        reinterpret_cast<uintptr_t>(moduleFunction_->cudaFunction()),
        moduleFunction_->paramSizes(), gridX, gridY, gridZ, blockX, blockY,
        blockZ, sharedMemBytes, attrsArray, numAttrs, argsArray, stream);
  }

  CUDA_CHECK_ERR(moduleFunction_->cudaDriver().cuLaunchKernelEx(
      &config, moduleFunction_->cudaFunction(), args, nullptr));
  MAYBE_SYNC(CUDADeviceContext::cast(context()));
  return success();
}

ErrorOrSuccess CUDADeviceContext::memAlloc(void **ptr, size_t byteSize,
                                           Device::AllocMode mode) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::memAlloc", TRACY_COLOR_PURPLE);

  assert(byteSize != 0);
  CUDA_WITH_CTX_ERR(*this);
  switch (mode) {
  case Device::AllocMode::ASYNC: {
    // We used to support async allocations but prefer only sync ones now.
    return Error("Async allocation is not supported for CUDA devices");

    // Deprecated logic. Remove later.
    // CUDA_CHECK_ERR(driver_.cuMemAllocAsync(ptr, byteSize, stream_));
    // MAYBE_SYNC(*this);
    break;
  }
  case Device::AllocMode::HOST: {
    // We must poll here since cuMemAllocHost_v2 is synchronous.
    POLL_PENDING_EVENTS(*this);
    CUDA_CHECK_ERR(driver_.cuMemAllocHost_v2(ptr, byteSize));
    break;
  }
  case Device::AllocMode::SYNC: {
    POLL_PENDING_EVENTS(*this);
    CUDA_CHECK_ERR(driver_.cuMemAlloc_v2(ptr, byteSize));
    break;
  }
  }
  return success();
}

ErrorOrSuccess CUDADeviceContext::memWrap(void **devPtr, void *hostPtr,
                                          size_t byteSize) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::memWrap", TRACY_COLOR_PURPLE);
  CUDA_WITH_CTX_ERR(*this);
  // CU_MEMHOSTREGISTER_PORTABLE (0x1): the registration is visible from every
  // context in the process
  constexpr unsigned int kFlags = 0x1;
  CUDA_CHECK_ERR(driver_.cuMemHostRegister_v2(hostPtr, byteSize, kFlags));
  // UVA gives a registered page one address; guaranteed at our CC 7.5 floor.
  *devPtr = hostPtr;
  return success();
}

ErrorOrSuccess CUDADeviceContext::memFree(void *ptr, Device::FreeKind kind) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::memFree", TRACY_COLOR_PURPLE);

  CUDA_WITH_CTX_ERR(*this);
  if (kind == Device::FreeKind::WRAPPED) {
    CUDA_CHECK_ERR(driver_.cuMemHostUnregister(ptr));
    return success();
  }

  if (kind == Device::FreeKind::HOST) {
    POLL_PENDING_EVENTS(*this);
    CUDA_CHECK_ERR(driver_.cuMemFreeHost(ptr));
  } else {
    // Defer cuMemFree_v2 until after GPU stream work completes. This prevents
    // a use-after-free when a kernel (e.g. allreduce reduce-scatter) is still
    // reading memory via P2P on another GPU while the CPU drops its reference.
    // During CUDA graph capture the stream records ops but does not execute
    // them, so no P2P race is possible; free immediately to keep the memory
    // pool available for subsequent capture allocations.
    if (isStreamCapturing(driver_, stream_)) {
      CUDA_CHECK_ERR(driver_.cuMemFree_v2(ptr));
    } else {
      RETURN_IF_ERROR(enqueueEventHandler(
          [contextRef = DeviceContextRef::copy(this), ptr = ptr]() {
            auto &cudaCtx = static_cast<CUDADeviceContext &>(*contextRef);
            CUDA_WITH_CTX(cudaCtx);
            CUDADriver::Result result = cudaCtx.driver_.cuMemFree_v2(ptr);
            if (result != CUDADriver::SUCCESS) {
              cudaCtx.setPendingError(
                  formatCUDAError(__FILE__, __LINE__, __FUNCTION__, result));
            }
          }));
    }
  }
  return success();
}

ErrorOr<CompletionFlagRef> CUDADeviceContext::allocateCompletionFlag() {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::allocateCompletionFlag",
                       TRACY_COLOR_PURPLE);
  CUDA_WITH_CTX_ERR(*this);
  POLL_PENDING_EVENTS(*this);
  void *hostPtr = nullptr;
  // CU_MEMHOSTALLOC_PORTABLE (0x1) | CU_MEMHOSTALLOC_DEVICEMAP (0x2).
  // DEVICEMAP is required so cuMemHostGetDevicePointer_v2 succeeds on
  // non-UVA systems. PORTABLE matches the existing cuMemAllocHost_v2
  // path and allows the same host allocation to be used from any
  // context on this process.
  constexpr unsigned int kFlags = 0x1 | 0x2;
  CUDA_CHECK_ERR(driver_.cuMemHostAlloc(&hostPtr, sizeof(uint64_t), kFlags));
  CUdeviceptr devPtr = nullptr;
  CUDADriver::Result r =
      driver_.cuMemHostGetDevicePointer_v2(&devPtr, hostPtr, 0);
  if (r != CUDADriver::SUCCESS) {
    (void)driver_.cuMemFreeHost(hostPtr);
    const char *errName = nullptr;
    (void)driver_.cuGetErrorName(r, &errName);
    return Error(
        std::string("cuMemHostGetDevicePointer_v2 failed for CompletionFlag: ")
            .append(errName ? errName : "(unknown)"));
  }
  // Initialize the flag to zero so the first wait observes a clean state.
  *static_cast<uint64_t *>(hostPtr) = 0;
  return CompletionFlagRef::take(
      new CompletionFlag(*this, hostPtr, reinterpret_cast<uint64_t>(devPtr)));
}

ErrorOrSuccess CUDADeviceContext::freeCompletionFlag(void *hostPtr) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::freeCompletionFlag",
                       TRACY_COLOR_PURPLE);
  CUDA_WITH_CTX_ERR(*this);
  POLL_PENDING_EVENTS(*this);
  CUDA_CHECK_ERR(driver_.cuMemFreeHost(hostPtr));
  return success();
}

bool CUDADeviceContext::ownsDeviceAddress(const void *ptr) const {
  if (ptr == nullptr)
    return false;
  // Query whether `ptr` is device-resident and, if so, which device it lives
  // on. cuPointerGetAttributes returns an error (not merely MEMORYTYPE_HOST)
  // for ordinary host pointers that were never allocated or registered through
  // CUDA, so any failure here means "not a device pointer we can borrow".
  CUmemorytype memType = CU_MEMORYTYPE_HOST;
  int ordinal = -1;
  CUpointer_attribute attrs[2] = {CU_POINTER_ATTRIBUTE_MEMORY_TYPE,
                                  CU_POINTER_ATTRIBUTE_DEVICE_ORDINAL};
  void *data[2] = {&memType, &ordinal};
  if (driver_.cuPointerGetAttributes(
          2, attrs, data,
          reinterpret_cast<CUdeviceptr>(const_cast<void *>(ptr))) !=
      CUDADriver::Result::SUCCESS)
    return false;
  // Only borrow memory that already lives on *this* device; a pointer on a
  // different GPU must still be staged. `device().id()` is the CUDA ordinal
  // (see CUDADevice::get -> cuDeviceGet), so it compares directly against
  // CU_POINTER_ATTRIBUTE_DEVICE_ORDINAL.
  return memType == CU_MEMORYTYPE_DEVICE && ordinal == device().id();
}

ErrorOrSuccess CUDADeviceContext::memCopyDtoD(DeviceBuffer &dst,
                                              DeviceBuffer &src,
                                              size_t srcByteOffset,
                                              size_t srcByteSize,
                                              bool crossStreamSync) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::memCopyDtoD", TRACY_COLOR_PURPLE);

  CHECK_IS_CUDA_ERR(src.context().device());
  CHECK_IS_CUDA_ERR(dst.context().device());
  CUDA_WITH_CTX_ERR(*this);

  // Resolve through backendContext() so a buffer stamped with a decorating
  // context (e.g. a device-graph RecordingDeviceContext) casts to the
  // driver-backed context it decorates.
  auto &srcCtx = CUDADeviceContext::cast(src.context().backendContext());
  auto &dstCtx = CUDADeviceContext::cast(dst.context().backendContext());

  if (this->context_ != dstCtx.context_) {
    RETURN_ERROR("device context does not match context of dst");
  }

  CUdeviceptr srcPtr = (uint8_t *)src.ptr() + srcByteOffset;
  CUdeviceptr dstPtr = dst.ptr();
  size_t dstByteSize = dst.byteSize();
  assert(srcByteOffset + srcByteSize <= src.byteSize());
  assert(srcByteSize == dstByteSize);
  // A copy whose source and destination are on different streams requires
  // cross-stream synchronization. Unless the caller opted out (because it
  // manages this synchronization itself, e.g. the graph compiler emits
  // explicit synchronization ops), bracket the copy with events so the
  // destination stream waits for the source before the copy and the source
  // stream waits for the copy to complete afterward.
  const bool needsSync =
      crossStreamSync && srcCtx.cudaStream() != dstCtx.cudaStream();

  if (needsSync) {
    // Ensure that we are waiting for the source data to be ready.
    DEFINE_OR_RETURN_ERROR(DeviceEventRef, srcEvent, srcCtx.enqueueEvent());
    RETURN_IF_ERROR(dstCtx.enqueueWaitForEvent(*srcEvent));
  }

  if (srcCtx.cudaContext() != dstCtx.cudaContext()) {
    CUDA_CHECK_ERR(driver_.cuMemcpyPeerAsync(dstPtr, dstCtx.context_, srcPtr,
                                             srcCtx.context_, dstByteSize,
                                             stream_));
  } else {
    CUDA_CHECK_ERR(
        driver_.cuMemcpyDtoDAsync_v2(dstPtr, srcPtr, dstByteSize, stream_));
  }

  if (needsSync) {
    // Wait for the copy to complete before proceeding with the source stream
    // (e.g. freeing or overwriting memory).
    DEFINE_OR_RETURN_ERROR(DeviceEventRef, dstEvent, dstCtx.enqueueEvent());
    RETURN_IF_ERROR(srcCtx.enqueueWaitForEvent(*dstEvent));
  }
  auto &registry = launchTraceRegistry();
  if (registry.isLaunchTraceEnabled(static_cast<void *>(stream_))) {
    KernelLaunchMetadata metadata(
        "cuMemcpyDtoD",
        hashMemcpyTrace(LaunchTraceKind::kMemcpyDtoD, dstByteSize),
        KernelLaunchMetadata::MemcpyKind::DtoD, dstByteSize);
    registry.appendLaunchTraceEntry(static_cast<void *>(stream_), metadata);
  }

  MAYBE_SYNC(*this);
  return success();
}

ErrorOrSuccess
CUDADeviceContext::memBatchCopy(llvm::ArrayRef<DeviceBuffer *> dsts,
                                llvm::ArrayRef<DeviceBuffer *> srcs) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::memBatchCopy", TRACY_COLOR_PURPLE);
  const size_t count = dsts.size();

  // No cuMemcpyBatchAsync (pre-CUDA 12.8): use the scalar loop.
  if (count == 0 || !driver_.hasCuMemcpyBatchAsync())
    return DeviceContext::memBatchCopy(dsts, srcs);

  CUDA_WITH_CTX_ERR(*this);

  // A pointer can join the batch only if UVA resolves it from this context:
  // host and pinned memory always do, a peer's memory only under peer access.
  // Every source context running on another stream needs its own ordering
  // bracket around the submit.
  SmallVector<CUDADeviceContext *, 2> streamSrcCtxs;
  SmallVector<DeviceBuffer *, 8> hostSrcs;
  std::vector<void *> dstPtrs(count);
  std::vector<const void *> srcPtrs(count);
  std::vector<size_t> sizes(count);
  size_t totalBytes = 0;
  for (size_t i = 0; i < count; ++i) {
    DeviceBuffer &src = *srcs[i];
    if (src.isHost() || src.context().device().api() == Device::cpuAPI) {
      hostSrcs.push_back(&src);
    } else {
      auto &srcCtx = CUDADeviceContext::cast(src.context().backendContext());
      if (srcCtx.cudaContext() != this->cudaContext()) {
        DEFINE_OR_RETURN_ERROR(bool, peerEnabled,
                               Device::allPeerAccessEnabled());
        // Without a peer mapping the pointer is unreachable from here; the
        // scalar loop reaches it with cuMemcpyPeerAsync.
        if (!peerEnabled)
          return DeviceContext::memBatchCopy(dsts, srcs);
      }
      if (srcCtx.cudaStream() != this->cudaStream() &&
          !llvm::is_contained(streamSrcCtxs, &srcCtx))
        streamSrcCtxs.push_back(&srcCtx);
    }
    dstPtrs[i] = dsts[i]->ptr();
    srcPtrs[i] = src.ptr();
    sizes[i] = dsts[i]->byteSize();
    totalBytes += sizes[i];
  }

  // Mirror the scalar host path: a source owned by a CPU device context has to
  // be settled up front because events cannot be awaited across device types,
  // and any host source is DMA'd on our stream rather than its owning one, so
  // its deferred free must be ordered against us too.
  for (DeviceBuffer *src : hostSrcs) {
    if (src->context().device().api() == Device::cpuAPI)
      RETURN_IF_ERROR(src->context().synchronize());
    recordBufferUsedOnContext(*src, *this);
  }

  // Match scalar memCopyDtoD: our stream waits for each source stream before
  // the copy, and each source stream waits for the copy afterwards.
  for (CUDADeviceContext *srcCtx : streamSrcCtxs) {
    DEFINE_OR_RETURN_ERROR(DeviceEventRef, srcEvent, srcCtx->enqueueEvent());
    RETURN_IF_ERROR(this->enqueueWaitForEvent(*srcEvent));
  }

  CUmemcpyAttributes attrs{};
  attrs.srcAccessOrder = CU_MEMCPY_SRC_ACCESS_ORDER_STREAM;
  size_t attrsIdx = 0;
  size_t failIdx = 0;
  CUDA_CHECK_ERR(driver_.cuMemcpyBatchAsync(
      dstPtrs.data(), srcPtrs.data(), sizes.data(), count, &attrs, &attrsIdx,
      /*numAttrs=*/1, &failIdx, stream_));

  if (!streamSrcCtxs.empty()) {
    DEFINE_OR_RETURN_ERROR(DeviceEventRef, dstEvent, this->enqueueEvent());
    for (CUDADeviceContext *srcCtx : streamSrcCtxs)
      RETURN_IF_ERROR(srcCtx->enqueueWaitForEvent(*dstEvent));
  }

  auto &registry = launchTraceRegistry();
  if (registry.isLaunchTraceEnabled(static_cast<void *>(stream_))) {
    KernelLaunchMetadata metadata(
        "cuMemcpyBatch",
        hashMemcpyTrace(LaunchTraceKind::kMemcpyDtoD, totalBytes),
        KernelLaunchMetadata::MemcpyKind::DtoD, totalBytes);
    registry.appendLaunchTraceEntry(static_cast<void *>(stream_), metadata);
  }

  MAYBE_SYNC(*this);
  return success();
}

ErrorOrSuccess CUDADeviceContext::enqueueSetMemory(void *dst, size_t byteSize,
                                                   uint64_t val,
                                                   size_t valSize) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::enqueueSetMemory",
                       TRACY_COLOR_PURPLE);

  CUDA_WITH_CTX_ERR(*this);
  if (valSize == 1) {
    CUDA_CHECK_ERR(driver_.cuMemsetD8Async(dst, static_cast<uint8_t>(val),
                                           byteSize, stream_));
  } else if (valSize == 2) {
    if ((byteSize & 1) != 0) {
      return Error("byteSize of buffer is misaligned");
    }
    size_t len = byteSize >> 1;
    CUDA_CHECK_ERR(driver_.cuMemsetD16Async(dst, static_cast<uint16_t>(val),
                                            len, stream_));
  } else if (valSize == 4) {
    if ((byteSize & 3) != 0) {
      return Error("byteSize of buffer is misaligned");
    }
    size_t len = byteSize >> 2;
    CUDA_CHECK_ERR(driver_.cuMemsetD32Async(dst, static_cast<uint32_t>(val),
                                            len, stream_));
  } else {
    if (valSize != 8) {
      return Error("unsupported valSize");
    }
    if ((byteSize & 7) != 0) {
      return Error("byteSize of buffer is misaligned");
    }
    uint32_t hiBits = static_cast<uint32_t>(val >> 32);
    uint32_t loBits = static_cast<uint32_t>(val & 0xfffffffful);
    if (hiBits == loBits) {
      size_t len = byteSize >> 2; // Divide by 4 as we are using 32-bit memset.
      CUDA_CHECK_ERR(driver_.cuMemsetD32Async(dst, loBits, len, stream_));
    } else {
      size_t len = byteSize >> 3;
      void *hiPtr = reinterpret_cast<void *>(reinterpret_cast<uintptr_t>(dst) +
                                             sizeof(uint32_t));
      CUDA_CHECK_ERR(
          driver_.cuMemsetD2D32Async(dst, 8, loBits, 1, len, stream_));
      CUDA_CHECK_ERR(
          driver_.cuMemsetD2D32Async(hiPtr, 8, hiBits, 1, len, stream_));
    }
  }
  auto &registry = launchTraceRegistry();
  if (registry.isLaunchTraceEnabled(static_cast<void *>(stream_))) {
    KernelLaunchMetadata metadata("cuMemset",
                                  hashMemsetTrace(byteSize, val, valSize),
                                  byteSize, val, valSize);
    registry.appendLaunchTraceEntry(static_cast<void *>(stream_), metadata);
  }

  MAYBE_SYNC(*this);
  return success();
}

static ErrorOr<std::pair<SmallVector<CUjit_option>, SmallVector<uintptr_t>>>
setupCompilationOptions(StringRef debugLevel, int32_t optimizationLevel) {
  static constexpr int kDefaultOptimizationLevel = 4;

  SmallVector<CUjit_option, 2> optionKind;
  SmallVector<uintptr_t, 2> optionValues;

  // The default optimization level for NVIDIA GPUs is 4.
  if (optimizationLevel < 0)
    optimizationLevel = kDefaultOptimizationLevel;

  // The Mojo compiler uses optimization level 3 as the highest optimization
  // level, but 4 is the highest for CUDA.
  if (optimizationLevel == 3)
    optimizationLevel = kDefaultOptimizationLevel;

  if (debugLevel == "full") {
    // Note that the PTX compiler complains if debugLevel=full and optimization
    // level is something other than 0 or 4 (the default).
    if (!llvm::is_contained({0, kDefaultOptimizationLevel},
                            optimizationLevel)) {
      RETURN_ERROR((("debugLevel of \"full\" requires optimizationLevel of "
                     "either '0' or '" +
                     llvm::Twine(kDefaultOptimizationLevel) + "' but got '" +
                     llvm::Twine(optimizationLevel) + "'"))
                       .str());
    }

    optionKind.push_back(CUjit_option::JIT_GENERATE_DEBUG_INFO);
    optionValues.push_back(1);
  } else if (debugLevel == "line-tables") {
    optionKind.push_back(CUjit_option::JIT_GENERATE_LINE_INFO);
    optionValues.push_back(1);
  }

  if (optimizationLevel != kDefaultOptimizationLevel) {
    optionKind.push_back(CUjit_option::JIT_OPTIMIZATION_LEVEL);
    optionValues.push_back(optimizationLevel);
  }

  return std::make_pair(optionKind, optionValues);
}

ErrorOr<DeviceFunctionRef>
CUDADeviceContext::loadFunction(StringRef moduleName, StringRef functionName,
                                StringRef code, int32_t maxDynamicSharedBytes,
                                StringRef debugLevel,
                                int32_t optimizationLevel) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::loadFunction", TRACY_COLOR_PURPLE);
  Device::FunctionCacheKey key{
      /*name=*/Device::FunctionCacheKey::moduleCacheName(moduleName, code),
      /*functionName=*/functionName.str(),
      /*debugLevel=*/debugLevel.str(),
      /*maxDynamicSharedBytes=*/maxDynamicSharedBytes,
      /*optimizationLevel=*/optimizationLevel};
  DeviceFunctionCacheEntryRef entry = device().findInFunctionCache(key);
  if (entry.getPointer() != nullptr && !bypassFunctionCache_) {
    CUDAModuleFunctionRef moduleFunc =
        CUDAModuleFunctionRef::take(CUDAModuleFunction::cast(entry.release()));
    return CUDADeviceFunctionRef::create(*this, std::move(moduleFunc));
  }

  // Only the miss path takes the gate: a hit issues no driver calls, and
  // gating it would put process-wide state on every kernel enqueue.
  KernelLoadGate::LoadScope loadGate(driver_.kernelLoadGate());

  // Under the bypass a cached kernel reloads on every launch; logging only
  // first loads keeps the log to one line per kernel and device.
  if (logLoadFunction_ && entry.getPointer() == nullptr) {
    // Assemble first, then write once. `errs()` is unbuffered and every `<<`
    // is its own write, so concurrent loaders otherwise interleave mid-record
    // and a reader cannot tell which name belongs to which load.
    llvm::SmallString<512> message;
    llvm::raw_svector_ostream stream(message);
    // The OS thread id is what a debugger reports as the thread's LWP, so a
    // backtrace taken during a stuck load names the kernel it wanted. The
    // CUDA ordinal rather than the logical device id, because it is what
    // `nvidia-smi` indexes by and the two diverge once a process is given a
    // subset of the node's GPUs.
    stream << "[tid " << llvm::get_threadid() << " device "
           << CUDADevice::cast(device()).cudaDevice()
           << "] CUDADeviceContext::loadFunction(" << functionName
           << (logVerbose_ ? "):\n" : ")") << (logVerbose_ ? code : "") << "\n";
    llvm::errs() << message;
  }
  auto errorOrOpts = setupCompilationOptions(debugLevel, optimizationLevel);
  if (errorOrOpts)
    return errorOrOpts.takeError();
  auto [optionKind, optionValues] = errorOrOpts.takeValue();

  CUmodule module;
  CUDA_WITH_CTX_ERR(*this);
  POLL_PENDING_EVENTS(*this);

  CUDA_CHECK_ERR(driver_.cuModuleLoadDataEx(
      &module, code.data(), optionKind.size(), optionKind.data(),
      reinterpret_cast<void **>(optionValues.data())));

  CUfunction function;
  CUDA_CHECK_ERR_MSG(
      driver_.cuModuleGetFunction(&function, module, functionName.data()),
      "function name: " + functionName.str());

  CUDA_CHECK_ERR(driver_.cuFuncSetAttribute(
      function,
      CUfunction_attribute::FUNC_ATTRIBUTE_NON_PORTABLE_CLUSTER_SIZE_ALLOWED,
      1));

  if (maxDynamicSharedBytes >= 0) {
    CUDA_CHECK_ERR(driver_.cuFuncSetAttribute(
        function,
        CUfunction_attribute::FUNC_ATTRIBUTE_MAX_DYNAMIC_SHARED_SIZE_BYTES,
        maxDynamicSharedBytes));
  }

  // Allocate func outside of the lock region to reduce the time spent under
  // lock. If this functionName has been registered concurrently, then we will
  // release this ref outside of the lock region before returning.
  auto moduleFunc = CUDAModuleFunctionRef::create(
      std::string(functionName), this->cudaDriver(), module, function);
  CUDADeviceFunctionRef result;
  entry = device().insertInFunctionCache(key, *moduleFunc);
  result = CUDADeviceFunctionRef::create(
      *this,
      CUDAModuleFunctionRef::take(CUDAModuleFunction::cast(entry.release())));
  return result;
}

ErrorOr<DeviceStreamRef> CUDADeviceContext::createStream(int priority) {
  // Ensure stream is created for this context.
  CUDA_WITH_CTX_ERR(*this);

  // Default priority is 0 (lowest); compatible with CUDA specs.

  // CUDA blocking streams are a legacy feature; interpretation of "blocking"
  // is w.r.t. the default stream and does not mean "synchronous".
  // We want our streams to be independent of any other stream.
  unsigned int constexpr kNonBlocking = 0x1;

  CUstream stream;
  CUDA_CHECK_ERR(this->cudaDriver().cuStreamCreateWithPriority(
      &stream, kNonBlocking, priority));

  // The pool takes ownership of the stream; the pool destroys the stream when
  // the context is released.
  streamPool_->emplace_back(stream);

  return CUDADeviceStreamRef::create(*this, stream);
}

unsigned CUDADeviceContext::numStreams() const { return streamPool_->size(); }

ErrorOr<DeviceContextRef> CUDADeviceContext::selectStream(unsigned streamId) {
  // Streams are created once at model setup (see ensureStreamCountForDevices in
  // MEFModel); a stream id past the end of the pool is a programming error.
  if (streamId >= streamPool_->size())
    return Error("invalid stream id: " + llvm::Twine(streamId));

  // Selecting the already-active stream is a no-op: hand back this context.
  if (streamPool_->get(streamId) == stream_)
    return DeviceContextRef::copy(this);

  // Return a retain-all view: a new context co-owning the same stream pool and
  // CUcontext (and therefore the same device memory pool), differing only in
  // which pooled stream is active.
  return DeviceContextRef::take(new CUDADeviceContext(
      CUDADevice::cast(device()), context_, streamPool_, streamId));
}

ErrorOr<DeviceEventRef> CUDADeviceContext::eventCreate(bool enableTiming) {
  TRACY_ZONE_SCOPED_NC("CUDADeviceContext::eventCreate", TRACY_COLOR_PURPLE);

  const bool recordedDuringCapture = isStreamCapturing(driver_, stream_);

  CUDA_WITH_CTX_ERR(*this);
  POLL_PENDING_EVENTS(*this);
  if (enableTiming) {
    // The cache holds only non-timing events, so timing events bypass it.
    CUevent event;
    CUDA_CHECK_ERR(driver_.cuEventCreate(
        &event, static_cast<unsigned int>(CUevent_flags::CU_EVENT_DEFAULT)));
    return CUDADeviceEventRef::create(CUDADevice::cast(this->device()), event,
                                      /*recordedDuringCapture=*/
                                      recordedDuringCapture,
                                      /*enableTiming=*/true);
  }
  // Reuse the cache the destructor pushes into, or it grows without bound.
  DEFINE_OR_RETURN_ERROR(CUevent, event,
                         CUDADevice::cast(device()).eventCachePop(
                             /*useCache=*/!recordedDuringCapture));
  return CUDADeviceEventRef::create(CUDADevice::cast(this->device()), event,
                                    /*recordedDuringCapture=*/
                                    recordedDuringCapture,
                                    /*enableTiming=*/false);
}

  CUDA_WITH_CTX_ERR(*this);

  CUDA_CHECK_ERR(driver_.cuEventCreate(&start, 0));
  CUDA_CHECK_ERR(driver_.cuEventCreate(&stop, 0));

  auto timer = CUDADeviceTimerRef::create(*this, start, stop);

  CUDA_CHECK_ERR(driver_.cuEventRecord(timer->cudaStartEvent(), stream_));

  return timer;
}

ErrorOr<std::chrono::nanoseconds>
CUDADeviceContext::stopTimer(const DeviceTimer &timer) {
  const auto &cudaTimer = CUDADeviceTimer::cast(timer);

  CUDA_WITH_CTX_ERR(*this);
  POLL_PENDING_EVENTS(*this);
  CUDA_CHECK_ERR(driver_.cuEventRecord(cudaTimer.cudaStopEvent(), stream_));
  CUDA_CHECK_ERR(driver_.cuEventSynchronize(cudaTimer.cudaStopEvent()));

  float millis;
  CUDA_CHECK_ERR(driver_.cuEventElapsedTime(&millis, cudaTimer.cudaStartEvent(),
                                            cudaTimer.cudaStopEvent()));

  constexpr double nanosPerMillisecond = 1000.0 * 1000.0;
  double nanos = static_cast<double>(millis) * nanosPerMillisecond;
  return std::chrono::nanoseconds(static_cast<int64_t>(nanos));
}

// Call sysconf() and check for errors.
static ErrorOr<size_t> getSystemValue(int name) {
  errno = 0;
  auto value = sysconf(name);
  if (errno != 0)
    RETURN_ERROR(strerror(errno));
  return static_cast<size_t>(value);
}

ErrorOr<Device::MemInfo> CpuDevice::getMemoryInfo() const {
  Device::MemInfo info;
  auto numPages = getSystemValue(_SC_PHYS_PAGES);
  if (numPages.isError())
    return numPages.takeError();
  auto pageSize = getSystemValue(_SC_PAGE_SIZE);
  if (pageSize.isError())
    return pageSize.takeError();

  rusage usage;
  if (-1 == getrusage(RUSAGE_SELF, &usage))
    RETURN_ERROR("Failed to get current memory usage via rusage");

// The unit for the _SC_PAGE_SIZE is bytes. The unit for the ru_maxrss is
// kilobytes on Linux and bytes on MacOS.
#if MODULAR_LINUX
  const size_t maxrssMultiple = 1024;
#else // macOS
  const size_t maxrssMultiple = 1;
#endif

  // This is the maximum resident set size used.
  // Current memory use may be lower, this is the "high water mark".
  size_t used = usage.ru_maxrss * maxrssMultiple;
  // Total memory = number of pages times the page size.
  info.total = numPages.takeValue() * pageSize.takeValue();
  // Free memory = total memory minus memory in use.
  info.free = info.total - used;
  return info;
}

CpuDeviceContext::CpuDeviceContext(CpuDevice &device)
    : DeviceContext(device, TypeID::get<CpuDeviceContext>()) {
  // Get or create the cpuDevice. Request mainWillDonate=false if this is the
  // only cpuDevice user, but allow using the existing cpuDevice options if they
  // are set. This is safe as the other cpuDevice users are guaranteeing they
  // will wait on the main thread to progress work. Otherwise CpuDeviceContext
  // is invariant to the cpuDevice options, so this is safe.
  cpuDevice = AsyncRT::getOrCreateCPUDevice(
      AsyncRT::CPUDeviceSource::CPUDeviceContext,
      AsyncRT::CPUDeviceOptions().withMainWillNotDonate(),
      /*allowUsingExistingOptions=*/true);

  streamChain = cpuDevice->getReadyChain().copy();
}

CpuDeviceContext::~CpuDeviceContext() {
  // Wait for pending work to finish
  if (!streamChain.isReady())
    cpuDevice->getWorkQueue()->await({&streamChain, 1});
}

ErrorOrSuccess CpuDeviceContext::memFree(void *ptr, Device::FreeKind kind) {
  TRACY_ZONE_SCOPED_NC("CpuDeviceContext::memFree", TRACY_COLOR_PURPLE);
  // A CPU device's allocations are already host memory; nothing to wrap.
  if (kind == Device::FreeKind::WRAPPED)
    RETURN_ERROR("CpuDeviceContext::memFree: WRAPPED memory is not supported");
  // The Runtime's allocator outlives any work enqueued on its work queue, so
  // capturing a raw pointer here (rather than a CPUDeviceRef) is safe.
  auto *allocator = cpuDevice->getAllocator();
  if (kind == Device::FreeKind::HOST) {
    allocator->deallocateBytes(ptr);
    return success();
  }
  return enqueueWork([=]() { allocator->deallocateBytes(ptr); });
}

// Enqueue work with stream-like semantics. Keep a chain to the last enqueued
// function so the next task can await it.
// Returns any pending error from previously enqueued async work.
ErrorOrSuccess CpuDeviceContext::enqueueWork(AsyncRT::TaskFunction &&work) {
  RETURN_IF_PENDING_ERROR(*this);

  auto eventChain =
      AsyncRT::AsyncValueRef<AsyncRT::Chain>::allocate(*cpuDevice);

  std::lock_guard<std::mutex> streamLock{streamChainMutex};
  streamChain.andThenAsync(
      [work = std::move(work), eventChain = eventChain.copy()]() mutable {
        work();
        std::move(eventChain).emplace();
      });
  streamChain = std::move(eventChain);
  return success();
}

ErrorOrSuccess CpuDeviceContext::memCopyDtoD(DeviceBuffer &dst,
                                             DeviceBuffer &src,
                                             size_t srcByteOffset,
                                             size_t srcByteSize,
                                             bool /*crossStreamSync*/) {
  TRACY_ZONE_SCOPED_NC("CpuDeviceContext::memCopyDtoD", TRACY_COLOR_PURPLE);

}

ErrorOrSuccess CpuDeviceContext::enqueueSetMemory(void *dst, size_t byteSize,
                                                  uint64_t val,
                                                  size_t valSize) {
  TRACY_ZONE_SCOPED_NC("CpuDeviceContext::enqueueSetMemory",
                       TRACY_COLOR_PURPLE);

  if (valSize > sizeof(uint64_t))
    return Error("unsupported val size");

  if (valSize != 1 && (byteSize & (valSize - 1)))
    return Error("byteSize of buffer is misaligned");

  return enqueueWork([this, dst, byteSize, val, valSize]() {
    size_t len = byteSize / valSize;
    switch (valSize) {
    case 1: {
      uint8_t u8Val = static_cast<uint8_t>(val);
      RECORD_PENDING_ERROR(*this,
                           M::fillHomogeneous(dst, len, DType::ui8, &u8Val));
      break;
    }
    case 2: {
      uint16_t ui16Val = static_cast<uint16_t>(val);
      RECORD_PENDING_ERROR(*this,
                           M::fillHomogeneous(dst, len, DType::ui16, &ui16Val));
      break;
    }
    case 4: {
      uint32_t ui32Val = static_cast<uint32_t>(val);
      RECORD_PENDING_ERROR(*this,
                           M::fillHomogeneous(dst, len, DType::ui32, &ui32Val));
      break;
    }
    case 8: {
      uint64_t ui64Val = static_cast<uint64_t>(val);
      RECORD_PENDING_ERROR(*this,
                           M::fillHomogeneous(dst, len, DType::ui64, &ui64Val));
      break;
    }
    default:
      llvm_unreachable("unsupported val size");
    }
  });
}

DeviceContext::MMapFileImplResult
CpuDeviceContext::memmapFileImpl(const std::filesystem::path &filename) const {
  auto result = openFile(filename, /*readOnly*/ true);
  if (result)
    return result.takeError();
  auto [fd, status] = *result;

  auto size = status.getSize();

  std::error_code ec;
  llvm::sys::fs::mapped_file_region mappedFile(
      fd, llvm::sys::fs::mapped_file_region::readonly, size, 0, ec);
  if (ec) {
    llvm::sys::fs::closeFile(fd);
    return Error(ec.message());
  }

  // Close the file, mmap will hold a ref to the descriptor.
  llvm::sys::fs::closeFile(fd);

  return std::tuple{
      mappedFile.data(),
      size,
      std::optional{std::move(mappedFile)},
  };
}

ErrorOrSuccess
CpuDeviceContext::enqueueHostFunction(void (*resumeFunc)(int8_t *),
                                      void (*destroyFunc)(int8_t *),
                                      int8_t *coroHandle) {
  TRACY_ZONE_SCOPED_NC("CpuDeviceContext::enqueueHostFunction",
                       TRACY_COLOR_PURPLE);
  // Resume the coroutine to execute the enqueued function, then immediately
  // destroy the coroutine as ownership of it has been transferred from Mojo by
  // this point.
  return enqueueWork([=]() {
    resumeFunc(coroHandle);
    destroyFunc(coroHandle);
  });
}

ErrorOrSuccess CpuDeviceContext::enqueueHostFunctionRange(
    void (*resumeFunc)(int8_t *), void (*destroyFunc)(int8_t *),
    int8_t **coroHandles, size_t numHandles) {
  TRACY_ZONE_SCOPED_NC("CpuDeviceContext::enqueueHostFunctionRange",
                       TRACY_COLOR_PURPLE);
  RETURN_IF_PENDING_ERROR(*this);

  if (numHandles == 0)
    return success();

  size_t numWorkers = cpuDevice->getWorkQueue()->getParallelismLevel();
  auto eventChain =
      AsyncRT::AsyncValueRef<AsyncRT::Chain>::allocate(*cpuDevice);
  std::lock_guard<std::mutex> streamLock{streamChainMutex};

  // When the current streamChain is ready, fan out all coroutine handles
  // across worker threads via parallelForEachNChainWithTaskIds, then
  // complete eventChain when all handles have been processed.
  // Copy the handles array since it may not outlive this call. Use a plain
  // std::vector as we will typically have one handle per CPU thread which is
  // too big for SmallVector.
  streamChain.andThenSync([cpuDevice = this->cpuDevice, numWorkers, resumeFunc,
                           destroyFunc, eventChain = eventChain.copy(),
                           handles = std::vector<int8_t *>(
                               coroHandles,
                               coroHandles + numHandles)]() mutable {
    size_t count = handles.size();
    auto completionChain = AsyncRT::parallelForEachNChainWithTaskIds(
        *cpuDevice, count,
        [numWorkers](size_t i) -> int {
          return static_cast<int>(i % numWorkers);
        },
        [resumeFunc, destroyFunc](size_t i, std::vector<int8_t *> &handles) {
          resumeFunc(handles[i]);
          destroyFunc(handles[i]);
        },
        std::move(handles));
    completionChain.andThenSync([eventChain = std::move(eventChain)]() mutable {
      std::move(eventChain).emplace();
    });
  });

  streamChain = std::move(eventChain);
  return success();
}

using DeviceToPyDeviceMap =
    llvm::SmallDenseMap<M::DeviceRef, Driver::Python::PyDeviceTy>;

/// Convert model execution results to Python buffers.
static std::vector<Driver::Python::Buffer>
extractPyBufferResults(ArrayRef<M::GraphCompiler::Driver::ExecResult> results,
                       ArrayRef<Driver::Python::PyDeviceTy> devices) {
  // Reconstruct a set of output tensor objects to be returned to the user.
  std::vector<Driver::Python::Buffer> pyResults;
  pyResults.reserve(results.size());

  // Aliasing outputs share one device buffer, so they must share one storage
  // for the Python objects to alias the way they did before.
  llvm::SmallDenseMap<M::Driver::DeviceBuffer *,
                      std::shared_ptr<Driver::Python::BufferStorage>>
      storageCache;
  size_t index = 0;
  for (const auto &result : results) {
    auto [it, inserted] =
        storageCache.try_emplace(result.buffer.getPointer(), nullptr);
    if (inserted)
      it->second = std::make_shared<Driver::Python::BufferStorage>(
          result.buffer, result.spec);
    pyResults.emplace_back(it->second, devices[index], nullptr);
    ++index;
  }

  return pyResults;
}

/// Resolves device references against session devices.
/// Creates CPU devices if needed, throws for missing accelerator devices.
static std::vector<Driver::Python::PyDeviceTy>
resolveDeviceRefs(const ArrayRef<M::DeviceRef> deviceRefs,
                  const DeviceToPyDeviceMap &sessionDeviceMap,
                  StringRef contextString) {
  std::vector<Driver::Python::PyDeviceTy> res;
  res.reserve(deviceRefs.size());

  for (const auto &[idx, deviceRef] : llvm::enumerate(deviceRefs)) {
    auto it = sessionDeviceMap.find(deviceRef);
    if (it != sessionDeviceMap.end()) {
      // Device found in session map.
      res.emplace_back(it->second);
      continue;
    }

    // Device not found in session map.
    if (deviceRef.label == kCPULabel) {
      // Handle CPU specially: create/get if not present.
      // TODO(GEX-2092): always create CPU device on the session.
      res.emplace_back(Driver::Python::getCpuDevice(deviceRef.id));
    } else {
      // Accelerator device not found, throw error.
      throw std::invalid_argument("Loaded Model " + contextString.str() +
                                  " idx=" + std::to_string(idx) +
                                  " uses device=" + deviceRef.toString() +
                                  " which was not set up in InferenceSession");
    }
  }
  return res;
}

/// Get a vector of all input tensors' device.
/// Throws a std::invalid_argument if getting the device for any particular
/// input is unsuccessful.
std::vector<Driver::Python::PyDeviceTy>
M::Core::ModelHandle::getInputDevices() const {
  if (!loadedModel)
    return {};

  DeviceToPyDeviceMap deviceMap;
  for (const auto &pyDevice : inferenceSession->getDevices())
    deviceMap.insert({pyDevice->deviceSpec.ref, pyDevice});

  auto *executableModel = loadedModel->get();
  if (!executableModel)
    return {};
  auto deviceRefs = executableModel->getModel()->getInputDevices();

/// Build a WeightsRegistry and shared managed-tensor vector from a Python dict.
///
/// Handles both read-only numpy arrays (borrowed pointer) and objects
/// implementing the DLPack protocol (shared ownership via DLManagedTensor).
/// Both the registry and the managed-tensor vector must outlive any model
/// that uses the registry.
static std::pair<WeightsRegistryRef,
                 std::shared_ptr<SmallVector<DLPack::DLManagedTensorWrapper>>>
buildWeightsFromDict(const nb::dict &weightsDict) {
  size_t dictSize = weightsDict.size();
  std::vector<const char *> weightNames;
  weightNames.reserve(dictSize);
  std::vector<const void *> weightPtrs;
  weightPtrs.reserve(dictSize);
  SmallVector<DLPack::DLManagedTensorWrapper> localManagedTensors;
  localManagedTensors.reserve(dictSize);

  for (const auto &[name, array] : weightsDict) {
    weightNames.push_back(nb::borrow<nb::str>(name).c_str());

    // TODO(MSDK-976): Older versions of numpy don't support the dlpack protocol
    // for read-only arrays (e.g. that come from memmapped weights). So for now
    // we just borrow their pointers and assume (hope, really) that they will
    // outlive our model execution.
    if (nb::isinstance<nb::ndarray<nb::ro>>(array)) {
      // We're specifically testing for read-only arrays, but a read-write array
      // also satisfies the above check. So make sure it isn't a read-write.
      if (!nb::isinstance<nb::ndarray<>>(array)) {
        auto npArray = nb::cast<nb::ndarray<nb::ro>>(array);
        weightPtrs.push_back(npArray.data());
        continue;
      }
    } else if (!nb::hasattr(array, "__dlpack__") ||
               !nb::hasattr(array, "__dlpack_device__")) {
      throw std::invalid_argument(
          "weight registry element does not implement dlpack");
    }

    // Take a shared owning reference to the underlying data from the input
    // weightsDict. Using the dlpack API ensures that the producer framework
    // (e.g. numpy) gets notified, and keeps the underlying array alive as long
    // as we need it.
    auto arrayOrTensor = nb::borrow<nb::object>(array);

    // This also ensures that the device is supported by dlpack.
    auto [_, streamID] = Driver::Python::getPyDevice(arrayOrTensor);

    DLPack::DLManagedTensorWrapper &managed = localManagedTensors.emplace_back(
        DLPack::callDLPack(arrayOrTensor, streamID));
    weightPtrs.push_back(managed->dl_tensor.data);
  }

  auto weightsRegistryOr = WeightsRegistry::create(
      {weightNames.data(), weightNames.size()},
      {llvm::bit_cast<const std::byte **>(weightPtrs.data()),
       weightPtrs.size()});
  if (weightsRegistryOr.isError())
    throw std::invalid_argument(weightsRegistryOr.getError());

  // Wrap the managed tensors in a shared_ptr so callers can share ownership
  // across multiple ModelHandles (keeping DLPack wrappers alive until all
  // consumers are destroyed).
  return {weightsRegistryOr.takeValue(),
          std::make_shared<SmallVector<DLPack::DLManagedTensorWrapper>>(
              std::move(localManagedTensors))};
}

M::AsyncExecutableModel
M::Core::InferenceSession::load(const M::Model *model,
                                WeightsRegistryRef weightsRegistry) {
  auto execModelAsync = runtimeContext->initModel(model, weightsRegistry);
  // Release the GIL during model initialization to allow other Python threads
  // to run (e.g., for logging progress messages during long loads).
  nb::gil_scoped_release release;
  if (auto err = Engine::Context::await(execModelAsync.copy()))
    throw std::invalid_argument(err.takeError().get());
  return execModelAsync;
}

/// Initializes all models in the compiled artifact and returns one ModelHandle
/// per model in MEF order.
std::vector<M::Core::ModelHandle>
M::Core::InferenceSession::loadAll(AsyncValueRef<CompiledModels> compiledModels,
                                   const nb::dict &weightsDict) {
  auto [sharedWeightsRegistry, sharedManagedTensors] =
      buildWeightsFromDict(weightsDict);

  // Ensure the compiled models are ready before accessing individual Model*s.
  // Release the GIL during the await to allow other Python threads to run
  // (e.g., for logging progress messages during long compilations).
  {
    nb::gil_scoped_release release;
    if (auto err = Engine::Context::await(compiledModels.copy()))
      throw std::invalid_argument(err.takeError().get());
  }

  const CompiledModels &compiled = compiledModels.get();
  size_t numModels = compiled.getNumModels();

  std::vector<ModelHandle> results;
  results.reserve(numModels);
  for (auto &&[index, model] : llvm::enumerate(compiled)) {
    M::AsyncExecutableModel execModel =
        load(model.get(), sharedWeightsRegistry);
    ModelHandle handle(compiledModels.copy(), nb::ref<InferenceSession>(this),
                       std::move(execModel), sharedWeightsRegistry,
                       sharedManagedTensors, index);
    // Build input and output device vectors exactly once at model load time.
    handle.inputDevicesPy = handle.getInputDevices();
    handle.outputDevicesPy = handle.getOutputDevices();
    results.push_back(std::move(handle));
  }
  return results;
}

void M::Core::ModelHandle::reload(const nb::dict &weightsDict) {
  // Drop current resource references before attempting to reload.
  weightsRegistry = {};
  managedTensors = {};
  loadedModel = {};

  auto [newRegistry, newManagedTensors] = buildWeightsFromDict(weightsDict);
  loadedModel = inferenceSession->load(
      compiledModels.get().getModel(modelIndex), newRegistry);
  weightsRegistry = std::move(newRegistry);
  managedTensors = std::move(newManagedTensors);
  inputDevicesPy = getInputDevices();
  outputDevicesPy = getOutputDevices();
}

void M::Core::ModelHandle::releaseWeights() {
  weightsRegistry = {};
  managedTensors = {};
}

void M::Core::ModelHandle::export_mef(const char *path) {
  if (!compiledModels || !compiledModels->getBuffer()) {
    throw std::invalid_argument(
        "model is null or compiled model isn't available");
  }
  // TODO MSDK-1026: Delete the `remove` call below.
  // Remove the file if it exists. Currently, the getFile maps the file to be
  // written to. But if the new content is shorter than the original file
  // content, there will be leftover data from the old version. A better fix is
  // to provide a createFile in WriteableBuffer.
  (void)llvm::sys::fs::remove(path);
  auto writeOr = WriteableBuffer::getFile(

    throw std::invalid_argument(writeOr.getError());
  }
  // Handle error
  WriteableBufferRef os = writeOr.takeValue();
  *os << compiledModels->getBuffer()->getBuffer();
}

/// Verifies that the input tensor's device matches that expected by the model.
/// It is only OK to pass a device pinned host tensor when a CPU graph input is
/// expected. It is not allowed to pass a pinned tensor in place of a GPU input.
/// Raises an `IndexError` if the tensor input index is out of bounds for the
/// model.
/// Raises a `TypeError` if the input tensor has a different device than that
/// expected by the model.
static void
verifyInputDevice(const Driver::Python::Buffer *tensor,
                  ArrayRef<Driver::Python::PyDeviceTy> modelInputDevices,
                  size_t tensorInputIdx) {
  if (tensorInputIdx >= modelInputDevices.size()) {
    std::string errorMsg = ("tensor input index " + Twine(tensorInputIdx) +
                            " out of bounds for model with " +
                            Twine(modelInputDevices.size()) + " devices")
                               .str();
    throw nb::index_error(errorMsg.c_str());
  }

  Driver::Python::PyDeviceTy modelInputDevice =
      modelInputDevices[tensorInputIdx];

  // A pinned tensor can only be used in place of a CPU graph input.
  // It cannot be used in place of a GPU graph input.
  if (tensor->isPinned()) {
    if (modelInputDevice->isHost()) {
      return;
    } else {
      std::string errorMsg =
          (Twine("expected argument ") + Twine(tensorInputIdx) +
           " to be a device tensor on " + modelInputDevice->getAsString() +
           " but found pinned tensor on " + tensor->getDevice()->getAsString() +
           " instead. Pinned tensors can only be used in place of CPU graph "
           "inputs.")
              .str();
      throw nb::type_error(errorMsg.c_str());
    }
  }
  // Otherwise, the tensor must be on matching devices.
  if (*tensor->getDevice() == *modelInputDevice)
    return;

  // Mismatch! Throw an error.
  std::string errorMsg =
      (Twine("expected argument ") + Twine(tensorInputIdx) +
       " to be on device " + modelInputDevice->getAsString() +
       ", but was on device " + tensor->getDevice()->getAsString())
          .str();
  throw nb::type_error(errorMsg.c_str());
}

/// Validates an ordered list of optional TensorSpecs for their compatibility
/// with a provided model. This is used when our execution inputs are an ordered
/// list of tensors or types that we don't verify.
static void validateInputSpecList(
    const AsyncValueRef<CompiledModels> &models, size_t modelIndex,
    const std::vector<Driver::Python::Buffer *> &inputTensors) {
  ErrorOr<ArrayRef<QuantTensorSpec>> inputSpecsOr =
      Engine::Context::getInputSpecs(models.copy(), modelIndex);
  if (inputSpecsOr.isError())
    throw std::invalid_argument(inputSpecsOr.takeError().get());

  ArrayRef<QuantTensorSpec> inputSpecs = inputSpecsOr.get();

  // We need to validate that the user has provided the correct number of
  // inputs.
  size_t numInputs = inputTensors.size();
  if (numInputs != inputSpecs.size()) {
    throw std::invalid_argument(
        "Number of inputs (" + std::to_string(numInputs) +
        ") does not match expected number (" +
        std::to_string(inputSpecs.size()) + ") for model");
  }

  for (size_t i = 0; i < numInputs; ++i) {
    const TensorSpec &providedSpec = inputTensors[i]->getSpec();
    const TensorSpec &expectedSpec = inputSpecs[i];

    // Use shared validation logic
    ErrorOrSuccess validationResult =
        M::GraphCompiler::Driver::validateInputSpec(providedSpec, expectedSpec);
    if (validationResult.isError())
      throw std::invalid_argument("Input at position " + std::to_string(i) +
                                  ": " + validationResult.takeError().get());
  }
}

// Entrypoint for executing Python DeviceTensors.
std::vector<Driver::Python::Buffer> M::Core::ModelHandle::executeDeviceTensors(
    std::vector<Driver::Python::Buffer *> &inputTensors) {
  TRACY_ZONE_SCOPED_NC("ModelHandle::executeDeviceTensors", TRACY_COLOR_YELLOW);

  if (!loadedModel)
    return {};

  // We now need to validate if the tensors the user provided are of the correct
  // shape and dtype.
  validateInputSpecList(compiledModels, modelIndex, inputTensors);

  M::Engine::Context &runtimeCtx = getRuntimeContext();

  const size_t numInputs = inputTensors.size();
  // Extract the objects backing the inputs and feed them into the execution
  // method.
  SmallVector<AsyncRT::AnyAsyncValueRef> valuePtrs;
  valuePtrs.reserve(numInputs);

  // Track the tensor input indices separately to index into the input devices.
  // This is because only tensor input devices are encoded in the `Model`.
  size_t tensorInputIdx = 0;
  for (auto &tensor : inputTensors) {
    // Check that the tensor input device is valid.
    verifyInputDevice(tensor, inputDevicesPy, tensorInputIdx);

    ErrorOr<std::shared_ptr<Driver::Python::BufferStorage>> storageOr =
        tensor->getInputStorage();
    if (storageOr.isError())
      throw std::runtime_error(storageOr.takeError().get());

    // Marshal the tensor into an AsyncValue for model execution.
    valuePtrs.push_back(M::GraphCompiler::Driver::prepareInput(
        runtimeCtx.getCPUDevice(), storageOr.takeValue()->buf,
        tensor->getSpec()));

    ++tensorInputIdx;
  }

  // Each user-visible model.execute() that reaches the executor counts as
  // one profiler step — whether the executor returns cleanly or throws. This
  // is the production step boundary: the count drives the warmup/active
  // step-window state machine (max-debug.profiling-warmup-steps /
  // profiling-active-steps) and forwards a libkineto iteration marker while
  // a trace is live. executePreparedDeviceTensors can dispatch kernels
  // before failing on a driver error, so the step boundary needs to fire
  // even on the throw path or libkineto's correlation-ID stream would lose
  // its iteration markers.
  // The disabled path is a single predicted-branch isEnabled() check and
  // early return inside M::Profiling::step() — the same fast-path contract
  // as rangeBegin/rangeEnd/RangeScope, and well below the noise floor of
  // the executor body. Perf gates (#86467) validate end-to-end.
  struct ScopedStep {
    ~ScopedStep() {
      // This dtor fires during stack unwinding when the executor throws.
      // step() can call into libkineto on the active path; a throw escaping
      // here would cross the (implicitly noexcept) destructor boundary
      // mid-unwind and call std::terminate. A profiler hiccup must never
      // turn an executor error into a hard abort, so swallow.
      try {
        M::Profiling::step();
      } catch (...) {
      }
    }
  } stepGuard;

  return executePreparedDeviceTensors(runtimeCtx, valuePtrs);
}

std::vector<Driver::Python::Buffer> ModelHandle::executePreparedDeviceTensors(
    M::Engine::Context &runtimeCtx,
    SmallVectorImpl<AnyAsyncValueRef> &inputValues) {
  auto execResults = [&]() -> GraphCompiler::Driver::ExecResultType {
    // We need to release the GIL while we execute. This is to prevent
    // situations where other threads are attempting to decref DLPack tensors
    // that are being used by our engine and the `execute` call holds the GIL.
    // This situation can cause a deadlock.
    nb::gil_scoped_release release;
    auto result = M::GraphCompiler::Driver::executeFromDriver(
        runtimeCtx, loadedModel.copy(), inputValues);
    if (result.isError())
      throw std::invalid_argument(result.takeError().get());

    return result.takeValue();
  }();

  return extractPyBufferResults(execResults, outputDevicesPy);
}

M::Core::InferenceSession::InferenceSession(
    std::vector<Driver::Python::PyDeviceTy> &&devices,
    std::vector<std::filesystem::path> &&customExtensions, size_t numThreads) {
  // Ideally this does direct initialization, populateCompileConfig reads
  // the current value.
  sessionCompileConfig = populateCompileConfig(std::move(customExtensions));

  // Defaults to 0 (use all threads)
  runtimeConfig.setNumThreads(numThreads);

  this->devices = std::move(devices);
  for (const auto &device : this->devices)
    runtimeConfig.addDevice(
        {std::make_shared<const M::DeviceSpec>(device->deviceSpec),
         device->ctx});

  runtimeConfig.setAPILanguage("python");

  auto runtimeCtxOr = Engine::Context::create(runtimeConfig);
  if (runtimeCtxOr.isError())
    throw std::invalid_argument(runtimeCtxOr.takeError().get());

  runtimeContext =
      std::make_unique<M::Engine::Context>(runtimeCtxOr.takeValue());

  // Enable Python stack traces for signal handler
  // Actual Python stack traces are handled by faulthandler for async signal
  // safety
  M::Init::enablePythonStackTraceCallback();

  // Auto-start the profiler when requested via configuration
  // (max-debug.profiling-enabled, settable through the
  // MODULAR_MAX_DEBUG_PROFILING_ENABLED / MODULAR_DEBUG env vars,
  // modular.cfg, or session.debug). Session construction is the earliest
  // common point on every entry path — before model load and therefore
  // before MLRT retains a device's primary context — so a capture spans
  // compilation too. On AMD the same knob makes the profiler host glue load
  // and register the plugin at device init; this enable() then records via
  // the deferred activation (see activatePendingTrace() in
  // Support/Profiling/Ranges.h). enable() is idempotent. The trace is flushed
  // by the profiler plugin's own exit hook, so no Python involvement is
  // required end to end.
  if (DebugConfig::instance().getProfilingEnabled()) {
    M::Profiling::enable();
    if (!M::Profiling::haveProfiler()) {
      // Once per process: several sessions would otherwise repeat it.
      static std::once_flag pluginMissingWarned;
      std::call_once(pluginMissingWarned, [] {
        std::fprintf(stderr,
                     "info: profiling was requested (max-debug.profiling-"
                     "enabled) but the profiler plugin (libMAXProfilerPlugin"
                     ".so) was not found; nothing will be recorded. Deploy the "
                     "plugin next to the MAX libraries or set "
                     "MODULAR_PROFILER_PLUGIN to its path.\n");
      });
    }
  }
}

void M::Core::InferenceSession::addCustomExtensionToCompileConfig(
    CompilationRequest &config, std::filesystem::path path) {
  if (M::Filesystem::isMojoBinaryPackagePath(path)) {
    // Mojo extension.
    if (std::error_code ec; !std::filesystem::exists(path, ec) || ec)
      throw std::invalid_argument("invalid path to kernel library: " +
                                  path.string());

    config.addKernelLibraryPath(std::move(path));
  } else {
    throw std::invalid_argument("Error: unknown custom extension type of `" +
                                path.string() + "`.");
  }
}

CompilationRequest M::Core::InferenceSession::populateCompileConfig(
    std::vector<std::filesystem::path> &&customExtensions) {
  // Clone the existing compile config
  auto compileConfig = sessionCompileConfig;

  for (auto path : customExtensions)
    addCustomExtensionToCompileConfig(compileConfig, std::move(path));

  return compileConfig;
}

static AsyncValueRef<CompiledModels>
compileModel(const M::Engine::Context &runtimeContext,
             CompilationRequest &&config) {
  AsyncValueRef<CompiledModels> compiledModels =
      runtimeContext.compileModel(std::move(config));
  if (compiledModels.isError()) {
    auto &telemetryCtx =
        *runtimeContext.maxContext->get<GML::MaxEngineTelemetryContext>();
    Error error = compiledModels.getDiagnostic().getMessage().copy();
    Telemetry::emitCompileInfo("compile.failure", telemetryCtx,
                               std::optional{error.copy()});

    throw std::invalid_argument(error.get());
  }
  return compiledModels;
}

AsyncRT::AsyncValueRef<CompiledModels> M::Core::InferenceSession::compile(
    std::filesystem::path modelPath,
    std::vector<std::filesystem::path> &&customExtensions) {
  CompilationRequest compileConfig =
      populateCompileConfig(std::move(customExtensions));
  compileConfig.setModelPath(std::move(modelPath));
  // Compile async, so it's safe to hold the gil here
  auto compiledModels{compileModel(*runtimeContext, std::move(compileConfig))};
  return compiledModels;
}

AsyncRT::AsyncValueRef<CompiledModels> M::Core::InferenceSession::compile(
    const nb::capsule &model,
    std::vector<std::filesystem::path> &&customExtensions,
    std::string &&pipelineName, bool tileBasedFusion) {
  CompilationRequest compileConfig =
      populateCompileConfig(std::move(customExtensions));
  // Set pipeline name. Tracked for telemetry.
  compileConfig.setPipelineName(std::move(pipelineName));
  // Opt into the tile-based programming model if requested.
  compileConfig.setTileBasedFusion(tileBasedFusion);
  // When the format is Max Graph, model is a opaque pointer of graph.
  // So we cast it to a pointer representation and pass it along.
  // The C API will open appropriate dylib for the format and pass the
  // pointer to the library. We have to make sure the pointer is passed down
  // to the library which created the pointer. This is to ensure mlir type
  // id invariants are not broken.
  compileConfig.setModelSource(ModelSource{
      .source = model.data(),
      .fileFormat = frameworkToFileFormat(),
  });
  // Compile async, so it's safe to hold the gil here
  AsyncValueRef<CompiledModels> asyncModel =
      compileModel(*runtimeContext, std::move(compileConfig));
  return asyncModel;
}

// ===== ModelHandle Graph Capture/Replay Methods ===== //

static SmallVector<ModelInputBuffer>
collectInputBuffers(const AsyncValueRef<CompiledModels> &compiledModels,
                    size_t modelIndex,
                    const std::vector<Driver::Python::Buffer *> &inputs,
                    ArrayRef<Driver::Python::PyDeviceTy> inputDevices) {
  validateInputSpecList(compiledModels, modelIndex, inputs);

  SmallVector<ModelInputBuffer> buffers;
  buffers.reserve(inputs.size());

  size_t tensorInputIdx = 0;
  for (auto *tensor : inputs) {
    verifyInputDevice(tensor, inputDevices, tensorInputIdx);
    ErrorOr<std::shared_ptr<Driver::Python::BufferStorage>> storageOr =
        tensor->getInputStorage();
    if (storageOr.isError())
      throw std::runtime_error(storageOr.takeError().get());
    std::shared_ptr<Driver::Python::BufferStorage> storage =
        storageOr.takeValue();
    buffers.push_back({storage->buf, storage->spec});
    ++tensorInputIdx;
  }

  return buffers;
}

std::vector<Driver::Python::Buffer>
M::Core::ModelHandle::capture(const std::vector<uint64_t> &graphKeys,
                              std::vector<Driver::Python::Buffer *> &inputs) {
  if (!loadedModel)
    throw std::runtime_error("Model not loaded");

  auto *executableModel = loadedModel->get();
  if (!executableModel)
    throw std::runtime_error("Executable model not available");

  auto buffers =
      collectInputBuffers(compiledModels, modelIndex, inputs, inputDevicesPy);
  auto result = [&] {
    nb::gil_scoped_release release;
    return executableModel->capture(graphKeys, buffers);
  }();
  if (result.isError())
    throw std::runtime_error(result.takeError().get());

  M::Engine::Context &runtimeCtx = getRuntimeContext();
  SmallVector<AnyAsyncValueRef> results = result.takeValue();
  auto execResults = GraphCompiler::Driver::extractDriverResults(
      runtimeCtx, loadedModel.copy(), results);

  if (execResults.isError())
    throw std::runtime_error(execResults.takeError().get());

  return extractPyBufferResults(*execResults, outputDevicesPy);
}

static CPUDeviceOptions
getOrCreateCPUDeviceOptions(const Engine::Config &config,
                            StringRef profileFilename) {
  AsyncRT::CPUDeviceOptions cpuDeviceOptions;
  cpuDeviceOptions.numThreads = config.getNumThreads();
  cpuDeviceOptions.maxThreads = config.getMaxThreads();
  cpuDeviceOptions.tcmallocAllocator =
      config.getAllocatorType() == (int)kCaching;
  cpuDeviceOptions.threadBusyWaitTime = config.getThreadBusyWaitTime().count();
  cpuDeviceOptions.profileFilename = profileFilename;
  cpuDeviceOptions.poolName = config.getContextName();
  if (cpuDeviceOptions.numThreads == 1)
    cpuDeviceOptions.withSingleThreaded();
  // Previously mainWillDonate was required to be false in order to avoid the
  // Runtime created by the Engine from overwriting the Runtime created by the
  // Mojo stdlib during startup, this is no longer the case. Though there is
  // still a question of whether the Engine should be initialized with
  // mainWillDonate as true or false, setting to true currently causes an issue
  // with integration with the Torch inductor. See GEX-3387 for details.
  cpuDeviceOptions.mainWillDonate = false;

  return cpuDeviceOptions;
}

static void setUnknownLocError(AnyAsyncValueRef &&asyncVal, Error error) {
  std::move(asyncVal).setToError(
      {std::move(error), UnknownLocationDecoder::getEncodedLocation()});
}

static ErrorOr<std::unique_ptr<ExecutableModel>>
createExecutableModel(const M::Model *model, CPUDevice &cpuDevice,
                      const Engine::Config &config,
                      const WeightsRegistry *weightsRegistry) {
  M::GraphCompiler::Driver::DeviceMap deviceMap;
  for (const auto &device : config.getDevices())
    deviceMap.insert({device.spec->ref, device.context});
  auto executableModelOr = model->setup(cpuDevice, weightsRegistry, deviceMap);
  if (executableModelOr.isError())
    return executableModelOr.takeError().getMessage().copy();

  auto executableModel = executableModelOr.takeValue();
  auto setupErrorOrSuccess = executableModel->waitForModelSetup();
  if (setupErrorOrSuccess.isError())
    return Error(Twine("Model setup failed, not ready for execution.  "
                       "Modular internal detail: ") +
                 setupErrorOrSuccess.getError());
  return std::move(executableModel);
}

static ErrorOr<ExecutableModels>
createExecutableModels(const CompiledModels &compiledModels,
                       CPUDevice &cpuDevice, const Engine::Config &config,
                       const WeightsRegistry *weightsRegistry) {
  if (compiledModels.getNumModels() == 0)
    return Error::getStaticString(
        "Compiled model does not contain any valid models");

  ExecutableModels results;
  results.reserve(compiledModels.getNumModels());

  for (const std::unique_ptr<const Model> &model : compiledModels) {
    ErrorOr<std::unique_ptr<ExecutableModel>> executableModelOr =
        createExecutableModel(model.get(), cpuDevice, config, weightsRegistry);
    if (executableModelOr.isError())
      return executableModelOr.takeError();
    results.push_back(executableModelOr.takeValue());
  }
  return results;
}

static ErrorOr<TensorMap>
executeExecutableModel(const ExecutableModel &executableModel,
                       TensorMap &inputMap, CPUDevice &cpuDevice) {
  auto inputNames = executableModel.getModel()->getInputNames();

  SmallVector<AnyAsyncValueRef> inputValuesInMEFIndexOrder;
  inputValuesInMEFIndexOrder.reserve(inputMap.tensors.size());

  // Iterating on names in MEF order here.
  for (auto inputName : inputNames) {
    auto it = inputMap.tensors.find(inputName);
    if (it == inputMap.tensors.end()) {
      return Error("The model requires an input tensor named '" + inputName +
                   "' but it was not provided.");
    }

    inputValuesInMEFIndexOrder.emplace_back(it->second.copy());
  }

  auto results = executableModel.execute(inputValuesInMEFIndexOrder);

  if (results.empty())
    return Error("Failed to execute model");

  if (auto err = AsyncRT::awaitOrError(results))
    return err.takeError();

  MutableArrayRef<AnyAsyncValueRef> resultCopy(results.data(), results.size());
  resultCopy = resultCopy.drop_front();
  llvm::SmallVector<AnyAsyncValueRef> outputTensorRefs;
  outputTensorRefs.reserve(resultCopy.size());
  for (auto &result : resultCopy) {
    outputTensorRefs.push_back(std::move(result));
  }

  AsyncRT::await(outputTensorRefs);

  llvm::StringMap<AnyAsyncValueRef> resultMap;
  auto outputNames = executableModel.getModel()->getOutputNames();
  for (auto [outIdx, tensor] : llvm::enumerate(outputTensorRefs)) {
    if (tensor.isError())
      return tensor.getDiagnostic().getMessage().copy();

    resultMap.insert({outputNames[outIdx], std::move(tensor)});
  }

  return TensorMap(std::move(resultMap), cpuDevice);
}

ErrorOr<Engine::Context>
Engine::Context::create(const M::Engine::Config &config) {
  std::string profileFilename =
      llvm::sys::Process::GetEnv("MODULAR_PROFILE_FILENAME").value_or("");

  ContextRef maxContext;
  if (ContextRef ctx = config.getMaxContext()) {
    maxContext = std::move(ctx);
  } else {
    Init::Options options;
    CPUDeviceOptions rtOptions =
        getOrCreateCPUDeviceOptions(config, profileFilename);
    options.withCPUDeviceOptions(rtOptions);
    options.withForceDisableCrashReporting(!config.isCrashLogEnabled());

    auto contextOr = Init::getOrCreateContext("max-engine", options);
    if (contextOr.isError())
      return contextOr.takeError();
    maxContext = contextOr.takeValue();
  }
  auto runtimeContext = Engine::Context(config, maxContext.copy());
  auto &maxTelemetryContext =
      runtimeContext.maxContext
          ->emplaceIfMissing<GML::MaxEngineTelemetryContext>(maxContext.copy());
  maxTelemetryContext.setAPILanguage(config.getAPILanguage().str());

  // Source of truth for the closed set of valid device labels. Downstream
  // consumers (notably the C-API M_HOST vs M_ACCELERATOR predicate in
  // M_getDeviceType / M_getDeviceTypeFromSpec) treat anything not rejected
  // here as a valid device, so this guard must stay in sync with the
  // kCPULabel / kGPULabel constants in Support/DeviceSpecs.h.
  for (const auto &device : config.getDevices()) {
    const DeviceSpec &spec = *device.spec;
    if (spec.ref.label != kCPULabel && spec.ref.label != kGPULabel) {
      return Error(Twine("unrecognized device '") + spec.ref.label + "'");
    }
    // else: no special extra device handling
  }
  return runtimeContext;
}

Engine::Context::Context(Context &&other)
    : maxContext(std::move(other.maxContext)), config(std::move(other.config)),
      cpuDevice(*maxContext->get<CPUDevice>()) {}

Engine::Context::Context(const M::Engine::Config &runtimeConfig,
                         M::ContextRef context)
    : maxContext(std::move(context)), config(runtimeConfig),
      cpuDevice(*maxContext->get<CPUDevice>()) {
  crashRecoveryContext.DumpStackAndCleanupOnFailure = true;
}

AsyncValueRef<CompiledModels>
Engine::Context::compileModel(CompilationRequest config) const {
  auto compiledModelAsync = AsyncValueRef<CompiledModels>::allocate(cpuDevice);

  addTask(cpuDevice, [config = std::move(config),
                      compiledModelAsync = compiledModelAsync.copy(),
                      this]() mutable {
    auto compiledModelOr = compileModelSync(std::move(config));

    auto &telemetryCtx = *maxContext->get<GML::MaxEngineTelemetryContext>();

    if (compiledModelOr.isError()) {
      Error compileError = compiledModelOr.takeError();
      // FIXME: This potentially can contain absolute file paths in user
      // machine. We might need to scrub that.
      Telemetry::emitCompileInfo("compile.failure", telemetryCtx,
                                 compileError.copy());
      return setUnknownLocError(std::move(compiledModelAsync),
                                std::move(compileError));
    }

    Telemetry::emitCompileInfo("compile.success", telemetryCtx, {});
    std::move(compiledModelAsync).emplace(compiledModelOr.takeValue());
  });

  return compiledModelAsync;
}

static void telemetryEmitModelFormat(FileFormat format, ContextRef context) {
  auto telemetryContext = context->get<Telemetry::TelemetryContext>();
  Telemetry::emitCompiledModelType(*telemetryContext, format);
}

static void telemetryEmitPipelineName(std::string_view pipelineName,
                                      ContextRef context) {
  auto telemetryContext = context->get<Telemetry::TelemetryContext>();
  Telemetry::emitPipelineName("max.pipeline.run", *telemetryContext,
                              pipelineName);
}

/// Compiles a model. Functionally identical to `M_compileModel`, but blocks
/// on execution. Unlike `M_compileModel`, the user does not need to call
/// `M_waitForCompilation` to await a compilation result. Also does not use CAS
/// for kernel caching.
ErrorOr<CompiledModels>
Engine::Context::compileModelSync(CompilationRequest config) const {
  config.setDevices(this->config.getDevices());
  auto modelOr =
      CompiledModels::create(maxContext.copy(), config, this->config);
  if (modelOr.isError())
    return modelOr.takeError();

  if (auto pipelineName = config.getPipelineName(); pipelineName)
    telemetryEmitPipelineName(*pipelineName, maxContext);
  telemetryEmitModelFormat(modelOr.get().getSourceModel().format(), maxContext);

  return modelOr.takeValue();
}

ErrorOrSuccess Engine::Context::await(AnyAsyncValueRef value) {
  return AsyncRT::awaitOrError(value);
}

M::AsyncExecutableModel
Engine::Context::initModel(const M::Model *model,
                           const WeightsRegistryRef &weightsRegistry) const {
  using ModelType = std::unique_ptr<M::ExecutableModel>;
  auto result = AsyncValueRef<ModelType>::allocate(cpuDevice);

  // Run on a cpuDevice worker thread to ensure AsyncRT cpuDevice is set in TLS.
  // (MGP_RT_BufferBorrowV2, called during Model::setup, requires a valid
  // current cpuDevice.)
  addTask(cpuDevice, [model, weights = weightsRegistry.copy(),
                      result = result.copy(), this]() mutable {
    auto executableModelOr = createExecutableModel(
        model, cpuDevice, getConfig(), weights.getPointer());
    if (executableModelOr.isError())
      return setUnknownLocError(std::move(result),
                                executableModelOr.takeError());
    std::move(result).emplace(executableModelOr.takeValue());
  });

  return result;
}

AsyncValueRef<ExecutableModels>
Engine::Context::initModel(AsyncValueRef<CompiledModels> compiledModels,
                           const WeightsRegistryRef &weightsRegistry) const {
  auto result = AsyncValueRef<ExecutableModels>::allocate(cpuDevice);

  // Use andThenAsync to ensure createExecutableModels runs on a cpuDevice
  // worker thread.  The caller may be a foreign thread (e.g. a Python
  // ThreadPoolExecutor thread) that has no AsyncRT cpuDevice set in its
  // thread-local storage; MGP_RT_BufferBorrowV2 (called during Model::setup)
  // requires a valid current cpuDevice.
  std::move(compiledModels)
      .andThenAsync(
          [result = result.copy(), weights = weightsRegistry.copy(),
           this](AsyncValueRef<CompiledModels> &&compiledModelsRef) mutable {
            if (compiledModelsRef.isError())
              return setUnknownLocError(
                  std::move(result),
                  compiledModelsRef.takeDiagnostic().getMessage().copy());

            auto executableModelsOr =
                createExecutableModels(compiledModelsRef.get(), cpuDevice,
                                       getConfig(), weights.getPointer());
            if (executableModelsOr.isError())
              return setUnknownLocError(std::move(result),
                                        executableModelsOr.takeError());

            std::move(result).emplace(executableModelsOr.takeValue());
          });

  return result;
}

AsyncValueRef<TensorMap>
Engine::Context::execute(AsyncExecutableModel executableModel,
                         AsyncValueRef<TensorMap> inputTensorMap) const {
  auto outputTensorMap = AsyncValueRef<TensorMap>::allocate(cpuDevice);
  AsyncExecutableModel executableModelRef = executableModel.copy();
  executableModel.andThenAsync([this, inTensorMap = inputTensorMap.copy(),
                                outTensorMap = outputTensorMap.copy(),
                                executableModelRef =
                                    std::move(executableModelRef)]() mutable {
    if (executableModelRef.isError()) {
      return std::move(outTensorMap)
          .setToError(executableModelRef.takeDiagnostic());
    }

    AsyncRT::await(inTensorMap);
    auto &inputMap = inTensorMap.get();

    std::unique_ptr<ExecutableModel> &executableModel =
        executableModelRef.get();
    if (!executableModel) {
      return std::move(outTensorMap)
          .setToError({Error::getStaticString("Executable model not available"),
                       UnknownLocationDecoder::getEncodedLocation()});
    }

    ErrorOr<TensorMap> outputsOr =
        executeExecutableModel(*executableModel, inputMap, cpuDevice);
    if (outputsOr.isError()) {
      const Model *model = executableModel->getModel();
      return std::move(outTensorMap)
          .setToError({outputsOr.takeError(),
                       model ? model->getLocation().copy()
                             : UnknownLocationDecoder::getEncodedLocation()});
    }
    std::move(outTensorMap).emplace(outputsOr.takeValue());
  });
  return outputTensorMap;
}

ErrorOr<ArrayRef<QuantTensorSpec>>
Engine::Context::getInputSpecs(AsyncValueRef<CompiledModels> compiledModels,
                               size_t modelIndex) {
  if (auto err = AsyncRT::awaitOrError(compiledModels))
    return err.takeError();

  if (auto model = compiledModels->getModel(modelIndex))
    return model->getInputSpecs();

  return Error::getStaticString("model index out of bounds");
}

ErrorOr<ArrayRef<QuantTensorSpec>>
Engine::Context::getOutputSpecs(AsyncValueRef<CompiledModels> compiledModels,
                                size_t modelIndex) {
  if (auto err = AsyncRT::awaitOrError(compiledModels))
    return err.takeError();

  if (auto model = compiledModels->getModel(modelIndex))
    return model->getOutputSpecs();

  return Error::getStaticString("model index out of bounds");
}

ErrorOr<Engine::ConfiguredDevice>
Engine::Context::resolveDevice(M::DeviceRef deviceRef) const {
  for (auto &device : getConfig().getDevices())
    if (deviceRef == device.spec->ref)
      return device;
  return Error(Twine("unrecognized device '") + deviceRef.toString() + "'");
}
