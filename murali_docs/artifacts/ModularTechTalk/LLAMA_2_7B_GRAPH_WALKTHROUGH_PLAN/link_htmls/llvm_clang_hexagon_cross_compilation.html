    WHAT LLVM ADDS TO THE TOOLCHAIN

    One representation, many backends.

    Clang gives LLVM C semantics in a typed intermediate form. LLVM’s middle-end can optimize that form; a target backend maps it to an instruction set. The linker and target runtime complete the executable.

    01 · DRIVER + FRONTEND

    Clang

    The driver interprets options and coordinates compiler/linker tools. Clang parses C, checks its types and semantics, then lowers the program into LLVM IR.

    02 · COMMON REPRESENTATION

    LLVM IR + target triple

    A typed, low-level representation shared by language frontends and LLVM’s optimization/code-generation infrastructure. The triple names the output target; here it is hexagon-unknown-unknown-elf, with Hexagon v68 selected by this toolchain. LLVM IR is not machine code.

    03 · VALUE FLOW

    SSA + phi

    In Static Single Assignment form, each SSA value is defined once. A phi instruction selects the incoming value associated with the control-flow edge that reached a block.

    04 · REUSABLE TRANSFORMS

    Optimization passes

    Target-aware LLVM passes can simplify or reshape defined C behavior. Here the -O1 snapshot replaces the loop with arithmetic; this is observed compiler output for this input and toolchain.

    05 · MACHINE-SPECIFIC OUTPUT

    Target backend

    The Hexagon backend lowers the LLVM module using Hexagon instructions, registers, predicates and ABI rules. A different backend can emit a different instruction set from LLVM IR.

    06 · TARGET SUPPORT

    Linker + runtime

    A target triple does not supply headers, libraries or a linker. Hosted OS targets commonly use a matching sysroot; this Hexagon ELF example uses the installed Qualcomm toolchain's linker, startup objects and target libraries.

entry:
  %n.addr = alloca i32, align 4
  %total = alloca i32, align 4
  %i = alloca i32, align 4
  store i32 %n, i32* %n.addr, align 4

  br label %for.cond

  %0 = load i32, i32* %i, align 4
  %1 = load i32, i32* %n.addr, align 4
  %cmp = icmp sle i32 %0, %1
  br i1 %cmp, label %for.body, label %for.end

for.body:                                         ; preds = %for.cond

  %3 = load i32, i32* %total, align 4
